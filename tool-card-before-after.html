สองทางแก้ — ต่างกันที่ “พับตอนไหน”

ทางกติกาได้จ่าย
A พับครั้งเดียว stretch ที่เทิร์นยังทำงานอยู่ = กางค้าง · พับเมื่อ stretch นั้นจบ (โมเดลเริ่มพูด · ผู้ใช้แทรก · เทิร์นจบ) ขยับรวม 380px · พับครั้งเดียว · ไม่มีแถววาดซ้ำ ตอนโมเดลเงียบคิดคำตอบนาน กล่องยังกางอยู่ (เดิมพับไปแล้ว) — ต้องมี caret ให้กดปิดเองได้ทันทีที่ไม่มีอะไรวิ่ง
B พับทุกรอบ พับเหมือนเดิมทุกครั้งที่รอบสุดท้ายกลับมา แต่โชว์เฉพาะรอบที่กำลังรัน ไม่กางของเก่าซ้ำ ไม่มีการวาดซ้ำ · งานที่เสร็จยังอยู่ในตัวเลข ยังขึ้นลงทุกรอบ (3 จังหวะ 864px) · รอบที่พับแล้วต้องกดเปิดดูเองได้

ตัวเลข “หน้าจอขยับรวม” ทั้งสามแบบ (อ่านจากหน้าจำลองนี้หลังรันจบ): ตอนนี้ 1120px / 3 จังหวะ / 21 แถววาดซ้ำ · A 380px / 1 จังหวะ / 0 · B 864px / 3 จังหวะ / 0 — B คือแบบที่ลงโค้ดแล้ว: จอขยับเท่าเดิม แต่ไม่มีแถววาดซ้ำและไม่มีจังหวะที่หายวับ
