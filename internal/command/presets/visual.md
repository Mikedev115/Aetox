เปลี่ยนเรื่องที่อธิบายยากนี้ให้เป็นภาพเดียวที่คนเข้าใจได้ใน 5 วินาที

**เลือกทรงก่อนวาด** — คำถามที่เรื่องนี้กำลังตอบ คือตัวบอกว่าต้องวาดเป็นทรงไหน ไม่ใช่ความสวย

| เรื่องนี้กำลังตอบว่า | วาดเป็น |
|---|---|
| มันทำงานยังไง เป็นขั้น ๆ | ลำดับขั้น หรือเส้นเวลา |
| มีขั้นตัดสินใจแยกทางด้วย | ผังงานที่มีสี่เหลี่ยมข้าวหลามตัด |
| มันเกี่ยวข้องกับอะไรบ้าง | วงล้อมรอบสิ่งหลัก |
| เรื่องใหญ่นี้มีอะไรอยู่ข้างใน | แผนที่ความคิดสองชั้น หรือแยกเป็นส่วนประกอบ |
| ซ้อนกันเป็นชั้น ๆ | ชั้นที่ทับกันจากบนลงฐาน |
| อันไหนต่างจากอันไหน | ตารางเทียบ หรือสองแกนสี่ช่อง |
| คนค่อย ๆ หายไปตามขั้นตอน | กรวย พร้อมเปอร์เซ็นต์ที่หลุดแต่ละขั้น |
| ลูกค้าเจออะไรบ้างตลอดทาง | เส้นทางลูกค้า พร้อมเส้นอารมณ์ที่มีจุดต่ำ |
| ของมาจากไหนไปถึงใคร | ห่วงโซ่อุปทาน หรือห่วงโซ่มูลค่าถ้าเน้นว่าใครเติมเท่าไร |
| ใครอยู่ใต้ใคร | ผังลำดับชั้น เส้นหักฉาก ไม่มีหัวลูกศร |
| ใหญ่/เล็กแค่ไหน | เทียบขนาดกับของที่คนเคยยืนข้าง |
| ถ้าเกิดเหตุการณ์นี้ | ทางแยกอนาคต พร้อมความน่าจะเป็นแต่ละทาง |
| ทำแล้วได้อะไร | ปัญหา → สิ่งที่ทำ → ผลลัพธ์ ที่ช่องสุดท้ายมีตัวเลข |
| มันเปลี่ยนมาเป็นแบบนี้ได้ยังไง | ลำดับภาพที่สลับกันไม่ได้ |

**วิธีทำ**
1. บอกก่อนหนึ่งบรรทัดว่าเลือกทรงไหนและทำไม ถ้าเรื่องที่ให้มาไม่มีรูปทรง (เป็นรายการที่ไม่มีลำดับ ไม่มีความสัมพันธ์) ให้บอกตรง ๆ ว่าเรื่องนี้ยังไม่ควรเป็นภาพ แทนที่จะวาดกล่องเรียงกันให้ดูเหมือนมีความหมาย
2. อ่านเทมเพลตของทรงนั้นจาก `aetox-slide-templates` ก่อนเขียนเอง มีของจริงให้ก๊อปอยู่แล้ว
3. วาดด้วย CSS กับ SVG ในไฟล์เดียว ถ้าเอาไปใส่เด็ค ให้ออกมาเป็นสไลด์ตามโครงของ `aetox-slides` ถ้าเอาไปใช้เดี่ยว ๆ ให้เป็นไฟล์ SVG ไฟล์เดียว

**สิ่งที่อยากได้**
- ตัวเลขจริงบนภาพ ถ้ายังไม่มีให้เว้นที่ไว้แล้วบอกว่าต้องเติมอะไร
- ป้ายทุกป้ายเป็นภาษาที่พูดออกเสียงได้ ไม่ใช่ศัพท์ที่ต้องอธิบายต่อ
- หนึ่งภาพตอบหนึ่งคำถาม ถ้ามีสองคำถามให้แยกเป็นสองภาพ
- บอกท้ายคำตอบว่าภาพนี้กำลังอ้างอะไร และตรงไหนที่ผมควรเช็คก่อนเอาไปใช้

**ห้าม**
- ห้ามส่งพรอมต์ให้ผมไปเจนรูปที่อื่น เว้นแต่งานนั้นเป็นภาพถ่ายหรือภาพผ่าซีกที่วาดด้วยโค้ดไม่ได้จริง ๆ แล้วค่อยบอกว่าทำไม
- ห้ามใช้ไลบรารีกราฟจาก CDN ห้ามลิงก์ CSS ข้างนอก ไฟล์เดียวจบ
- ห้ามแปะบุลเล็ตแล้วตีกรอบเรียกว่าไดอะแกรม
- ห้ามแต่งตัวเลขหรือเปอร์เซ็นต์ขึ้นมาเพื่อให้ภาพดูสมบูรณ์
