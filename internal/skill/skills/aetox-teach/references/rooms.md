# The rooms, one at a time

Read this when the user asks where something is, or when an answer is about to
send them somewhere. Everything below is a label printed on a screen. Use those
words and no others: a room described by the tool that opens it is a room the
user cannot find.

Each entry says what the room is for and, more usefully, **what it is not**.
Most wrong expectations about this app are one of the "not" lines below.

## The switch above the logo

Two doors are on it in this build:

- **Aetox ผู้ช่วย**, the storefront, holding the first six rooms below.
- **Aetox โค้ด**, the workshop, holding one room.

A third door, **Aetox ทีม**, and the **ห้องทำงาน** behind it are built and
wired but not offered on the switch yet. If a user asks about saved workflows,
say that honestly rather than describing a room they cannot open.

Switching doors changes the shell, not the app. One engine, one store of
settings, memory and permissions underneath all of it.

## ผู้ช่วย

The main chat. Everything on the machine except the developer tooling: files,
the shell, the web, documents, media, memory, and hiring the specialists.

- **Not** a chat window that hands back text to copy. The end of a job here is
  usually a file.
- **Not** limited to non-software work. Fixing a program, installing something,
  writing a script are all this desk's work. What it lacks is the code tooling
  (a language server, repository browsing), not permission.
- **Not** bound to a folder. It can reach anywhere the user allows.

## ความสามารถ

What the assistant is made of, and what can be added: the built-in tools, the
MCP servers connected, and the skills installed. Servers not yet installed are
shown first, on purpose, because this room exists to announce that plugging
things in is possible at all.

- **Not** a settings page. Nothing is configured here; it is a shelf.
- **Not** where agents are managed. That is เอเจนเฉพาะทาง.

## โปรเจกต์

A named folder that groups chats and carries a few context files into every
session held inside it, so each new chat starts already knowing.

- **Not** a fence. The assistant still reaches the whole machine from inside a
  project. This is the difference from the workshop's projects, which do root
  the sandbox and that is their entire point.
- **Not** shared memory between the chats in it. A session gets the files, not
  the other conversations.

## เอเจนเฉพาะทาง

The specialists: who is available, what each is for, and what work has been
handed over. They can be talked to directly from here, or given a job from a
ผู้ช่วย chat without leaving it.

- **Not** something to walk into for every job. Handing over is worth it when
  the job is a brief that comes back as a file.
- **Not** visible from the โค้ด desk. That desk hires nobody.
- Hiring a new one is the user's decision. Offer, never do it unasked.

## งานวิดีโอ

Making a video, or cutting one that already exists. Walking in asks which of
the two, and routes to the right specialist.

- **Not** a chat room. It is a question that decides who does the work.

## ผลงาน

Every file Aetox has made, swept off the disk rather than kept in a list, so
what is shown is what is really there.

- **Not** tied to the chat that made it. Deleting a chat leaves its files.
- Only the user deletes from here.

## โค้ด

Full software work bound to a project folder on disk: files, shell, code
tooling, the terminal and the editor panes.

- **Not** a gate that keeps ผู้ช่วย away from software. It is a different set
  of tools, not a different set of permissions.
- **Not** reachable from a ผู้ช่วย conversation. A session stays at the desk it
  was opened on for its whole life. Changing desks means a new chat, which
  costs nothing.

## The panels beside the chat

On the desktop, work becomes visible in the panels: a terminal, a browser, a
file view, and a slide view that pages through an HTML deck and exports it.
Say what was put in one and where. Never name the tool that opened it.

## The composer

- The **โหมดทำงาน** control: **ลงมือ** (normal, full tools), **วางแผน** (looks
  at everything, changes nothing, ends with a plan), **คู่คิด** (talk only, no
  tools). Switchable at any time without losing the conversation.
- **`/`** opens the prompt presets.
- The mic, if speech is set up in ตั้งค่า > เสียง.
