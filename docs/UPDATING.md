# อัปเดต Aetox

> คู่มือเดียวสำหรับคำถาม "จะอัปเป็นรุ่นใหม่ยังไง และถ้าอัปแล้วไม่ขึ้นต้องทำอะไร"
> วิธีติดตั้งครั้งแรกอยู่ที่ [README › ติดตั้ง](../README.th.md#ติดตั้ง) · English summary at the end

## ก่อนอื่น: รู้ว่าตัวเองใช้รุ่นไหน และลงมาทางไหน

เปิด **การตั้งค่า › เกี่ยวกับ Aetox** จะเห็นสองบรรทัดที่ต้องใช้

- **เวอร์ชันที่ติดตั้ง** เช่น `v1.9.9`
- **ช่องทาง** หนึ่งในสี่แบบ: *ติดตั้งด้วยตัวติดตั้ง* · *แบบพกพา แตกจากไฟล์ zip* · *ติดตั้งจาก Microsoft Store* · *ติดตั้งผ่าน Scoop*

วิธีอัปเดตขึ้นกับช่องทาง ไม่ใช่กับรุ่น รุ่นล่าสุดดูได้ที่ [หน้า Releases](https://github.com/Mikedev115/Aetox/releases/latest)

## แอปบอกเองเมื่อมีรุ่นใหม่

แอปถามหารุ่นใหม่ประมาณ 20 วินาทีหลังเปิด แล้ววันละครั้งตลอดที่เปิดค้างไว้ ถ้ามี จะขึ้นการ์ด
**มี Aetox v… แล้ว** ที่มุมขวาล่าง พร้อมหัวข้อ "รุ่นนี้มีอะไร" ถ้าตรวจไม่สำเร็จ (ไม่มีเน็ต GitHub ไม่ตอบ) แอปจะเงียบ
ไม่ขึ้นอะไร อยากถามเองเมื่อไรก็กด **ตรวจหาการอัปเดต** ในหน้าเกี่ยวกับ Aetox

แอป**ไม่โหลดอะไรเองจนกว่าคุณจะกด** และทุกไฟล์ที่โหลดมาจะถูกตรวจลายเซ็นกับค่าแฮชก่อนใช้ ไฟล์ที่ตรวจไม่ผ่านจะถูกทิ้ง
รุ่นที่ใช้อยู่ไม่ถูกแตะ

## อัปเดตตามช่องทาง

### ตัวติดตั้ง (ลงใน Program Files)

1. บนการ์ดกด **ดาวน์โหลด** (ในหน้าเกี่ยวกับ Aetox ปุ่มชื่อ **ดาวน์โหลดอัปเดต**) ใช้งานต่อได้ระหว่างโหลด
2. โหลดเสร็จ การ์ดเปลี่ยนเป็น **v… พร้อมแล้ว** กด **รีสตาร์ทเพื่ออัปเดต** ตอนที่สะดวก
   ถ้าเอเจนกำลังทำงานอยู่ แอปจะยังไม่ยอมรีสตาร์ท รอให้จบแล้วค่อยกด
3. แอปปิดตัว Windows เด้งหน้าต่างขอสิทธิ์ผู้ดูแล (UAC) **กด Yes** ตัวติดตั้งรันเงียบ ๆ ไม่กี่วินาที แล้วแอปเปิดกลับมาเอง
4. เช็กว่า **เวอร์ชันที่ติดตั้ง** ในหน้าเกี่ยวกับ Aetox เป็นเลขใหม่แล้ว

ยังไม่สะดวกรีสตาร์ท กด **ไว้ก่อน** หรือปิดแอปไปได้เลย ไฟล์ที่โหลดไว้จะรออยู่ เปิดแอปครั้งหน้าการ์ดขึ้น
**พร้อมแล้ว** ให้กดรีสตาร์ทได้ทันทีโดยไม่ต้องโหลดใหม่ ถ้าระหว่างนั้นมีรุ่นที่ใหม่กว่าออกมาอีก แอปจะทิ้งไฟล์เก่าแล้วเสนอรุ่นล่าสุดแทน

**ทางมือ** (ใช้ได้เสมอ): ปิด Aetox ให้หมด แล้วรัน
[aetox-amd64-installer.exe รุ่นล่าสุด](https://github.com/Mikedev115/Aetox/releases/latest/download/aetox-amd64-installer.exe)
ทับของเดิม

### แบบพกพา (zip)

1. กด **ดาวน์โหลด** แอปโหลด ตรวจ แล้วสลับ `aetox.exe` กับ `aetox-engine.exe` ในโฟลเดอร์เดิมให้ทั้งคู่
2. กดรีสตาร์ท หรือปิดแอปตามปกติแล้วเปิดใหม่ทีหลัง ตอนเปิดครั้งถัดไปจะเป็นรุ่นใหม่ ไม่ต้องใช้สิทธิ์ผู้ดูแล

**ทางมือ:** ปิด Aetox โหลด
[zip รุ่นล่าสุด](https://github.com/Mikedev115/Aetox/releases/latest/download/aetox-windows-amd64-portable.zip)
แล้วแตกทับโฟลเดอร์เดิม ต้องได้**ทั้งสองไฟล์** จากรุ่นเดียวกัน เอาแค่ `aetox.exe` ไฟล์เดียวไม่ได้ ตัวหน้าต่างกับ engine
ต่างรุ่นกันคุยกันไม่รู้เรื่อง

### Microsoft Store

Windows อัปเดตให้เอง แอปไม่โหลดอะไรเอง ถ้ายังไม่ได้รุ่นล่าสุด ปิด Aetox แล้วไปที่
**Microsoft Store › ไลบรารี › รับการอัปเดต** รุ่นใหม่ถึง Store ช้ากว่า GitHub ได้ถึงหนึ่งวัน เพราะไมโครซอฟท์ตรวจก่อนปล่อย

### Scoop

```powershell
scoop update aetox
scoop update aetox-cli   # ถ้าลงคอนโซลไว้ด้วย
```

manifest ของ Scoop ตามหลังหน้า Releases ไม่กี่ชั่วโมงหลังรุ่นออก ถ้า `scoop update` ยังบอกว่าเป็นรุ่นล่าสุด ลองใหม่ทีหลัง

## ข้อมูลไม่หายตอนอัปเดต

แชต ความจำ คีย์ ผู้ให้บริการ และการตั้งค่าอยู่ใน `%APPDATA%\Aetox` ไม่ได้อยู่ในโฟลเดอร์โปรแกรม
ทุกช่องทางข้างบนแทนแค่ตัวโปรแกรม ยกเว้น Store ที่ Windows ให้โฟลเดอร์ข้อมูลแยกของตัวเอง
**อย่าย้ายช่องทางไปมา** (เช่น จากตัวติดตั้งไป Store) ถ้าไม่จำเป็น เพราะข้อมูลจะไม่ตามไปเอง

## อัปแล้วไม่ขึ้น: ไล่ตามอาการ

| อาการ | ทำไม | ทำอะไร |
|:---|:---|:---|
| กดรีสตาร์ทแล้วแอปกลับมาเป็นรุ่นเดิม การ์ดขึ้น **พร้อมแล้ว** อีก | ตัวติดตั้งถึง 1.9.8 ข้ามไฟล์ `aetox.exe` ไปเงียบ ๆ ถ้ามีโปรแกรมอื่นเปิดค้างไว้ แก้แล้วใน [1.9.9](release-notes/v1.9.9.md) | ปิด Aetox ให้หมด (ดูใน Task Manager ว่าไม่มี `aetox.exe` เหลือ) แล้วรันตัวติดตั้งรุ่นล่าสุดเองตาม**ทางมือ**ข้างบน |
| การ์ดบอกว่าหน้าต่างขอสิทธิ์ผู้ดูแลถูกยกเลิก | กด No หรือปิดหน้าต่าง UAC | กดรีสตาร์ทอีกครั้ง แล้วกด **Yes** |
| การ์ดบอกว่าตัวติดตั้งจบด้วยรหัสตัวเลข | ตัวติดตั้งเขียนไฟล์ไม่ได้ ไม่มีอะไรถูกเปลี่ยน | ปิด Aetox ให้หมดแล้วลองรีสตาร์ทใหม่ ไม่หายก็ใช้ทางมือ |
| **ไม่ได้รับข้อมูลเลยนาน 60 วินาที** | เน็ตหลุดระหว่างโหลด | กด **ลองอีกครั้ง** โหลดใหม่ตั้งแต่ต้น ไม่มีอะไรเสียหาย |
| **อัปเดตไม่สำเร็จ** อื่น ๆ | ข้อความต่อท้ายบอกเหตุ | รุ่นที่ใช้อยู่ยังครบ ใช้ต่อได้ ลองอีกครั้ง หรือใช้ทางมือ |
| ไม่มีการ์ดเลยทั้งที่มีรุ่นใหม่ | ตรวจไม่สำเร็จ (แอปเงียบไว้) หรือปิดการตรวจไว้ด้วย `AETOX_DISABLE_UPDATE_CHECK` | กด **ตรวจหาการอัปเดต** ในหน้าเกี่ยวกับ Aetox จะเห็นเหตุผล |
| Windows Defender กักไฟล์หลังอัปเดต | คำตัดสินผิดของ Defender กับไฟล์ใหม่ | ทำตามย่อหน้า Windows Defender ใน [README › ติดตั้ง](../README.th.md#ติดตั้ง) แล้ว[แจ้งปัญหา](https://github.com/Mikedev115/Aetox/issues) |

ยังไม่หาย: **การตั้งค่า › เกี่ยวกับ Aetox › แจ้งปัญหา** แอปกรอกรุ่น ระบบ และบันทึกล่าสุดให้ คุณเห็นทุกบรรทัดก่อนส่ง

## English summary

Check **Settings › About Aetox** for your version and install channel. The app looks for a new release about 20 s
after it opens and daily after that, and shows a card; nothing downloads until you press it, and every file is
signature- and hash-checked before use.

- **Installer:** *Download* → *Restart to update* → press **Yes** at the Windows admin prompt; the app reopens on
  the new build. Manual way: close Aetox and run the
  [latest installer](https://github.com/Mikedev115/Aetox/releases/latest/download/aetox-amd64-installer.exe) over it.
- **Portable zip:** *Download* swaps both exes in place; the next launch is the new build. Manually, extract the
  latest zip over the folder — both files, always from the same release.
- **Microsoft Store:** Windows updates it (Store › Library › Get updates).
- **Scoop:** `scoop update aetox` (and `aetox-cli`).

Your data lives in `%APPDATA%\Aetox` and survives every update. If a restart brings back the same build
(installers up to 1.9.8 could silently skip a held `aetox.exe`; fixed in 1.9.9), close Aetox completely and run the
latest installer yourself.
