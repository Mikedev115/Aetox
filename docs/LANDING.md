ตั้งแต่ **11 ก.ย. 2026** หน้าเว็บอยู่ที่ [Mikedev115/aetox-landing](https://github.com/Mikedev115/aetox-landing)
(Next.js ส่งออกเป็นไฟล์นิ่ง → GitHub Pages ที่ <https://mikedev115.github.io/aetox-landing/>)

เหตุผลที่แยก: คนที่ fork แอปไม่ควรได้เว็บการตลาดกับ `node_modules` ติดไปด้วย,
เว็บควรปล่อยได้โดยไม่ต้องผ่าน CI ของ Go สามแพลตฟอร์ม, และป้ายเวอร์ชันบนเว็บ
อ่านจาก GitHub Releases ตอน build ได้เอง — เลขรุ่นจึงหายไปจากรายการ "ต้องแก้หลายที่"

## สิ่งที่ยังอยู่ในโฟลเดอร์นี้ และทำไม

| ไฟล์ | ทำไมยังอยู่ |
|---|---|
| `index.html` | หน้า redirect ไปเว็บใหม่ — ลิงก์เก่าใน README/โพสต์/Store ไม่ตาย |
| `privacy.html` | **ห้ามย้าย** — URL นี้จดทะเบียนไว้กับ Microsoft Store (Partner Center) เว็บใหม่ลิงก์กลับมาที่นี่ |
| `case-studies/` | หน้าเว็บที่ Aetox สร้างจริง เว็บใหม่ลิงก์มา |
| `assets/*.png` | README ทั้งสองยังใช้รูปเหล่านี้ · `og.png` เป็นภาพ preview ของลิงก์เก่าที่เคยแชร์ไป |
