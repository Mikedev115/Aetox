# 🧩 Aetox v1.9.4

รุ่นนี้ให้แชทส่งข้อความหากันตาม ID เพิ่มศูนย์บัญชาการพร้อมงานตั้งเวลา และทำให้เห็นทั้งโมเดลกับเอเจนในแอปชัดขึ้น
หน้าโค้ดส่งขึ้น ดึงลง และเปิด worktree ได้จากหน้าต่างเดียวกัน
ส่วนงานจูนวงทำงานรับการซ่อมที่พิสูจน์ได้สองจุด พร้อมเผยแพร่ผลทดลองที่ยังมีคะแนนตกครบตามจริง

## แชทคุยข้ามเซสชันได้ด้วย ID

**เดิม** แชทแต่ละห้องถือบริบทของตัวเอง การส่งเรื่องจากห้องหนึ่งไปอีกห้องต้องคัดลอกเอง
**รุ่นนี้** คัดลอก ID ข้างชื่อแชท จากเมนูแชท หรือหัวช่องตอนแบ่งจอ แล้วบอกเอเจนในอีกแชทให้ถามหรือแจ้งเรื่องไปหาได้

- ผู้ส่งใช้เครื่องมือ `chat` ดูรายการและส่งข้อความ ผู้รับได้รับข้อความระหว่างทำงาน หรือเปิดเทิร์นเองเมื่อว่าง
- ทุกข้อความบอกต้นทาง ปลายทาง เวลา และชนิด: ถามเพื่อรับคำตอบหนึ่งครั้ง แจ้งให้รู้ หรือคำตอบของคำถามที่ยังรออยู่
- คำตอบรับได้เฉพาะเมื่อมีคำถามค้าง จึงไม่วนตอบรับหรือขอบคุณต่อกัน
- ประวัติและไฟล์ส่งออกเก็บที่มาของข้อความ เปิดแชทกลับมาแล้วผู้รับอ่านกรอบข้อความเดิมได้
- ลูกมือไม่มีสิทธิ์ส่งข้ามแชท และโหมดวางแผนดูรายการได้อย่างเดียว

แชทที่ปิดอยู่ในโปรเจกต์อื่นต้องเปิดก่อน ระบบยังไม่ปลุกมันเข้าโฟลเดอร์ของโปรเจกต์ปัจจุบัน

## ศูนย์บัญชาการ: ดูทุกแชท สั่งงานบนเว็บ และตั้งเวลา

**เดิม** หน้าเว็บบนเครื่องใช้ตั้งค่าองค์กรและมีมือถือจำลองคุยกับเลขา
**รุ่นนี้** หน้า `:8317` เป็นศูนย์บัญชาการของ Aetox เปิดได้จากปุ่มบนแถบบนและหน้าตั้งค่า

- กระดานงานรวมแชทที่กำลังทำงาน ชิ้นงาน และสถานะขององค์กร
- เปิดแชทเดิม เริ่มแชทใหม่ ส่งข้อความ และหยุดงานจากเว็บได้เมื่อเปิดสวิตช์ให้หน้าเว็บสั่งงาน
- งานตั้งเวลามีแชทประจำของตัวเอง ทำขณะ Aetox เปิดอยู่ รอบที่พลาดทำครั้งเดียวเมื่อเปิดแอปกลับมา
- เลขาตั้งงานได้จากบทสนทนา โดยการสร้างงานที่ทำต่อภายหลังต้องขออนุญาตทุกโหมด
- เปิดประตู Wi-Fi แล้วจับคู่เครื่องอื่นด้วยโค้ดจากแอป ถอนเครื่องที่จับคู่ไว้ได้

ค่าเริ่มต้นรับเฉพาะบนเครื่องและปิดการสั่งงานจากเว็บ การอนุมัติ คีย์ และผู้ให้บริการยังจัดการในแอป
งานตั้งเวลานี้เป็นบทสนทนาของ Aetox การสั่งรันเวิร์กโฟลว์และอ่านผลของ n8n หรือ Windmill ยังไม่มี

## เปิดปิดโมเดลรายตัว และดูสมองของทั้งทีม

**เดิม** ปุ่มท้ายแถวโมเดลสลับแชทไปใช้ตัวนั้น ส่วนการตั้งโมเดลลูกทีมอยู่คนละหน้า
**รุ่นนี้** ปุ่มท้ายแถวเป็นสวิตช์ว่าจะให้โมเดลอยู่ในเมนูเลือกหรือไม่ เปิดได้หลายตัวและไม่เปลี่ยนโมเดลของแชทที่ใช้มันอยู่

- ดาวเป็นรายการโปรด แยกจากสวิตช์เปิดปิด และจำสถานะหลังปิดแอป
- ค้นจากข้อมูลทุกโมเดล แต่แบ่งหน้าต่างของแถวที่วาด รายชื่อใหญ่ไม่สร้างทุกสวิตช์พร้อมกัน
- แผงตั้งระดับคิดและบริบทลอยใต้ปุ่ม ไม่ดันรายการให้เลื่อน ช่องบริบทว่างใช้ค่าจาก catalog
- หน้า **เอเจน › ภาพรวม** แสดงหน้า ยศ จำนวน ใครมอบงานให้ใคร และไฟล์ที่ต้องดู
- บอกค่าใช้ตามแชทครั้งเดียว แสดงตัวที่ตั้งแยก และแก้หรือคืนโมเดลในแถวโดยเก็บข้อมูลอื่นของเอเจนไว้

## Git ส่งขึ้น ดึงลง ดูกราฟ และเปิด worktree ได้

**เดิม** หน้า Git ดูไฟล์ที่เปลี่ยน คอมมิต และอ่านประวัติได้ แต่ไม่มีทางส่งหรือรับคอมมิตจาก remote
**รุ่นนี้** มี fetch, pull, push สถานะนำหน้าและตามหลัง ตำแหน่ง remote และคอมมิตที่ยังไม่ส่งบนกราฟสาขา

- ดึงแบบ fast-forward ก่อน ถ้าสาขาแยกทางจึงให้เลือก rebase หรือ merge ไม่มีการบังคับส่งทับ
- ดู worktree ของรีโป เปิดอีกโฟลเดอร์ หรือสร้าง worktree จากสาขาใหม่และสาขาที่มีอยู่
- โปรเจกต์ที่เปิดในโฟลเดอร์ย่อยของรีโปหรือ linked worktree มีหน้า Git และชื่อสาขาถูกต้อง
- แก้วันของคอมมิตที่ซ้ำจนไทมไลน์ค้าง และชื่อโฟลเดอร์ใหม่ที่เคยว่าง
- การเขียนข้อความคอมมิตแยกกลุ่มบอกว่ากำลังเขียนหรือรอคิว พร้อมเวลารอ กลุ่มที่โมเดลเงียบจบด้วยเหตุผลแล้วเดินต่อ และลองใหม่ได้

## วงทำงานโค้ด: ซ่อมสองจุดและเก็บผลทดลองครบ

**เดิม** `did **not** complete` หลุดตัวตรวจงานไม่เสร็จ และโฟลเดอร์ที่เริ่มว่างอาจถูกจำว่าไม่ใช่โปรเจกต์ตลอดเซสชัน
**รุ่นนี้** อ่านคำปฏิเสธผ่านตัวหนาได้ และหลังสร้าง `package.json` หรือ `go.mod` กลไกตรวจโค้ดกลับมาทำงาน

ทดลองทิศทางงานโค้ด 120 รันบน Luna และ Terra ด้วยซอร์สตรึง เก็บเฉพาะสองการซ่อมนี้
พรอมป์ต์ทดลองและการขยายรูปประโยคไม่ดีขึ้นสม่ำเสมอจึงถอดคืน รายงานเก็บงานหลายเทิร์นที่ Luna เหลือ 106/205 ไว้ครบ
ผลนี้ยังไม่พิสูจน์ว่าทั้งรุ่นดีที่สุด ดีขึ้นโดยรวม หรือไม่มีการถอยหลัง และคะแนนคู่เทียบเดิมไม่ใช่การวัดพร้อมกัน
อ่านวิธีวัด ผลดิบ และข้อจำกัดที่ [รายงานทิศทางงานโค้ด](../reports/harness-direction-2026-09-30.md)

เทสต์ที่เพิ่มตรวจการส่งงานกลับผ่านวงจริง การรู้จัก workspace หลังสร้างโปรเจกต์ การบันทึกสวิตช์พร้อมกัน
การค้นรายการโมเดลขนาดใหญ่ การส่งและรับ Git กับ remote จริง และการเดินทุกคำสั่ง `chat` ผ่านทะเบียนเซสชัน

## อื่น ๆ ในรุ่นนี้

- รับ Base URL ของ Anthropic แบบไม่มี `/v1` ตามคู่มือ SDK และแสดงสวิตช์คิดของปลายทาง Messages API ที่เพิ่มเอง
- เพิ่ม 9Router เป็นผู้ให้บริการของตัวเอง รายการและความสามารถอ่านจากปลายทางจริง พร้อมการ์ดตั้งค่าสามขั้น
- การ์ดติดตั้ง เปิดเซิร์ฟเวอร์ และตรวจโมเดลใช้กับ LM Studio และ Ollama ด้วย
- คำขอแบบไม่สตรีมระบุ `stream: false` ป้องกันเกตเวย์ส่ง SSE กลับมาทางตัวอ่าน JSON
- แถบล่างแยกการใช้ CPU ของคำสั่ง LSP เอนจิน และหน้าจอระหว่างทำงาน
- เก็บสวิตช์ Agent/Editor เป็นแท็บเล็กได้ พร้อมจำสถานะการพับและแสดงว่างานกำลังทำหรือรอคำตอบ
- ค้นประวัติด้วยคำหนึ่งหรือสองตัวอักษรได้ และตัวละครเก็บขีดล่างในชื่อไฟล์อย่าง `id_ed25519`
- ใช้กุญแจ SSH เพื่อ deploy ได้โดยไม่เปิดอ่านกุญแจ พร้อมถามก่อนเข้าถึงเครื่องอื่นและเลือกไว้ใจเครื่องนั้นได้
- ผู้ให้บริการ Gemini/Antigravity ไม่รับ enum ที่มีค่าว่าง จึงตัดค่าว่างออกจาก schema ที่ส่งไป
- OpenCode ส่งโมเดลไป API ตามประตูที่ catalog ของเขาระบุ
- อัปเดต README และคู่มือไทย อังกฤษ จีนให้ตรงกับหน้าตั้งค่าใหม่
