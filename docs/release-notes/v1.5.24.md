# 🔐 Aetox v1.5.24

รุ่นนี้ปิดช่องว่างฝั่งเครื่องมือ **Git** ครบวงจร — ตั้งแต่ป้องกันความลับหลุดก่อน commit
ไปจนถึง AI ช่วย review โค้ดและร่าง PR description — พร้อม **Skills** บันเดิลสี่ตัวและ
ระบบ **Habits** ที่เรียนรู้รูปแบบการทำงานของคุณโดยอัตโนมัติ

---

## 🔒 Git Security — ป้องกันไฟล์ความลับก่อน commit

- ตรวจจับไฟล์อันตราย (`.env`, private keys, `credentials.json`, `.pem`, `.key`, ฐานข้อมูล, executables ฯลฯ) และเตือนก่อนที่จะ commit
- แสดง badge เตือนบนหน้า Git และบน split-commit group ทันทีที่มีไฟล์อันตรายอยู่ในกลุ่ม
- Split-commit AI จะ **ไม่เสนอไฟล์อันตราย** ให้เลือกโดยอัตโนมัติ — ผู้ใช้ต้องเปิดใช้เองถ้าตั้งใจ
- ปุ่ม "ถามผู้ช่วย" แสดง reason ของแต่ละไฟล์เป็นภาษาที่ตั้งค่าไว้ (th/en/zh)
- `gitSecurity.ts` รองรับ path ทั้งแบบ `/` และ `\` — แก้บั๊คที่ Windows path ไม่ match pattern

## 🤖 AI Git — คอมมิตและ PR อย่างชาญฉลาด

- **AI Smart Split** (`GitSuggestSplitCommits`) วิเคราะห์ working tree และแบ่งไฟล์เป็นกลุ่ม commit ที่เล็กที่สุด พร้อม commit message แต่ละกลุ่ม
- **AI Commit Message** (`GitSuggestCommitMessage`) สร้างข้อความ commit จาก diff จริง
- **AI PR Description** (`SuggestPRDetails`) ร่าง title + description จาก commits ตั้งแต่ branch แยกออกมา
- **AI Code Review** (`ReviewPullRequest`) วิเคราะห์ diff ของ PR และแสดง feedback แบบ inline

## 🧠 Skills — bundled skills สี่ตัว

Skills ของ Aetox สี่ตัวถูกฝังมาพร้อมแอปแล้ว ไม่ต้องติดตั้งแยก:

| Skill | หน้าที่ |
|:--|:--|
| **aetox-forge** | TDD-first implementation — เขียนเทสก่อน แล้วค่อยสร้างโค้ด |
| **aetox-grill** | Stress-test แผนก่อนลงมือ — ตั้งคำถามจนไม่มีข้อกำกวม |
| **aetox-slice** | แตกสเปกเป็น tickets ที่วิ่งขนานกันได้ พร้อม DAG |
| **aetox-spec** | สังเคราะห์การตัดสินใจออกแบบให้เป็น SPEC/RFC อย่างเป็นทางการ |

รองรับ `op=create` — สร้างโฟลเดอร์และไฟล์ SKILL.md ใหม่จากใน Settings ได้เลย

## 💡 Habits — เรียนรู้รูปแบบซ้ำๆ ของคุณ

- คำนวณจากฐานข้อมูลล้วนๆ **ไม่ใช้ LLM** — เร็ว ไม่กินโควตา
- ตรวจจับคำสั่งที่คุณสั่งซ้ำใน ≥ 2 เซสชัน และเสนอทำเป็น Skill หรือ starter card
- **Habit synthesis pipeline** วิเคราะห์และเสนอ skill/memory ให้โดยอัตโนมัติ
- กด dismiss ได้ ถ้าไม่ต้องการเห็นอีก หรือ restore กลับมาได้ทุกเมื่อ
- ตาราง `ignored_habits` เก็บรายการที่ dismiss ไว้อย่างถาวร

## 🧬 Memory — จัดการความจำข้ามขอบเขต

- `AddLearnedEntry` — เพิ่มความจำใหม่เข้า USER.md หรือ MACHINE.md จากในแอป
- `MoveLearnedEntry` — ย้ายความจำระหว่าง scope (user ↔ machine) โดยไม่ต้องแตะไฟล์เอง
- ปรับ schema คำอธิบายให้ชัดขึ้น: `user` = ตัวตน/ความชอบ, `machine` = สภาพแวดล้อม/เครื่อง

## 🖥️ Workbench — badge และ tab ใหม่

- **Badge แจ้งเตือน** บน tab Git เมื่อมีไฟล์ที่แก้ค้างอยู่ และบน tab PR เมื่อมี PR ที่รอ review
- **Artifacts tab** — ดู Plan, Walkthrough, UI Mockups และ Media จาก session ปัจจุบัน
- **Inspector button** บน workbench header สำหรับเปิด codeStatus panel

## 📋 PR — filter และ UX ที่ดีขึ้น

- Filter open/closed PR ได้จากใน PRPane
- tag **Merged** แสดงบน PR ที่ merge แล้ว (icon แยกจาก Open/Closed)
- refresh spinner แสดงระหว่างโหลด
- `PullRequest` struct ได้ field `Merged` + icon `gitMerge`

## ⚙️ Settings — จัดการ Memory, Habits และ Quota

- **Memory editor** — ดู แก้ไข และเพิ่มความจำได้จาก Settings โดยตรง
- **Habits manager** — ดูรายการ habit และ dismiss/restore ได้ในที่เดียว
- **Antigravity quota** — แสดงโควตาที่เหลืออยู่จาก Antigravity API แบบ realtime

## 🔧 Prompt และ Subagent

- ปรับ identity, offering, coding mode และ plan stance ให้เป็น adaptive/design-tree
- `OpenAgentHome` เปิด home directory ของ agent โดยตรง
- cache quota ใน `providerAccount` เพื่อลด round-trip ไปยัง API

## 🐛 Bug Fixes

- **จอดำ** จาก Icon missing ใน Workbench — แก้แล้ว
- **overflow/clipping** ของ PR list + badge styles ที่ซ้อนกัน
- `git commit` — unquote worktree paths และปิด `quotepath` อัตโนมัติ เพื่อให้ path ที่มีตัวอักษรพิเศษ/ภาษาไทย commit ได้ถูกต้อง
- Browser upload ผ่าน `button/label` ที่ซ่อน file input — แก้ได้แล้ว
- Element labeling สำหรับ hidden file input ใช้ข้อความพิเศษแทน `hidden` ทั่วไป
