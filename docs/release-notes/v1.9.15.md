# 🧩 Aetox v1.9.15

รุ่นแก้งานมอบหมายกับหน้าตา: ทีมที่ยังไม่ได้แต่งตั้งบอกทางแทนที่จะปล่อยให้เลขาวน หน้าว่างของแผงขวาฝั่งโค้ดกับผู้ช่วย
เปลี่ยนเป็นหน้าต่างที่ทำงานจริง และโต๊ะโค้ดอ่านตัวหนังสือจากรูปในโปรเจกต์ได้

## ทีมที่ยังไม่ได้แต่งตั้ง บอกตรง ๆ ว่ายังไม่แต่งตั้ง และแต่งตั้งที่ไหน

**เดิม** ลูกค้าสร้างทีม "โปรแกรม" หัวหน้า boss แต่ไม่ได้แต่งตั้งให้เลขา คำสั่งมอบงานตอบ "no sub-agent named; available:" ว่าง ๆ
แล้วตามด้วย "every worker is switched off" เลขาเลยวนหาทางเปิดสิทธิ์เองอยู่ 50 รอบ 6 นาที

**รุ่นนี้**

- ถ้าชื่อทีม แผนก หรือบริษัทมีอยู่แต่ยังไม่ได้แต่งตั้ง คำตอบบอกชื่อ กับทางไปแต่งตั้ง
  (ตั้งค่า → ตัวหลัก → หัวนั้น → มอบงาน) และบอกว่าโมเดลทำเองไม่ได้
- รายชื่อลูกมือที่ว่างแยกสามกรณี: ยังไม่แต่งตั้ง · ยังไม่มีทีม · ปิดสวิตช์จริง
- prompt, `secretary.md` และสกิล aetox เลิกชี้ "สิทธิ์มอบงาน" ที่ไม่มีอยู่แล้ว
- ลำดับชั้น: seat หัวหน้าทีมชนะ `head_scope` ในไฟล์ (boss ไม่ขึ้นเป็นหัวหน้าบริษัทอีก)
- ห้องทำงาน: ขั้นที่ทีมยังไม่แต่งตั้ง ให้เลขาเตือนก่อนเริ่ม · ตัวนับ "แต่งตั้งแล้ว" นับแผนกกับบริษัทด้วย
- ท้ายหน้าทีมเลิกบอกว่าผู้ช่วยส่งงานด้วยชื่อทีม

## หน้าว่างฝั่งโค้ด: editor ที่โค้ดกำลังพิมพ์อยู่จริง

**เดิม** (1.9.14) เมืองโค้ดแบบไอโซเมตริก เจ้าของบอกว่าอ่านเป็นแค่กล่องกับเส้น ไม่อ่านว่าเป็นโค้ด

**รุ่นนี้** หน้าต่าง editor จาง ๆ เอียงหันข้าง กลางเป็นโค้ดพิมพ์ทีละตัว ซ้ายเป็นกราฟ Git ที่มี commit ใหม่ดันขึ้นบนสุดเมื่อพิมพ์จบ
ขวาเป็นแผนที่โปรเจกต์ ไฟล์ที่แก้ติดไฟ วนทุก 10 วินาที CSS ล้วน ลดการเคลื่อนไหวแล้วเห็นสิ่งที่แก้เสร็จแล้ว
ข้อมูลเป็นตัวอย่างคงที่ ไม่ใช่รีโปจริง

ไม่ได้ทำ: ให้โค้ดที่พิมพ์เป็นไฟล์ที่เพิ่งเปลี่ยนในโปรเจกต์จริง (เสนอไว้ เจ้าของยังไม่สั่ง)

## หน้าว่างฝั่งผู้ช่วย: หน้าต่างที่ค้นเว็บ เรียนรู้ จัดไฟล์ ทำสไลด์

**เดิม** โต๊ะทำงานไอโซเมตริกอ่านเป็นกล่องเหมือนเมืองโค้ด

**รุ่นนี้** มุมเดียวกับหน้าต่างโค้ด ซ้ายเป็นคำขอกับแผนสี่ขั้นที่ติ๊กตาม ขวาเปลี่ยนตามขั้น:
ค้นเว็บ → อ่านแล้วจด ("จำไว้แล้ว") → จัดไฟล์ในดาวน์โหลด → ทำสไลด์ จบด้วยการ์ด `.pptx` วนทุก 16 วินาที
ข้อความเป็นตัวอย่างคงที่ ไทยบนจอไทย อังกฤษบนจออื่น ประตูทีมยังเป็นเงาบริษัท

## โต๊ะโค้ดกับ editor อ่านตัวหนังสือจากรูปได้

**เดิม** โต๊ะโค้ดไม่ถือหมวดสื่อ (ยกเว้น `image_make`) เอเจนดึงข้อความจากภาพออกแบบหรือภาพจอในโปรเจกต์ไม่ได้

**รุ่นนี้** เพิ่ม `image_ocr` ให้โต๊ะโค้ดและ editor เฉพาะ action รูปภาพ `video_ocr` กับ `audio_transcribe` ยังไม่เปิด

ไม่ได้ทำ: เปิดทั้งหมวดสื่อให้โต๊ะโค้ด
