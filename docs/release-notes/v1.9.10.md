# 🧩 Aetox v1.9.10

รุ่นนี้ทำให้ผลงานวิดีโอไม่จบแค่ไฟล์ MP4: เอเจนกับคนเปิดและแก้ไฟล์ `.cut` เดียวกันในห้องตัดได้
หน้าแชทมีชุดคำสั่งแยกตามโต๊ะ เสียงไทยอ่านคำอังกฤษรู้เรื่องขึ้น และหน้า MCP เพิ่ม PowerPoint ได้จากปุ่มเดิม

## ห้องตัดที่แก้ต่อด้วยมือได้จริง

**เดิม** งานตัดและประกอบคลิปผ่าน kinocut จบที่ผลเรนเดอร์ คนไม่มีห้องที่เปิดงานเดิมแล้วแก้ต่อร่วมกับเอเจนได้

**รุ่นนี้**

- ไฟล์ `.cut` เก็บคำ วลี รอยตัด และเทคที่พับไว้ ตัดตามคำพูด ย่อช่วงเงียบ คืนรอยตัด และแก้คำที่ถอดผิดได้
  ต้นฉบับไม่ถูกเขียนทับ
- งานสตูดิโอประกอบซีนใต้เสียงพากย์ผ่าน `cut assemble` อ่านซับจาก `.srt` และเทียบความยาวซีนกับย่อหน้า
  เพลงหลบเสียงพูด และผลเรนเดอร์รายงานความดังที่วัดจากไฟล์
- ห้องตัดมีไทม์ไลน์หลายแทร็ก คลังไฟล์ในโปรเจกต์และคลังสตูดิโอ ตัวเล่นสด ภาพซ้อน เสียง ข้อความ ซับ และคำ
  ลากวาง ย้าย ตัดขอบ แยก ทำซ้ำ ลบ ย้อนกลับและทำซ้ำได้
- ดับเบิลคลิกคำหรือซับเพื่อแก้ด้วยมือ ปรับตำแหน่ง ขนาด หมุน ความทึบ ครอป พลิก ความเร็ว เฟดเสียง และสีของคลิป
  ใส่ข้อความและทรานสิชันได้จากแผงปรับแต่ง
- คีย์เฟรมสำหรับตำแหน่ง ขนาด การหมุน ความทึบ และระดับเสียง หยุดภาพ ลากปรับบนจอเล่น และเลือกความละเอียดกับเฟรมเรตส่งออก
- ห้องว่างเลือกไฟล์ `.cut` ในโปรเจกต์ได้เอง การเปิดไฟล์ชนิดนี้พาเข้าห้องตัดแทน JSON ดิบ
  แอปจำไฟล์ของแต่ละแชตข้ามหน้าต่างและการรีสตาร์ท
- editor ใช้ `cut` กับ ffmpeg แทน kinocut แอปลบเฉพาะรายการ MCP kinocut ที่แอปเคยสร้างเอง
  ไม่ลบโฟลเดอร์เครื่องมือหรือรายการที่ผู้ใช้ตั้งไว้เอง

ข้อจำกัดที่ยังอยู่: ไม่มี green screen, mask, blur หรือ motion tracking ใน `cut`
และตัวส่งออก FCPXML เดิมยังอ่าน Cutfile รูปแบบเก่า ไม่ใช่ไฟล์ `.cut` ใหม่นี้
ไฟล์ใหม่แก้ต่อในห้องตัดของ Aetox ได้ แต่ไม่เคลมว่าส่งไป Resolve หรือ Premiere ได้แล้ว

## ชุดคำสั่งของโต๊ะที่กำลังนั่ง

**เดิม** การ์ดหน้าแชทกับชุดคำสั่งเป็นคนละรายการ และสูตรไม่บอกว่าต้องใช้โต๊ะไหนหรือเริ่มด้วยการวางแผน

**รุ่นนี้**

- หน้าแชทเปล่า เมนู `/` และช่องส่งข้อความใช้รายชื่อชุดเดียวกัน ผู้ช่วย โค้ด และเลขาเห็นสูตรของโต๊ะตัวเองก่อน
  เลือกสูตรของโต๊ะอื่นแล้วมีทางย้ายข้อความไปโต๊ะนั้น
- ชุดคำสั่งกำหนดชื่อบนหน้าแชท โต๊ะ ไอคอน ชั้นผลงาน และการเริ่มในท่าทีวางแผนได้จากตัวแก้ไข
  ส่วนหัวเหล่านี้ไม่ถูกส่งเป็นเนื้อพรอมต์ให้โมเดล
- สูตรงานนักพัฒนา ระบบธุรกิจ เบราว์เซอร์ เอกสาร ผู้ช่วยและเลขา พร้อมปกจากตัวอย่างสไตล์กระจก
  งานกรอกฟอร์ม ซื้อของ เผยแพร่ หรือใช้เงินยังหยุดรอคำสั่งผู้ใช้
- `/podcast` ค้นหลายแหล่งแล้วพาทำพอดแคสต์ภาษาไทยใน NotebookLM ผ่านเบราว์เซอร์
  หยุดให้ผู้ใช้เข้าสู่ระบบเอง ไม่แชร์หรือยอมรับเงื่อนไขแทน
- สกิล `aetox-glass` มีธีมร่วมสำหรับ HTML และ React กับคลังคอมโพเนนต์ MIT จาก 21st
  เก็บชื่อผู้เขียนและข้อกำหนดสัญญาอนุญาตไว้กับคลัง

## เสียงไทยไม่สะกดคำอังกฤษทีละตัว

**เดิม** ปุ่มฟังอ่านชื่อฟังก์ชัน พาธ ตัวย่อ และคำอังกฤษบางคำเป็นตัวอักษร ทั้งที่เสียงพากย์ใช้เสียงเดียวกัน

**รุ่นนี้** ชั้นจัดข้อความก่อนอ่านใช้ร่วมกันระหว่างปุ่มฟัง อวตาร ไกด์ และเสียงพากย์
พาธเหลือชื่อไฟล์ ชื่อฟังก์ชันแยกคำ หน่วย เวอร์ชัน ช่วงตัวเลขและเครื่องหมายอ่านเป็นคำไทย
คำอังกฤษใช้คลังคำไทยร่วมกับเสียงอ่านจาก CMU Pronouncing Dictionary และผู้ใช้เพิ่มคำอ่านเองได้
ประโยคอังกฤษที่ควรอ่านเป็นอังกฤษยังปล่อยไว้ ไม่แปลงทุกอย่างเป็นไทย

การถอดเสียงในเครื่องด้วย faster-whisper อ่านผลจาก JSON UTF-8 แทน stdout ที่อาจใช้รหัสอักษร Windows
เมื่อ CUDA/cuBLAS/cuDNN ใช้ไม่ได้จะลอง CPU int8 และจำทางนี้ในเอนจิน
โมเดลเริ่มต้นเปลี่ยนเป็น `small` และบอกขนาดดาวน์โหลดในหน้าเสียงตามจริง
ความผิดพลาดที่ CLI พิมพ์แม้จบด้วยรหัส 0 ถูกแจ้งเป็นข้อผิดพลาด ไม่ใช่ผลถอดเสียงว่าง
ไม่สลับไปผู้ให้บริการถอดเสียงอื่นเอง

## PowerPoint อยู่บนหน้า MCP

**เดิม** คนที่อยากให้เอเจนสร้างหรือแก้ `.pptx` โดยตรงต้องหาชื่อแพ็กเกจและเพิ่มเซิร์ฟเวอร์เอง

**รุ่นนี้** หน้า MCP มี `powerpoint` ในหมวดบนเครื่องนี้ กดเพิ่มผ่านปุ่มเดิมได้
ใช้เซิร์ฟเวอร์ชุมชนของ [sbroenne](https://github.com/sbroenne/mcp-server-powerpoint) ซึ่งควบคุม PowerPoint จริง
สร้างสไลด์ กราฟ ตาราง SmartArt ใช้เทมเพลต และส่งออกภาพให้ตรวจเลย์เอาต์ได้

ต้องมี Windows, PowerPoint desktop รุ่น 2016 ขึ้นไป และ Node.js 18 ขึ้นไป
การเพิ่มนี้ไม่ติดตั้ง Office หรือสกิลต้นทาง ไม่เชื่อมต่อให้ทุกคนอัตโนมัติ และยังไม่ได้ทดลองแก้ไฟล์จริงในรอบนี้
จึงไม่ใส่จำนวนเครื่องมือหรือราคาโทเคนที่ยังไม่ได้วัด

## อื่น ๆ ในรุ่นนี้

- เปิดแชตตรงของเอเจนกลับมาแล้วประกอบเอนจินจากเก้าอี้ของแชตนั้น ไม่หยิบเก้าอี้ของแชตที่กำลังจะออก
- tester และ dev เป็นของโต๊ะโค้ดตามค่าเริ่มต้น สำเนาลูกมือในเครื่องไม่ล้างข้อจำกัดหัวของโปรไฟล์ที่มากับแอป
- หน้าเอเจนทั้งหมดตั้งหรือล้างโมเดลรายตัวได้ และแถวยศไม่บอกว่าใช้ตามแชตเมื่อทุกตัวตั้งเอง
- เพิ่มพจนานุกรมตัดคำไทยเพื่อให้ขอบซับและขอบตัดไม่อยู่กลางคำ พร้อมข้อมูลเวลาภายในวลีจากตัวถอดเสียงที่รองรับ
- เทสต์ที่เพิ่มหรือขยายครอบคลุมไฟล์ `.cut` แทร็ก คุณสมบัติคลิป คีย์เฟรม หยุดภาพ ประกอบซีน
  ห้องตัดฝั่งหน้าจอ ชุดคำสั่ง การอ่านเสียง และ GPU fallback ของ faster-whisper
  รวมเทสต์ preset PowerPoint ใน `capabilityRoom.test.ts`

การตรวจในรอบเตรียมรุ่นนี้: เทสต์ความตรงกันของเวอร์ชันและตัวตรวจลิงก์รายงานผ่าน
ไม่ได้รันสวีตซ้ำในเครื่องตามกติกาปล่อยรุ่น; `go vet` และ `svelte-check` ที่ตรวจความพร้อมก่อนหน้านี้หมดเวลา 120 วินาที
จึงไม่ใช้เป็นหลักฐานว่าผ่าน สวีต Go ของไฟล์ที่ปล่อยจริงเป็นด่านบังคับใน workflow รุ่นนี้
