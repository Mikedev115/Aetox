# Aetox v1.9.19

วันที่ 8 ตุลาคม 2026

**เนื้อหาพรอมป์ต์สำเร็จรูปที่แอปแถมทั้ง 72 ชุดเป็นภาษาอังกฤษแล้ว** โดยคงชื่อการ์ดและ metadata ภาษาไทย รวมทั้งค่าที่คุณส่งผ่าน `$ARGUMENTS` ไว้ รุ่นนี้ยังเพิ่มสถานะและการยกเลิกการบีบอัดบริบท เปิดไฟล์จากแผนที่คลังความรู้ และคงหน้าเบราว์เซอร์กับเทอร์มินัลเมื่อสลับแชท

รวมการเปลี่ยนแปลงของ v1.9.18 ที่ยังไม่ได้เผยแพร่ให้ผู้ใช้ด้วย

## พรอมป์ต์สำเร็จรูป

- เปลี่ยนเนื้อหาคำสั่งที่ส่งให้โมเดลของพรอมป์ต์แถมทั้งหมดเป็นภาษาอังกฤษ ไม่ใช่เฉพาะชุด `admin`
- คงชื่อชุดคำสั่ง ชื่อการ์ด ภาพปก โต๊ะ และท่าทีที่กำหนดไว้ ไม่เปลี่ยนภาษาของหน้าจอทั้งแอป
- คงข้อกำหนดเดิมของแต่ละงาน รวมทั้งข้อที่ระบุให้สร้างผลลัพธ์เป็นภาษาไทย
- ไม่เขียนทับชุดคำสั่งที่ผู้ใช้บันทึกเอง และยังรับอาร์กิวเมนต์ภาษาไทยได้ตามเดิม

## บริบทและการบีบอัด

- แสดงสถานะระหว่างบีบอัดบริบท และให้ยกเลิกงานบีบอัดที่กำลังทำได้
- แยกบัญชีบริบทโปรเจกต์จากคำสั่งระบบ เพื่อดูว่าส่วนใดใช้พื้นที่บริบท
- มิเตอร์เลือกข้อมูลของบทสนทนาหลักและโมเดลปัจจุบัน ไม่ปนข้อมูลของลูกมือหรือโมเดลที่ใช้ก่อนหน้า
- อธิบายค่าประมาณหลังบีบอัดหรือเปิดแชทกลับมาใหม่ โดยไม่ใช้ข้อมูลแคชจากคำขอเก่ามาอธิบายยอดปัจจุบัน

## คลังความรู้และแผนที่สมอง

- อ่านไฟล์จากคลังความรู้ที่เชื่อมไว้ และนำข้อมูลที่เกี่ยวข้องมาใช้กับงาน
- แตกโฟลเดอร์ในแผนที่เพื่อดูไฟล์ แล้วเปิดตัวอย่างไฟล์ในแอปได้
- ปรับจุดกดของแผนที่และใช้ข้อมูลร่วมกันระหว่างมุมมอง โดยไม่แก้ไฟล์ต้นฉบับในคลังที่เชื่อมไว้

## สลับงานและประวัติแชท

- พักหน้าเบราว์เซอร์และเทอร์มินัลเมื่อสลับแชทแทนการปิด เพื่อรักษาหน้าและเซสชันเดิมเมื่อกลับมา
- ประวัติแชทที่ยาวทยอยแสดงเฉพาะช่วงที่ใช้งาน แทนการวาดข้อความทั้งหมดพร้อมกัน
- กันหน้า dev ในแท็บเบราว์เซอร์ควบคุมหน้าต่างหลัก และคง Dock เมื่อมีเทอร์มินัลใช้งาน
- แยกข้อความแจ้งงานเบื้องหลังออกจากข้อความผู้ใช้ ไม่กินไฟล์แนบที่เตรียมไว้ส่งครั้งถัดไป
- แก้ข้อความแนบซ้ำ และรักษารายการงานที่มอบหมายเมื่อสร้างสถานะแชทกลับมาใหม่

## แนวทางเอเจนต์และการเชื่อมต่อ

- ย้ำว่าคำสั่งที่ผู้ใช้ตัดสินใจแล้วไม่ต้องถามยืนยันซ้ำ และไม่ขยายงานหรือสั่งบิลด์นอกขอบเขต
- ลดการมอบงานเกินจำเป็น และให้ผู้ช่วยทำงานเฉพาะจุดหรือที่ต้องใช้บริบทร่วมกันเองก่อน
- ย่อสกิลออกแบบให้เป็นทิศทางและขอบเขต ย้ายรายละเอียดอ้างอิงออกจากเนื้อหาหลัก และถอดสกิล glass กับสูตรที่ผูกอยู่กับสกิลนั้น
- คงความสามารถส่งออก PowerPoint ไว้ ไม่ได้ถอดฟีเจอร์จากการเปลี่ยนเทสต์ที่อิงโครงสกิลเดิม
- เพิ่มพรีเซ็ตและโลโก้ 21st.dev สำหรับค้นหาและติดตั้งคอมโพเนนต์ React ต้องตั้ง API key ของบัญชีผู้ใช้เอง งานสร้างด้วย AI ขึ้นกับสิทธิ์บัญชี
- ถอดข้อห้ามรหัสผ่านและ API key ออกจากคำอธิบายเครื่องมือเบราว์เซอร์ตามขอบเขตที่เจ้าของผลิตภัณฑ์กำหนด ไม่ได้ถอดข้อจำกัดข้อมูลบัตรและข้อมูลการเงินอื่น
