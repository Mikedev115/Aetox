# 🧩 Aetox v1.9.13

รุ่นเล็กที่เอาคำถามออกสองจุด: ตั้งรันเต็มที่แล้วแอปไม่ถามก่อนเอเจนเข้าโฟลเดอร์นอกโปรเจกต์อีก
และการ์ด "เครื่องมือ X ล้มซ้ำ" ที่เด้งขึ้นเองเลิกเด้งแล้ว

## รันเต็มที่ ไม่ถามก่อนเข้าโฟลเดอร์นอกโปรเจกต์

**เดิม** ตั้งระดับการอนุมัติเป็นรันเต็มที่แล้ว แต่ในโหมดโค้ดที่โฟกัสโปรเจกต์ไว้ พอเอเจนอ่านหรือแก้ไฟล์ที่อยู่
นอกโฟลเดอร์โปรเจกต์ การ์ด "งานนี้ต้องใช้ ... ซึ่งอยู่นอกโปรเจกต์ เพิ่มโฟลเดอร์นี้เข้าโปรเจกต์ไหม" ก็ยังขึ้น
และงานหยุดรอให้กดทุกครั้ง การ์ดนี้ไม่ได้ดูระดับการอนุมัติเลย จึงเป็นคำถามเดียวที่รันเต็มที่ยังถาม

**รุ่นนี้** ตอนรันเต็มที่ โฟลเดอร์นั้นเข้ารายการ "ไฟล์ที่จำเป็นต้องเข้าถึง" เอง แล้วงานเดินต่อทันที
รายการนี้ยังเป็นที่เดียวที่บอกว่าเอเจนเข้าถึงอะไรได้ เห็นได้ในเมนูโปรเจกต์ และเอาออกได้ทุกเมื่อ

ไม่ได้ทำ: โฟลเดอร์ที่เก็บรหัสผ่านและคีย์ (เช่น `.ssh`) ยังถูกปฏิเสธทุกโหมดเหมือนเดิม · ระดับถามก่อนและ
ถามเฉพาะคำสั่งเสี่ยงยังเห็นการ์ดเดิม · รันเต็มที่ไม่ได้แปลว่าเปิดทั้งเครื่อง

เทสต์ที่เพิ่มในรุ่นนี้: `TestWidenUnderFullAccessAddsWithoutAsking`

## เลิกเด้งการ์ด "เครื่องมือ X ล้มซ้ำ"

**เดิม** แอปสรุปความล้มเหลวของเครื่องมือเองแล้วเด้งการ์ดให้กด การ์ดขึ้นมาแล้ว 41 ใบ ถูกกดว่าไม่เป็นไร 38 ใบ
ค้างอยู่ 3 ใบ ส่วนใหญ่เป็นคำปฏิเสธที่บอกโมเดลว่าต้องทำอะไรต่อ ซึ่งแปลว่าเครื่องมือทำงานถูกแล้ว

**รุ่นนี้** ตัวสรุปนั้นถูกเอาออก การ์ดที่ค้างอยู่ถูกปิดให้เอง ความล้มเหลวทุกครั้งยังถูกบันทึกไว้เป็นหลักฐานเหมือนเดิม
