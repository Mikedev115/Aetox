# 🧰 Aetox v1.5.28

รุ่นนี้แก้ข้อความสไตล์ Go comment (`// …`) ที่โผล่ขึ้นเป็นข้อความจริงกลางหน้าแชท

---

## 💬 comment แบบ `//` ที่วางผิดระดับในไฟล์ Svelte ไม่หลุดออกจออีกต่อไป

**อาการที่เห็น:** ท่อนข้อความลักษณะ `// While a call is out the box holds the ROUND it
belongs to…` แสดงขึ้นในหน้าแชทเป็นข้อความตรง ๆ ซ้ำซาก และหมุนวนซ้ำชุดเดิม — ทั้งที่ควรเป็น
comment ในโค้ดเท่านั้น ผู้ใช้พบบนผู้ให้บริการ DeepSeek ทุกโมเดล

**ต้นเหตุ:** comment สองบล็อกใน `Chat.svelte` (โซนการพับแถวเครื่องมือของรอบ) เขียนด้วย
`//` ซึ่งเป็นสไตล์ comment ของ Go/JavaScript **แต่ถูกวางอยู่ระดับ markup ของ Svelte**
ตรงนั้น `//` ไม่ใช่ comment แต่เป็น text node จริง — Svelte จึงวาดทุกตัวอักษรออกจอ
และข้อความก้อนนี้ก็เลอะเข้าไปใน context ที่ส่งให้โมเดล ทำให้โมเดลตอบกลับมาเป็นข้อความ
ประเภทเดียวกัน (แม้ระดับความคิดจะตั้ง off ก็ตาม — ฝั่ง wire ของ `thinking:
{"type":"disabled"}` ทำงานถูกต้องตามเอกสารของ DeepSeek อยู่แล้ว ไม่ได้แตะแก้ในรุ่นนี้)

**ที่เปลี่ยน:** สองบล็อกนั้นกลายเป็น `<!-- … -->` ซึ่ง Svelte ตัดออกจากผลลัพธ์จริง
และตรวจกวาดทุกไฟล์ `.svelte` ในโปรเจกต์แล้ว — จุดอื่นที่เห็น `//` เป็น comment ใน
inline handler (`onkeydown`, `onchange`, `{@render}` ฯลฯ) ซึ่งถูกต้องอยู่แล้ว
ไม่มีจุดที่หลุดระดับ markup ค้างอยู่อีก

**การตรวจ:** `svelte-check` 0 errors (warnings เดิม 3 อันในไฟล์อื่นไม่เกี่ยวกับการแก้)
และชุดทดสอบ frontend ผ่านครบ 159 ไฟล์ / 1,533 เทสต์
