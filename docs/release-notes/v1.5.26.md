# 🔌 Aetox v1.5.26

## 🔌 OpenAI-compatible เป็นผู้ให้บริการเต็มตัว ไม่ใช่นามแฝงของ OpenAI อีกแล้ว

เดิมพิมพ์ `openai-compatible` หรือ `compatible` จะได้แถวของ OpenAI ทุกประการ — คีย์ของ OpenAI
base URL ของ OpenAI และไม่มีทางบอกว่าคุณอยากไปที่อื่น รุ่นนี้แยกมันออกมาเป็นแถวของตัวเอง:
**คุณใส่ base URL, API key และชื่อโมเดลเอง** ใช้กับ gateway หรือเซิร์ฟเวอร์ที่รันในเครื่อง
ที่พูดโปรโตคอล OpenAI (`/v1/chat/completions`, `/v1/models`) ได้ทั้งหมด

| | |
|:--|:--|
| ชื่อที่พิมพ์ได้ | `openai-compatible` · `custom-openai` · `custom` · `compatible` |
| Base URL เริ่มต้น | `http://localhost:8000/v1` |
| ตัวแปรสภาพแวดล้อม | `OPENAI_COMPATIBLE_API_KEY` · `CUSTOM_OPENAI_API_KEY` |
| Runtime | `RuntimeOpenAICompatible` — ตัวเดียวกับที่ `deepseek`, `kilo` และแถวอื่นใช้อยู่ |

### สิ่งที่ต้องรู้ก่อนอัปเกรด

**`compatible` และ `openai-compatible` ไม่ได้หมายถึง OpenAI อีกต่อไป** คำที่เคยเป็นทางลัดไปหา OpenAI
ตอนนี้ชี้ไปที่แถวใหม่ (base URL `localhost:8000`) คนที่ตั้งผู้ให้บริการไว้เป็น `openai` จากหน้าตั้งค่า
ไม่กระทบอะไร เพราะค่านั้นถูกบันทึกเป็นชื่อ canonical อยู่แล้ว (`SwitchProvider`) — ที่เปลี่ยนคือคนที่
พิมพ์นามแฝงนั้นตรงๆ เช่นรัน CLI ด้วย `--model-provider compatible`

### ในหน้าต่างเลือกผู้ให้บริการ

แถวใหม่มีไอคอนเป็นมาร์กของ OpenAI เพราะมันพูดโปรโตคอลเดียวกัน ไม่ใช่เพราะเป็นบริษัทเดียวกัน
และมันไม่มีลิงก์ "ไปขอคีย์จากที่นี่" — ปลายทางไม่ใช่เจ้าเดียวที่จะมีหน้าให้ลิงก์ได้
เทสต์ที่บังคับว่าทุกแถวที่ขอคีย์ต้องมีที่ไปเอา key จึงยกเว้นแถวนี้แบบระบุชื่อตรงๆ ไม่ใช่ผ่อนกฎทั้งข้อ

**ทะเบียนจริงตอนนี้ 24 ราย** (ไม่นับ `aetox` ที่มีในตัว) — เลขนี้ถูกแก้ให้ตรงใน README ทั้งสองภาษาแล้ว
พร้อมใส่ชื่อแถวใหม่เข้าลิสต์ เพราะเลขที่ประกาศไว้เกินจริงคือเลขที่ไม่มีใครไปตรวจ

## 🧠 ความจำผู้ใช้: เสนอน้อยลง แต่ตรงขึ้น

`Habit Synthesis` และ `Session Review` — สองตัวที่ขอให้ Aetox จำอะไรเกี่ยวกับคุณ —
ถูกเขียนคำสั่งใหม่ทั้งคู่ เหลือกฎชุดเดียวสั้นๆ ที่บังคับสามอย่าง:

- **ภาษา** — ข้อความที่เสนอต้องเป็นภาษาเดียวกับบทสนทนา ไม่ใช่ไทยปนอังกฤษตามใจโมเดล
- **กรอง** — เอาเฉพาะข้อเท็จจริงถาวร (บทบาท, tech stack, สภาพแวดล้อม) และกติกาถาวรที่คุณสั่งชัด
- **ทิ้ง** — งานครั้งเดียว อารมณ์ นิสัยเฉพาะหน้า และการเดา

เหตุผลคือของเดิมกว้างกว่านี้ และสิ่งที่เก็บมากว้างเกินไปจะถูกอ่านกลับเป็น *คำสั่ง* ในเซสชันถัดไป
ทุกครั้งที่ผู้ช่วยเปิดไฟล์นั้น

**เพดาน `USER.md` ขยับจาก 2 KB เป็น 4 KB** (~20-30 บรรทัด ≤ ~800 โทเคน) เพราะไทยกินราวสามไบต์
ต่อตัวอักษร อังกฤษหนึ่งตัว — เพดานเดิมที่พอดีกับภาษาอังกฤษจึงคับเกินไปสำหรับข้อความไทย
และเมื่อไฟล์เต็ม **จะไม่เสนอให้อนุมัติเลย** แทนที่จะเสนอแล้วโดนตัดทิ้งตอนบันทึก ซึ่งเสียทั้งการรอ
ของโมเดลและการตัดสินใจของคุณไปเปล่าๆ
