# Aetox v1.9.18

วันที่ 8 ตุลาคม 2026

**เห็นสถานะการบีบอัดบริบทและยกเลิกได้ เปิดไฟล์จากแผนที่คลังความรู้ และสลับแชทโดยคงหน้าเบราว์เซอร์กับเทอร์มินัลไว้** รุ่นนี้ปรับแนวทางเอเจนต์และสกิลออกแบบให้ตรงขอบเขตงาน พร้อมเพิ่มพรีเซ็ต MCP ของ 21st.dev

## บริบทและการบีบอัด

- แสดงสถานะระหว่างบีบอัดบริบท และให้ยกเลิกงานบีบอัดที่กำลังทำได้ แทนการรอโดยไม่เห็นความคืบหน้า
- แยกบัญชีบริบทโปรเจกต์จากคำสั่งระบบ เพื่อดูว่าส่วนใดใช้พื้นที่บริบท
- มิเตอร์เลือกข้อมูลการใช้บริบทของบทสนทนาหลักและโมเดลปัจจุบัน ไม่ปนข้อมูลของลูกมือหรือโมเดลที่ใช้ก่อนหน้า
- อธิบายค่าประมาณหลังบีบอัดหรือเปิดแชทกลับมาใหม่ และไม่ใช้ข้อมูลแคชจากคำขอเก่ามาอธิบายยอดปัจจุบัน

## คลังความรู้และแผนที่สมอง

- อ่านไฟล์จากคลังความรู้ที่เชื่อมไว้ และนำข้อมูลที่เกี่ยวข้องมาใช้กับงาน
- แตกโฟลเดอร์ในแผนที่เพื่อดูไฟล์ แล้วเปิดตัวอย่างไฟล์ในแอปได้
- ปรับจุดกดของแผนที่และใช้ข้อมูลร่วมกันระหว่างมุมมอง ไม่แก้ไขไฟล์ต้นฉบับในคลังที่เชื่อมไว้

## สลับงานและประวัติแชท

- พักหน้าเบราว์เซอร์และเทอร์มินัลเมื่อสลับแชทแทนการปิด เพื่อรักษาหน้าและเซสชันเดิมเมื่อกลับมา
- ประวัติแชทที่ยาวทยอยแสดงเฉพาะช่วงที่ใช้งาน แทนการวาดข้อความทั้งหมดพร้อมกัน
- กันหน้า dev ที่เปิดในแท็บเบราว์เซอร์ควบคุมหน้าต่างหลัก และคง Dock เมื่อมีเทอร์มินัลใช้งาน
- แยกข้อความแจ้งงานเบื้องหลังออกจากข้อความผู้ใช้ ไม่กินไฟล์แนบที่เตรียมไว้สำหรับส่งครั้งถัดไป
- แก้ข้อความแนบซ้ำ และรักษารายการงานที่มอบหมายเมื่อสร้างสถานะแชทกลับมาใหม่

## แนวทางเอเจนต์และสกิล

- ย้ำว่าคำสั่งที่ผู้ใช้ตัดสินใจแล้วไม่ต้องถามยืนยันซ้ำ และไม่ขยายงานหรือสั่งบิลด์นอกขอบเขต
- ลดการมอบงานเกินจำเป็น และให้ผู้ช่วยทำงานเฉพาะจุดหรือที่ต้องใช้บริบทร่วมกันเองก่อน
- ย่อสกิลออกแบบให้เป็นทิศทางและขอบเขต ย้ายรายละเอียดอ้างอิงออกจากเนื้อหาหลัก และถอดสกิล glass กับสูตรที่ผูกอยู่กับสกิลนั้น
- คงความสามารถส่งออก PowerPoint ไว้ การถอดเทสต์เก่าที่อิงโครง HTML ในเนื้อหาสกิลไม่ได้ถอดฟีเจอร์ส่งออก

## MCP และเบราว์เซอร์

- เพิ่มพรีเซ็ต 21st.dev สำหรับค้นหาและติดตั้งคอมโพเนนต์ React โดยต้องตั้ง API key ของบัญชีผู้ใช้เอง งานสร้างด้วย AI ขึ้นกับสิทธิ์บัญชี
- เพิ่มโลโก้ 21st จากต้นฉบับของผู้ให้บริการในรายการ MCP
- ถอดข้อห้ามรหัสผ่านและ API key ออกจากคำอธิบายเครื่องมือเบราว์เซอร์ตามการตั้งขอบเขตของเจ้าของผลิตภัณฑ์ ไม่ได้ถอดข้อจำกัดข้อมูลบัตรและข้อมูลการเงินอื่น

## การอัปเดต
