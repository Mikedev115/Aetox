# 🧭 Aetox v1.7.3

รุ่นแก้ไขนี้ทำให้ไกด์เข้าใจพื้นที่ทำงานด้านขวาจริง ๆ และทำให้หน้าต่างเบราว์เซอร์คงสเกลที่ถูกต้อง
เมื่อย้ายข้ามจอ

---

## ไกด์รู้ว่าแท็บไหนอยู่ตรงหน้า

- ไกด์แยกบริบทของ **Terminal, Browser, Files, Git, Timeline, Pull requests, แผนที่โค้ด,
  สไลด์, แผน และชิ้นงาน** ออกจากหน้าผู้ช่วยหรือหน้าโค้ดที่ครอบอยู่
- เปิดหรือสลับแท็บด้านขวาแล้วไกด์อธิบายแท็บนั้นโดยตรง ไม่วนกลับไปแนะนำ “หน้าผู้ช่วย” หรือ
  “หน้าโค้ด” ซ้ำ และไม่แสดงจำนวนจุดแนะนำของทั้งหน้าราวกับเป็นของแท็บเดียว
- คำถามถัดไปของไกด์อิงกับงานที่ทำได้ในแท็บปัจจุบัน และไม่เสนอให้เปิดแท็บที่เปิดอยู่แล้ว
- สมองโมเดลของไกด์ได้รับทั้งชื่อหน้าและบริบทของแท็บ พร้อมรีเซ็ต snapshot เมื่อสลับแท็บแม้ยังอยู่
  ในหน้าแชทเดิม
- พฤติกรรมหน้าแชทหลักของทั้งโต๊ะผู้ช่วยและโต๊ะโค้ดยังคงเดิมเมื่อไม่ได้โฟกัสแผงเครื่องมือ

## หน้าต่างเบราว์เซอร์ข้ามจอ

- WebView2 ติดตามค่า scale ของจอที่หน้าต่างอยู่จริง จึงไม่ค้างที่ DPI ของจอเดิมเมื่อย้าย Aetox
  ระหว่างจอที่ตั้งสเกลต่างกัน

## การตรวจสอบ

- ชุดทดสอบ frontend ผ่าน 2,110 เคสจาก 205 ไฟล์
- `svelte-check`, production build และชุดทดสอบ Go ของ desktop ผ่าน
- `scoop/aetox.json` ชี้ไป `v1.7.3` แล้ว ส่วน `hash` ยังเป็นของรุ่นก่อนตามขั้นตอนปกติ
  และต้องเติมจาก `checksums.txt` ของ artifact ที่ workflow เผยแพร่จริง
