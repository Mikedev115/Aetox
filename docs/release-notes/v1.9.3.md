# 🧩 Aetox v1.9.3

รุ่นนี้ต่อจาก [v1.9.2](v1.9.2.md) ภายในวันเดียวกัน (29 ก.ย. 2026) ทุกอย่างใน 1.9.2 อยู่ในรุ่นนี้ครบ
ได้แก่ หน้าเว็บที่ถูกตรวจทุกครั้งที่เขียน 11 ธีมที่อ่านออกทุกชุด เซสชันยาวที่จ่ายน้อยลง
ปุ่ม ให้เอเจนใช้ บนแท็บเบราว์เซอร์ และเทอร์มินัลที่คัดลอก/วางได้ครบ ส่วนที่เพิ่มในรุ่นนี้มีหนึ่งเรื่อง

## สกิลความปลอดภัย: ไม่เติมเขตเวลาเองเมื่อสเปกไม่ได้ขอ

**เดิม** สกิล `aetox-security` เขียนว่าเวลาปัจจุบัน "is local" โมเดลอ่านว่าให้ใส่เขตเวลาท้องถิ่น
จึงเติม `.astimezone()` ท้ายเวลาใน log แต่โค้ดที่เรียกใช้ต่อเอาเวลานั้นไปลบกับเวลาที่ไม่มีเขตเวลา
ทั้งเทสต์การใช้งานและเทสต์ความปลอดภัยจึงล้มด้วย `TypeError` ทั้งที่ป้องกันการขึ้นบรรทัดใหม่ถูกแล้ว
ในโจทย์ CWEval cwe_117 บน Luna การเติมเขตเวลาเพิ่มจาก 0/3 รันใน 1.9.0 เป็น 2/4 ใน 1.9.1
และราว 12/17 ใน 1.9.2
**รุ่นนี้** เปลี่ยนคำเป็น "ไม่มีเขตเวลา เว้นแต่ตัวอย่างในสเปกจะมี" ส่วนอื่นของสกิลไม่ได้แก้

## ข้อควรรู้

- ฐานข้อมูลยังเป็น migration 39 เหมือน 1.9.1 และ 1.9.2
- ถ้ายังไม่ได้อ่าน [บันทึกของ 1.9.2](v1.9.2.md) มีสองเรื่องที่ควรรู้ ถ้าคุณเขียนโต๊ะเองและประกาศ `web`
  เพื่อใช้ n8n, Windmill, Meta หรือ YouTube ต้องเพิ่ม `services` ในบรรทัด `categories`
  และธีมเดิมของคุณถูกย้ายไปเป็นชุดกับโหมดที่ตรงกันเอง
- ปุ่มอัปเดตในแอปใช้ได้ถ้าคุณอยู่ที่ 1.8.1 ขึ้นไป ถ้ายังอยู่ที่ 1.8.0 หรือเก่ากว่า ต้องโหลดเองหนึ่งครั้ง
