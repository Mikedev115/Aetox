# 🧩 Aetox v1.9.7

รุ่นนี้รวมเรื่อง "ใครส่งงานให้ใครได้" มาไว้ที่ตัวหลักแต่ละตัว: ทีมถึงตัวหลักได้ด้วยการแต่งตั้งเท่านั้น
ผู้ช่วยกับโค้ดเรียกสมาชิกทีมได้ตรง ๆ และเลขาแต่งตั้งจากแผนผังองค์กรของตัวเอง
นอกจากนั้นเอเจนเขียนสกิลจากงานที่ทำได้ รัน dev server ของโปรเจกต์ตามชื่อแล้วส่งลูกมือไปกดทดสอบ
และเลิกเปิดสกิลที่อ่านแล้วซ้ำทุกเทิร์น

## ตัวหลัก: แท็บมอบงาน แทนหน้าสิทธิ์มอบงาน

**เดิม** ว่าตัวหลักส่งงานให้ใครได้ อยู่หน้า สิทธิ์มอบงาน แยกจากหน้าตัวหลัก หน้านั้นโชว์ทุกทีมพร้อมบรรทัด
"ยังไม่เคยเลือก" ทีมที่มีหัวหน้าถูกส่งงานทั้งก้อนผ่านหัวหน้าทีม แม้ผู้ช่วยหรือโค้ดจะเป็นคนนำทีมนั้นเอง
และรายชื่อที่ไม่มีหัวหน้าอยู่ได้แค่ตัวหลักเดียว แต่งตั้งที่อื่นแล้วย้ายไป
**รุ่นนี้** ตัวหลักแต่ละตัวมีแท็บ **มอบงาน** ของตัวเอง แถว สิทธิ์มอบงาน ออกจากแถบซ้าย ที่อยู่เดิมพามาแท็บนี้

- **ผู้ช่วย · โค้ด** แยกเป็นสองก้อน: **ลูกมือ** ที่มากับตัวหลักโดยไม่ต้องแต่งตั้ง และ **เอเจนเฉพาะทาง**
  ที่ว่างจนกว่าคุณจะแต่งตั้งทีม ตอนว่างมีแค่ปุ่มแต่งตั้งทีม หน้าต่างเลือกใช้คำ แต่งตั้ง และ ถอด
- ทีมที่แต่งตั้งแล้ว ผู้ช่วยหรือโค้ดเป็นหัวหน้าเอง เรียกสมาชิกตามชื่อได้ตรง ใต้เพดานเครื่องมือของทีมนั้น
  หัวหน้าทีมเดิมไม่ถูกเรียก (การ์ดทีมบอกไว้) สมาชิกรู้ว่าอยู่ทีมไหน ตำแหน่งอะไร และกฎทีมคืออะไร
  ทีมหนึ่งแต่งตั้งให้ทั้งสองตัวหลักพร้อมกันได้
- **เลขา** มอบงานตามแผนผังองค์กร แต่งตั้งได้ทั้งทีม แผนก และบริษัท ทุกกล่องมีป้ายบอกว่า สั่งตรง
  ผ่านหัวหน้าข้างบน หรือต้องแต่งตั้ง ถ้ายังไม่เคยแต่งตั้ง เลขาถึงทุกหน่วยเหมือนเดิม
- การ์ดตัวหลักมีบรรทัดสรุปว่ามอบงานให้ใครได้ ปุ่มทีมข้างช่องพิมพ์อ่านค่าเดียวกับการแต่งตั้ง
  และขึ้นว่า "ยังไม่แต่งตั้งทีม" แทน "ยังไม่มีรายชื่อจ้าง"

**ผู้ใช้เดิมไม่ต้องตั้งใหม่:** ตอนเปิดแอปครั้งแรกหลังอัปเดต ตัวหลักที่ยังไม่เคยตั้งค่าได้ทีมที่มันเคยส่งงานให้จริง
(อ่านจากประวัติการเรียกเครื่องมือ) ส่วนติดตั้งใหม่เริ่มว่าง ตัวหลักที่คุณตั้งไว้แล้วไม่ถูกแตะ

ที่จงใจไม่ทำ: ฝั่งงานทีมของเลขา หัวหน้าทีมยังเป็นหัวหน้า เลขาส่งงานผ่านหัวหน้าทีมเหมือนเดิม

## เอเจนทั้งหมด = หน้าตั้งค่ารวมของทุกเอเจน

**เดิม** โมเดลของแต่ละเอเจนกระจายอยู่หน้าของมันเอง ไม่มีที่ดูภาพรวม
**รุ่นนี้** หน้า เอเจน › เอเจนทั้งหมด ตั้งโมเดลของทุกเอเจนได้ที่เดียว ทั้งรายตัวและ **ตามยศ**
(หัวหน้าบริษัท V · หัวหน้าแผนก IV · หัวหน้าทีม III …) ผังทั้งหมดอยู่เป็นการ์ดท้ายหน้า
แถบซ้ายจัดตามหน้าที่ บุคลากร เปลี่ยนชื่อเป็น เอเจน และ ผลงาน › โครงสร้าง กลับมา

## สกิลจากงานที่ทำ

**เดิม** แท็บ "ที่สั่งบ่อย" นับข้อความที่พิมพ์ซ้ำแล้วเสนอเป็นสกิล แถวส่วนใหญ่กลับเป็นพรอมต์ของรอบทดสอบ
และข้อความที่พิมพ์ซ้ำก็ไม่ใช่วิธีทำงานที่ควรเก็บ
**รุ่นนี้** ถอดตัวนับออกทั้งหมด แทนด้วยสองทางที่แยกกัน

- สวิตช์ **สร้างสกิลเบื้องหลัง**: เปิดแล้วเอเจนเขียนสกิลระหว่างทำงาน เมื่อคุณแก้วิธีทำงานของมัน หรือมันหาทางที่ใช้ได้เจอ
  สกิลที่เอเจนสร้างเองเขียนทันทีพร้อมปุ่มย้อนใต้คำตอบ ส่วนการแก้สกิลของคุณหรือที่มากับแอปเข้าคิวรออนุมัติ
  ปิดแล้วเอเจนไม่มีเครื่องมือนี้
- **ทบทวนย้อนหลัง**: คุณเลือกแชตเอง กรองตามเจ้าของแชต (พร้อมหน้าเอเจนและยศ) และช่วงเวลา
  ทั้งหมด วันนี้ สัปดาห์นี้ เดือนนี้ หรือเลือกวัน/เดือน ตัวทบทวนเห็นดัชนีหนึ่งบรรทัดต่อเทิร์น
  แล้วเปิดอ่านเฉพาะช่วงที่เกี่ยว ข้อเสนอเข้าคิวรออนุมัติ แชตที่อ่านแล้วถูกจำไว้

ที่จงใจไม่ทำ: เอเจนไม่อ่านแชตย้อนหลังเองไม่ว่าสวิตช์จะเปิดหรือปิด การทบทวนย้อนหลังเกิดเมื่อคุณสั่งเท่านั้น

## รัน dev ตามชื่อ แล้วส่งลูกมือไปกดทดสอบ

**เดิม** รอบจริงรอบหนึ่งใช้ 5 นาที 42 วินาทีกว่าจะเปิดหน้าแอปได้ บิ้วจริงแค่ 1 นาที 42 วินาที
ที่เหลือคือคลำหาวิธีรัน และผลการรันกับการกดทดสอบไหลกลับเข้าแชตหลัก 67 KB จาก 32 ครั้ง ค้างในบริบทและถูกส่งซ้ำทุกรอบ
**รุ่นนี้**

- เครื่องมือ **dev** (list · start · logs · stop) รัน dev server ตามชื่อในไฟล์ `.aetox/launch.json` ของโปรเจกต์
  ถ้ามีตัวที่เปิดอยู่แล้วในพอร์ตนั้นจะใช้ตัวนั้นและไม่หยุดมัน ถ้าไม่มีจะเริ่มเองแล้วรอจนพอร์ตตอบ
  จากนั้นโหลดหน้าตรวจให้หนึ่งครั้ง ขอสิทธิ์เหมือนคำสั่ง shell
- การ์ดเซิร์ฟเวอร์ในแชตใช้ชื่อจากไฟล์ launch บอกว่าตรวจหน้าแล้วหรือยังตามที่เอนจินจดไว้
  ตัวที่ไม่ได้เริ่มเองไม่มีปุ่มหยุด
- ลูกมือ **tester** กดทดสอบของจริงในแอปที่ dev รันอยู่ แล้วคืนผลผ่าน/ไม่ผ่านทีละข้อ ไม่แก้ไฟล์และหยุด dev ไม่ได้
  รอบทดสอบจริง แชตหลักใช้ 4 ครั้ง 7 KB ส่วน 68 KB ของการกดและอ่านหน้าอยู่ในบริบทของ tester
- ลูกมือทุกตัวเป็นโฟลเดอร์สามไฟล์ หน้าที่ · ตัวตน · วิธีคิด แบบเดียวกับพนักงาน

## ติดดาวโมเดลได้จากเมนูเลือกโมเดล ทุกที่

**เดิม** ติดดาวได้ที่หน้าผู้ให้บริการที่เดียว ผู้ให้บริการที่ยังไม่มีดาว เมนูจึงไม่บอกเลยว่าติดได้
**รุ่นนี้** ทุกแถวในเมนูเลือกโมเดลมี ☆ กดติดได้ตรงนั้นหลายตัวติดกัน รายการไม่ขยับระหว่างเมนูเปิด
รอบถัดไปที่เปิดค่อยเรียงตามดาว การ์ดเติมโค้ดกับแผงไกด์ใช้เมนูเดียวกันจึงได้ดาวด้วย
และ `/model` ในคอนโซลเทอร์มินัลเรียงตัวติดดาวขึ้นก่อน ไม่แสดงตัวที่ปิด

## เอเจนเลิกเปิดสกิลที่อ่านแล้วซ้ำทุกเทิร์น

**เดิม** สองประโยคทำงานต่อกัน: พรอมต์บอกให้เปิดสกิลในการเรียกเครื่องมือครั้งแรก (ตรวจใหม่ทุกเทิร์น)
และสกิลระดมความคิดบอกว่าได้ชุดสุ่มใหม่ทุกครั้งที่อ่าน เอเจนจึงเปิดสกิลเดิมซ้ำทุกเทิร์น
**รุ่นนี้** แก้คำเดิมโดยไม่เพิ่มประโยค สกิลที่อ่านแล้วในแชตนับว่าอ่านแล้ว
และเปิดซ้ำได้แค่ชุดสุ่มใหม่ ไม่ได้เนื้อสกิลเต็มอีกรอบ

วัด 4 เทิร์นต่อแชต 3 แชต: เปิดซ้ำในเทิร์น 2–4 จาก 9/9 เหลือ 0/9 รอบโมเดล 25 → 15
เวลาเฉลี่ย 156 → 115 วินาทีต่อแชต ส่วนเนื้อสกิลที่ส่งต่อแชตจาก 9.9 KB เหลือ 2.5–3.4 KB

## อื่น ๆ ในรุ่นนี้

- เมนูเลือกเชลล์ (Windows · WSL) กับเมนูเอนจินอัตโนมัติข้างช่องพิมพ์ ปิดเมื่อคลิกข้างนอกแล้ว
  เดิมเปิดค้างไว้แล้วไปหน้าตั้งค่า เมนูลอยค้างทับหน้านั้น ตอนนี้ปิดทุกครั้งที่ออกจากหน้าแชต
  ไม่ว่าจะออกด้วยการคลิก คีย์ลัด หรือไกด์
- ภาพที่เอเจนสร้างเปิดในแผงขวาได้ และมีปุ่มลองโหลดใหม่เมื่อโหลดพลาด
- ห้องความสามารถ: ป้ายทีมในแถบ "ใหม่สัปดาห์นี้" ใช้ชื่อทีม ไม่ใช่คำอธิบายทั้งประโยคที่ล้นแถว
  ช่องค้นหาแถบซ้ายหดตามความกว้างแถบ
- คำอธิบายสวิตช์สร้างสกิลเบื้องหลังเหลือบรรทัดเดียว
