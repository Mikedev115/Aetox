# 🧩 Aetox v1.9.20

วันที่ 10 ตุลาคม 2026

**รันเซสชันโค้ดบน CLI ภายนอกได้ (Claude Code, OpenCode, Antigravity) และบอต Telegram/Discord รับไฟล์ ตอบด้วยปุ่ม และตั้งโมเดลแยกต่อการเชื่อมต่อได้** รุ่นนี้ยังเพิ่มวิดีโอคนพูดจากภาพบุคคลกับเสียง แผนที่สมองที่ขยับตามเมาส์ และหน้าเกี่ยวกับคุณที่แบ่งเป็นหน้าเดียวต่อครั้ง

## เอนจินภายนอกบนโต๊ะโค้ด

- เลือกเอนจินภายนอกของเซสชันได้พร้อมโมเดล ตัวเลือก และโหมดอนุมัติ มีตัวปรับต่อ Claude Code, OpenCode และ Antigravity
- ตัวปรับแต่ละตัวรัน CLI ของมัน แปลงสตรีมเป็นรอบสนทนา อ่านรายการโมเดล และหยุดได้สะอาดบน Windows
- เครื่องมือของเอนจินภายนอกผ่านตัวรันและด่านอนุมัติเดียวกับเครื่องมือของ Aetox แถวประวัติบอกว่าเอนจินใดรันเครื่องมือนั้น
- หน้าแรกของแชทแสดงเอนจินที่แชทใหม่จะใช้ และแถวเซสชันมีเครื่องหมายของเอนจิน

## บอต Telegram และ Discord

- ตั้งโมเดล ระดับการคิด และเส้นทางแยกต่อการเชื่อมต่อได้ และเปลี่ยนแล้วมีผลทันที
- ข้อความรับไฟล์ได้ โดยดาวน์โหลดเมื่อเอนจินขอและไม่เกินขนาดที่กำหนด บอตส่งไฟล์กลับได้
- ถามคำถามพร้อมปุ่มได้ ถ้าไม่มีปุ่มจะถามเป็นข้อความธรรมดา การกดปุ่มบน Discord ผ่านด่านจับคู่ ตัวแยกคำสั่ง และการตรวจเจ้าของแบบเดียวกับข้อความที่พิมพ์
- `ask_user` และการอนุมัติส่งถึงแชท ข้อความเสียงถูกถอดเสียง และตารางเวลาออกไปทำงานแจ้งบอตได้
- การจับคู่ผูกกับ ID ผู้ใช้ที่คงที่ พิมพ์รหัส `/pair` ผิดห้าครั้งล็อกเฉพาะผู้ใช้คนนั้น 15 นาที

## วิดีโอคนพูด

- สร้างวิดีโอคนพูดจากภาพบุคคลกับเสียงพูด ผ่านเครื่องมือวิดีโอคนจริงที่มีหน้าตั้งค่าและการตั้ง MCP ของตัวเอง
- คีย์ของบริการอยู่ที่หน้าจอ มีเพียงช่องส่งที่เซ็นแล้วที่ถึงเอนจิน เอเจนต์ผู้กำกับและวิดีโอรู้ว่าเมื่อไรควรใช้เครื่องมือนี้

## แผนที่สมองและคลังความรู้

- แผนที่สมองใหญ่เป็นระบบแรงที่ทำงานต่อเนื่อง: คุณอยู่กลาง โต๊ะ โปรเจกต์ และวันกับแนวทางทำงานอยู่บนวงรอบ ขยายออกจากตัวคุณ ปรับกรอบให้พอดี และตามเมาส์ จุดลากได้ และไฟล์ของโฟลเดอร์งอกออกมา
- แก้การกดจุดที่เปิดไม่ได้ และโต๊ะหรือโปรเจกต์แสดงความจำของมัน (ไฟล์ความจำและงานห้าวันล่าสุด) เปิดดูแต่ละวันได้
- โฟลเดอร์ที่เชื่อมเป็นหน้าเดียวพร้อมต้นไม้ไฟล์ บอกคำสัญญาว่าอ่านอย่างเดียวครั้งเดียว ติ๊กเลือกไฟล์หรือทั้งโฟลเดอร์ และข้ามโฟลเดอร์ที่ซ่อน เช่น `.trash` `.stfolder` `.obsidian`
- เรียนรู้ทั้งโฟลเดอร์ไม่มีเพดานและไม่มีข้อผิดพลาดดิบอีก ตั้งแต่ 50 ไฟล์ขึ้นไปจะเตือนว่าใช้เวลานานและใช้โทเคนมาก ยกเลิกแล้วงานที่เรียนไปแล้วยังอยู่
- ถามในแชทด้วยภาษาธรรมดาก็หาไฟล์ที่เรียนไว้เจอ (เดิมต้องมีทุกคำ คำถามภาษาไทยจึงว่าง)

## หน้าเกี่ยวกับคุณ

- แยกเป็นหกหน้าใต้แถบเดียว: ภาพรวม (แผนที่สด) · ทีละวัน · เกี่ยวกับคุณ · วิธีที่คุณทำงาน · คลัง · การจดบันทึก
- ทีละวันแสดงครั้งละสิบวัน และคู่มือในแอปรู้จักแท็บใหม่

## เอเจนต์ MCP และเครื่องมือ

- สกิลระบุได้ว่าเป็นคู่มือของ MCP เซิร์ฟเวอร์ใด และไปอยู่ในบรรทัดของเซิร์ฟเวอร์นั้น แถมคู่มือ GitHub และ Firecrawl พร้อมสกิลของผู้ให้บริการบนชั้นติดตั้ง
- เพิ่มเกตเวย์ MCP ส่วนตัวที่ให้ความสามารถของเครื่องมือหนึ่งอย่างต่อหนึ่งบทสนทนา ตรวจสิทธิ์ทุกครั้งที่เรียก และไม่รับเอนจิน เซสชัน หรือรากพาธจากไคลเอนต์ พร้อมคำสั่ง `mcp-bridge`
- เครื่องมือหน้าจอถูกประเมินก่อนขออนุมัติ ถ้าประเมินพลาดจะหยุดการเรียกแทนที่จะถือเป็น "ไม่" และผลลัพธ์ภาพจาก MCP ถึงโมเดลแม้โมเดลหลักของเซสชันรับรูปไม่ได้
- อาร์กิวเมนต์ชนิดลิสต์หรือออบเจ็กต์ที่โมเดลส่งมาเป็นสตริง JSON ถูกถอดก่อนเรียก
- เครื่องมือไฟล์ในตัวหาพาธใน sandbox ของเซสชันนั้น และเบราว์เซอร์เปิด/อัปโหลดไฟล์ในขอบเขตเดียวกัน
- สกิล `aetox-proposal-page` ทำข้อเสนอที่ดูด้วยตาเป็นหน้า HTML เดียวที่สลับตัวเลือกได้ เปิดด้วยเบราว์เซอร์ และขึ้นใน ชิ้นงาน แม้สร้างในโปรเจกต์ที่โฟกัสอยู่ เพราะนับไฟล์ที่แชทสร้างแล้วเปิดให้ดู
- เอเจนต์ย่อยตัดสินใจเองและรายงานทางเลือกที่ทำ ถามผู้ใช้เมื่อติดจริงเท่านั้น

## แชทและโมเดล

- แสดงสถานะรอโมเดลเมื่อผู้ให้บริการยังไม่ตอบ ทั้งในแชทและ TUI และยังอยู่หลังรีโหลด การยกเลิกการสลับโมเดลที่ต่อคิวบอกว่ายกเลิกได้หรือมีผลไปแล้ว
- สตรีมที่ขาดโดยไม่มีคำตอบลองใหม่เฉพาะคำขอนั้น ก่อนเครื่องมือใดจะรัน และเปิดเซสชันเดิมกลับมาแล้วมิเตอร์บริบทอิงจำนวนที่ผู้ให้บริการนับ
- เซสชันของผู้ให้บริการและการปักหมุดเป็นของบทสนทนา เส้นทางและคีย์แคชคงเดิมเมื่อสร้างไคลเอนต์ใหม่ หมุดอยู่กับหน้าจอ ไม่ใช่ที่เก็บของ WebView และนำเข้าหมุดเก่าให้ครั้งเดียว
- ข้อเท็จจริงของเกตเวย์แยกตาม endpoint และข้อความผิดพลาดบอก endpoint ท้องถิ่นที่ใช้จริง
- แชทติดต่อเซสชันอื่นเมื่อจำเป็นเท่านั้น
- เอนจินเริ่มทำงานโดยรายงานความคืบหน้า และเดสก์ท็อปรอภายใต้เส้นตาย ถอยไป TCP เฉพาะข้อผิดพลาดที่ถอยได้ การ์ด dev แสดงความคืบหน้าและความล้มเหลวของเซิร์ฟเวอร์

## หน้าตาและความสะดวก

- ตัวเลือกผู้ให้บริการและชิปโมเดลใส่สีแบรนด์ (แบรนด์ที่โลโก้เป็นสีเดียว เช่น OpenAI ยังเทา)
- ปักหมุดโปรเจกต์ในตัวเลือกโปรเจกต์
- แถบแท็บโต๊ะแชทมีเครื่องหมายชนิดไฟล์และปุ่มปิดทั้งหมด
- แถวสถิติการตอบในตั้งค่ามีไอคอนเดียวกับแถบในกล่องพิมพ์และตัวอย่างหนึ่งบรรทัด
- ชื่อ Aetox Harness ครบทั้งหน้าเกี่ยวกับ หน้าต้อนรับ ป้ายอัปเดต ทัวร์ (อังกฤษ ไทย จีน) และชื่อ PWA บนโทรศัพท์
- ฟองของตัวละครเก็บขีดล่างคู่ในคำ เช่น `mcp__aetox__codebase` ไว้ ไม่ลบหายไป

## Git

- ตัวเขียนข้อความคอมมิตครอบคลุมทุกไฟล์ของคอมมิตกว้าง เดิมไฟล์แรกๆ ใช้งบหมดและคอมมิต 340 ไฟล์ถูกอธิบายด้วยฟีเจอร์แรกเท่านั้น
- แบ่งคอมมิตอัตโนมัติไม่เทไฟล์ที่เหลือลงคอมมิตยักษ์ก้อนเดียวอีก ไฟล์ที่โมเดลตกถูกแบ่งตามโฟลเดอร์ และงบคำตอบโตตามจำนวนไฟล์
- ไทม์ไลน์ประวัติอ่านใหม่เมื่อ HEAD เปลี่ยนนอกหน้านี้ เช่น คอมมิต รีเซ็ต หรือเขียนประวัติใหม่จากเทอร์มินัลหรือเซสชันอื่น

## การเปลี่ยนแปลงอื่นในรุ่นนี้

- เทสต์ใหม่ล้มเมื่อซอร์สที่ส่งมอบอ้างโฟลเดอร์โฮมของเครื่องที่บิลด์ หลังพบพาธฮาร์ดโค้ดใน fallback ของ Claude Code
- แก้เทสต์ภาพแนบสองข้อที่เรียก `runTurn` โดยไม่มาร์กรอบก่อน จึงยกเลิกคอนเท็กซ์ตั้งแต่เริ่ม
