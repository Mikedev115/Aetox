# 🧩 Aetox v1.9.12

รุ่นนี้คือ v1.9.11 ที่ได้ปล่อยจริง: tag v1.9.11 บิ้วไม่ผ่านที่ขั้นแพ็กเกจ Store จึงไม่เคยถึงมือผู้ใช้
ทุกอย่างใน[บันทึกรุ่น v1.9.11](v1.9.11.md) อยู่ในรุ่นนี้ครบ พร้อมสองจุดที่แก้เพิ่มด้านล่าง

## แชทจาก Telegram ใช้โมเดลเดียวกับที่เลือกล่าสุดในแอป

**เดิม** ตั้งแต่ v1.9.5 การเลือกโมเดลผูกกับแต่ละแชท และปุ่ม + ใช้ตัวที่เลือกล่าสุด แต่แชทที่เข้ามาทาง
Telegram หรือ Discord ยังอ่านค่าเริ่มต้นเดิมของแอป ซึ่งไม่ถูกเขียนใหม่อีกแล้ว บอทจึงค้างอยู่ที่โมเดล
ที่เลือกไว้ก่อนการเปลี่ยนนั้น ถ้าโมเดลตัวนั้นเป็นเซิร์ฟเวอร์ในเครื่อง (เช่น 9Router) ที่ไม่ได้เปิดอยู่
บอทจะตอบกลับแค่ข้อผิดพลาด `local server not running` ทั้งที่แอปเองคุยได้ปกติ

**รุ่นนี้** แชทใหม่จากบอทเริ่มด้วยโมเดลเดียวกับที่ปุ่ม + ให้ คือโมเดลที่เลือกล่าสุดในแอป

ไม่ได้ทำ: ล็อกบอทกับโมเดลของหน้าใดหน้าหนึ่งแยกต่างหาก และไม่ได้ให้บอทสลับไปผู้ให้บริการอื่นเอง
เมื่อเซิร์ฟเวอร์ในเครื่องไม่ได้เปิด

## แพ็กเกจ Microsoft Store บิ้วได้อีกครั้ง

คอมเมนต์ใน `AppxManifest.xml` มี `--` ซึ่ง XML ไม่อนุญาต makepri จึงปฏิเสธไฟล์ (PRI191)
แก้ข้อความคอมเมนต์ และเพิ่มเทสต์ `TestTheStoreManifestIsWellFormedXML` ที่อ่าน manifest ทุกครั้งที่รัน
`go test` เพื่อไม่ให้รู้ตัวช้าถึงตอนบิ้ว tag
