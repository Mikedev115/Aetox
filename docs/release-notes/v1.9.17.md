# Aetox v1.9.17

วันที่ 7 ตุลาคม 2026

**หน้าเกี่ยวกับคุณรวมบันทึกงานและสิ่งที่ Aetox เรียนรู้ไว้ในคลังสมองส่วนตัว พร้อมแผนที่เชื่อมโยงโต๊ะและโปรเจกต์** เปิดศูนย์บัญชาการผ่าน Cloudflare Tunnel ได้โดยทุกเครื่องต้องจับคู่ก่อนใช้งาน และเมื่อคุณพิมพ์แทรกระหว่างทำงาน เอเจนต์ต้องตอบก่อนเริ่มเครื่องมือที่เหลือ

รุ่นนี้รวมการเปลี่ยนแปลงของ [v1.9.16](v1.9.16.md) ซึ่งบิลด์ผ่านแล้วแต่ยังไม่ได้เผยแพร่ให้ผู้ใช้ด้วย

## คลังสมองในหน้าเกี่ยวกับคุณ

- ดูบันทึกงานรายวันแยกตามโต๊ะ และสิ่งที่เรียนรู้เกี่ยวกับรูปแบบการทำงานของคุณในหน้าเดียว
- กรองบันทึกตามโต๊ะ โปรเจกต์ และคำค้น เพื่อย้อนหางานที่เกี่ยวข้องได้
- เพิ่มโฟลเดอร์คลังความรู้ของคุณให้ Aetox อ่านได้ โดยไม่เขียนทับไฟล์ในโฟลเดอร์ที่เชื่อมไว้
- แผนที่ย่อแสดงจุดหลักของคุณ โต๊ะ และโปรเจกต์ ส่วนแผนที่เต็มเปิดดูความเชื่อมโยงเพิ่มเติมได้
- เอาการ์ดคำถามออกจากหน้าเกี่ยวกับคุณ ให้พื้นที่หลักอยู่กับบันทึกและแผนที่

## ศูนย์บัญชาการจากเครื่องอื่น

- ตั้งชื่อโดเมน Cloudflare Tunnel ในการตั้งค่าศูนย์บัญชาการ เพื่อเข้าใช้งานจากนอกเครือข่ายบ้านได้
- ทุกเครื่องต้องจับคู่ด้วยรหัสก่อนเข้าใช้งาน รวมถึงการเข้าผ่าน tunnel
- รับคำขอผ่าน tunnel เฉพาะโดเมนที่ตั้งไว้ และใช้คุกกี้สำหรับ HTTPS

## สื่อสารระหว่างทำงาน

- เมื่อคุณพิมพ์แทรกขณะเอเจนต์ใช้เครื่องมือหรือรอคำตอบจากโมเดล ระบบพักกลุ่มเครื่องมือที่ยังไม่เริ่ม เพื่อนำข้อความของคุณไปให้เอเจนต์ตอบก่อนทำต่อ
- เครื่องมือที่เริ่มไปแล้วคืนผลตามเดิม ไม่ฆ่าคำสั่งกลางทาง และเก็บข้อความ รูปแนบ และผลเครื่องมือไว้ครบ
- เมื่อทำงานเงียบครบ 3 นาทีหรือ 8 รอบเครื่องมือ ระบบเตือนให้โมเดลรายงานสถานะในคำขอถัดไป ไม่ใช่การรับประกันข้อความทุก 3 นาทีระหว่างคำสั่งยาวที่ยังไม่คืนผล
- ถ้าโมเดลยังเรียกเครื่องมือโดยไม่ตอบข้อความแทรกหลังการเตือนซ้ำที่มีขอบเขต ระบบพักงานแทนการปล่อยให้ทำต่อเงียบ ๆ
- รายงานที่หยุดรอการตัดสินใจของเจ้าของจบเทิร์นได้ ไม่ถูกตัวเตือนงานค้างสั่งให้ทำต่อเอง

## ขอบเขตการมอบงานและปล่อยรุ่น

- ย้ำว่าลูกมือชั้นปลายไม่มีเครื่องมือมอบงานต่อ โดยยังคงให้หัวหน้าทีมส่งงานถึงสมาชิกได้ตามบทบาท
- แนวทางปล่อยรุ่นกำหนดให้หยุดเมื่อ version gate, CI หรือ pre-push hook ไม่ผ่าน รายงานสิ่งที่ทำไปแล้วและสิ่งที่ยังไม่ได้ทำ ไม่ซ่อมโค้ดหรือเผยแพร่ต่อเอง

## แก้ไข

- ชื่อผู้ใช้ไม่ค้างว่างเมื่ออ่านชื่อไม่สำเร็จหรือมีหลายหน้าร้องขอชื่อพร้อมกัน การอ่านที่ล้มเหลวลองใหม่ได้ในครั้งถัดไป
- การถามสถานะคำสั่งที่ระบบหยุดเพราะนิ่งแล้วรับผลการหยุดเดิม ไม่เริ่มคำสั่งเดียวกันซ้ำ
- แก้ข้อมูล MCP อ่าน–เขียนชนกันเมื่อเปลี่ยนการตั้งค่าระหว่างเชื่อมต่อ คืนสำเนารายชื่อเซิร์ฟเวอร์และคำสั่งแทนการแบ่งข้อมูลที่แก้ร่วมกัน
- สถานะห้องทำงานอ่านข้อมูลโต๊ะอย่างปลอดภัยระหว่างการอัปเดตการตั้งค่า
- ปรับเทสต์หน้าจอและ Wails mock ให้ตรงกับสัญญาปัจจุบัน ไม่ได้เพิ่มความสามารถใหม่จากการเปลี่ยนเทสต์เหล่านี้

## รวมจากรุ่นที่ยังไม่ได้เผยแพร่

- ทีมที่ยังไม่ได้แต่งตั้งบอกทางไปแต่งตั้ง แทนที่จะปล่อยให้ผู้ช่วยวนหาทางเปิดสิทธิ์เอง
- หน้าว่างของแผงขวาฝั่งโค้ดและผู้ช่วยเปลี่ยนเป็นภาพหน้าต่าง editor และลำดับงานผู้ช่วย ภาพเหล่านี้เป็นตัวอย่าง ไม่ใช่ข้อมูลโปรเจกต์จริง
- โต๊ะโค้ดและ editor อ่านตัวหนังสือจากรูปในโปรเจกต์ได้ โดยไม่ได้เปิดการอ่านวิดีโอหรือถอดเสียงเพิ่ม

## การอัปเดต

ฐานข้อมูลบันทึกงานอัปเดตอัตโนมัติเมื่อเปิดรุ่นนี้ ไม่ต้องย้ายข้อมูลด้วยตนเอง อัปเดตทั้งแอปและเอนจินพร้อมกันผ่านตัวติดตั้งหรือแพ็กเกจพกพาของรุ่นเดียวกัน
