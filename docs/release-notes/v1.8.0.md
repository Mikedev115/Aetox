## โต๊ะโค้ดมีสองโหมด: Agent · Editor

**เดิม** โต๊ะโค้ดคือแชทกับ workbench ทางขวา ไฟล์เปิดเป็นการ์ดในแชท จะแก้เองต้องออกไปเปิดโปรแกรมอื่น
**รุ่นนี้** สวิตช์บนแถบบนอ่านว่า Agent · Editor Agent คือโต๊ะแบบเดิมทุกอย่าง Editor วางไฟล์ไว้กลางจอ
มีแผงขวาของตัวเอง (เอเจนต์ · Explorer · Git · ชิ้นงาน) แชทข้างเดียวกันถูก mount ครั้งเดียวแล้วย้ายบ้าน
สลับโหมดไม่ปิดอะไรเลย และโหมดอยู่คงที่ข้ามการสลับโปรเจกต์

สิ่งที่อีดิเตอร์ทำได้ในรุ่นนี้ (ไม่มีตลาดส่วนขยาย จึงต้องสร้างในตัวทั้งหมด):

- **Ctrl+K ขอแก้** กล่องใต้บรรทัดที่เลือก คำตอบเข้ามาเป็นฮังก์ให้เก็บหรือคืนทีละก้อน ไม่มีเส้นทางพิเศษ
  — เอเจนเขียนไฟล์แบบที่มันเขียนอยู่แล้ว เอกสารที่เปิดอยู่รับการเปลี่ยนเป็นฮังก์
- **Ghost text จากสมองตัวไหนก็ได้** FIM endpoint ที่มี (DeepSeek, OpenAI-style, Ollama) และ chat
  พร้อมมาร์กเกอร์ `<CURSOR>` สำหรับที่เหลือ หนึ่งคำถามต่อการหยุดพิมพ์ ทิ้งเมื่อพิมพ์ต่อ
  สามสิบครั้งต่อนาทีแล้วเงียบ ทุกครั้งลงตาราง `fill_calls` (โทเค็น, ms, แคช, รับไหม)
  เป็นชั้นสมองของตัวเองในการ์ดตั้งค่า แผนหมดก็ส่งต่อให้ผู้ให้บริการอื่น
- **Language server อยู่ข้างหลัง Monaco** completion, hover, go-to-definition, Problems list,
  `#` symbols — ผ่านซ็อกเก็ตของเอนจิน ลูกค้าคนละตัวกับ diagnose ของเอเจน พิสูจน์บน gopls:
  60 completion สำหรับ `strings.` มาร์กเกอร์แดงบนบรรทัดผิด
- **หน้าภาษาเป็นแคตาล็อก 44 เซิร์ฟเวอร์** ในสี่แถบ (มีแล้ว · กดติดตั้งได้เลย · ต้องมีเครื่องมือก่อน ·
  ใส่เอง) ตอนแรกมีห้าตัวในแมป ผู้ใช้ Python เห็นห้าแถวและไม่มีทางไปแถวที่หก ทางติดตั้งมีสองทาง:
  ผ่าน toolchain แบบเดิม และ **ดาวน์โหลดจาก GitHub release ของเซิร์ฟเวอร์เอง** (asset ตาม OS/arch
  ตรวจ SHA-256 เมื่อเขาเผยแพร่ กัน zip-slip) ทางที่สองเสนอเฉพาะเมื่อกดเท่านั้น ตรวจกับ github.com
  จริง: 11 จาก 12 แพตเทิร์น asset ตรงกับ release วันนี้ texlab โหลดและรันได้ หน้าแสดงเฉพาะภาษาที่เลือก
  พร้อมโลโก้ (42 มาร์ก) แคตาล็อกทั้งหมดอยู่หลังปุ่มเลือกภาษา ภาษาที่เลือกแต่ไม่มีเซิร์ฟเวอร์ขึ้นสีอำพัน
  หนึ่งบรรทัดบนสุด และ**ไฟล์ที่ภาษายังไม่มีเซิร์ฟเวอร์ได้หนึ่งบรรทัดเหนืออีดิเตอร์** พร้อมปุ่มที่ไปเอามา
  (PATH walk ~150 ms จ่ายครั้งเดียวต่อรัน) แถวที่ผู้ใช้เขียนเองอยู่ใน `<data>/lsp/custom.json`
- **Git** จัดรูปแบบตอนเซฟ (Ctrl+S เท่านั้น) บรรทัดที่เปลี่ยนใน gutter blame ที่บรรทัดเคอร์เซอร์
  (ถามครั้งเดียวต่อช่วงพิมพ์) เทียบกับ HEAD ข้างกัน และ**คอมมิตทีละฮังก์** — ผ่าน index ชั่วคราวที่สร้าง
  จาก HEAD ไม่แตะ index จริงที่เชลล์อาจใช้อยู่ update-ref ใช้ HEAD เป็น compare-and-swap
  หน้า Git เป็นสแต็กเดียว (working tree + timeline) ทั้งในแผง Editor และแท็บ Git ของ workbench
- **แบ่งจอสองฝั่ง** Ctrl+\ และปุ่มบนแท็บ · **รันเทสต์ใต้เคอร์เซอร์** ▶ บนหัวไฟล์เทสต์ ลง dock terminal ·
  **แทนที่ทั่วโปรเจกต์** · `.editorconfig` · Ctrl+F ในสกรอลแบ็กของเทอร์มินัล · Ctrl+C ถึงเชลล์บนคีย์บอร์ดไทย
- **ไฟล์ SQLite เปิดเป็นตาราง** อ่านอย่างเดียว (`mode=ro` + `query_only`) SELECT/WITH/EXPLAIN เท่านั้น
  ทีละคำสั่ง หน้าละไม่เกิน 1,000 แถว เซลล์ตัดที่ 2,000 ตัวอักษร นับตารางใต้นาฬิกาสองวินาที
  หาเจอทั้งจากชื่อและจาก 16 ไบต์แรก ไดรเวอร์อยู่ใน go.mod แล้ว ไม่มี dependency ใหม่
- **สีจริงสำหรับ Svelte, Vue, Astro, TOML, Prisma, Zig** จาก grammar ของ VS Code โหลดเมื่อใช้ครั้งแรก
  และทุกภาษาที่ Monaco มี (.ps1 เคยเป็นข้อความเปล่า)
- Explorer มีเมนูบนแถว (เปลี่ยนชื่อในที่ · คัดลอกเส้นทาง · เปิดที่เก็บ · ลบ) ปุ่มไฟล์ใหม่/โฟลเดอร์ใหม่
  แผนกับแผนที่โค้ดเปิดเป็นห้องบนแถบกลาง เบราว์เซอร์และเทอร์มินัลของผู้ใช้เองอยู่หลัง + ของแถบ

**จงใจไม่ทำ** ทางดาวน์โหลดจาก release ไม่รันเงียบ ๆ ตอนใช้ครั้งแรก (ยังเป็น toolchain เท่านั้น) ·
terraform-ls เผยแพร่บน releases.hashicorp.com จึงเป็นแถวใส่เอง · ghost text ไม่มี session, transcript,
เครื่องมือ หรือความจำ — เป็นคำถามเดียว ไม่ใช่เทิร์น

## เครื่องมือ MCP เป็นชั้นวาง

**เดิม** ทุกเครื่องมือของทุกเซิร์ฟเวอร์บนโต๊ะถูกส่งเป็น schema เต็มทุกคำขอ วัดบนเจ็ดเซิร์ฟเวอร์ของเจ้าของ:
vercel 212 เครื่องมือ ≈ 121k โทเค็น, kinocut 198 ≈ 42k, canva 34 ≈ 23k, github 47 ≈ 13k
ขณะที่บล็อกของโต๊ะเองคือ 33 เครื่องมือ ≈ 9.8k — เซิร์ฟเวอร์เดียวคือหกถึงสิบสองเท่าของโต๊ะ ทุกคำขอ
**รุ่นนี้** เครื่องมือของเซิร์ฟเวอร์ถูกตั้งชื่อไว้ในดัชนีสกิลใต้พื้นที่ `mcp` หนึ่งบรรทัดต่อเซิร์ฟเวอร์
(ชื่อเครื่องมือ หรือตั้งแต่ 30 ตัวขึ้นไปเป็นกลุ่มตามเรื่องพร้อมจำนวน อ่านจากชื่อโดยตัดชื่อเซิร์ฟเวอร์กับ
กริยานำ — github อ่านว่า issue · pull · commit · file ไม่ใช่ get · list · create; 212 ของ vercel
อ่านเป็น 37 เรื่องใน 135 โทเค็น) และ dispatcher ส่ง definition ต่อเมื่อแชทนี้เอื้อมถึงมันครั้งแรก
ไม่ว่าเรียกชื่อตรง ๆ หรือ `mcp_view` ดู schema ก่อน เซิร์ฟเวอร์ห้าเครื่องมือหรือน้อยกว่าขี่แบบเดิม
ชุดที่โหลดแล้วเป็นของแชทและรอด re-bootstrap ถึงพนักงาน ลูกมือ การ์ด และแชทที่เปิดใหม่ทั้งหมด
บล็อกเครื่องมือเป็น dial สด — definition ที่โหลดในรอบนี้อยู่ในคำขอรอบถัดไป

มิเตอร์บริบทวาด **MCP เป็นแถวของตัวเอง** ระหว่างเครื่องมือกับข้อความ เปิดดูเครื่องมือที่บริดจ์มาพร้อม
ชื่อเซิร์ฟเวอร์ และบอกว่าชั้นวางเก็บอะไรไว้นอกคำขอ

## ห้องความสามารถวาดใหม่ในรูปหน้าปลั๊กอิน

**เดิม** ราง 748px ที่ 900px มีหัวข้อกับแถวย่อย หน้า placement สองหน้าและ picker แยกกัน
**รุ่นนี้** เจ้าของวางหน้าปลั๊กอินของผลิตภัณฑ์อื่นบนโต๊ะแล้วขอรูปร่างนั้น DESIGN.md §1 ให้ยืมกรอบได้แต่ห้าม
ยืมเครื่องประดับ — ทุกสี รัศมี และคำเป็นของแอปเอง

- รางเป็นหกแถว หนึ่งเรื่องต่อแถว (MCP server · สกิล · เครื่องมือในตัว · ชุดคำสั่ง · การใช้คอมพิวเตอร์ ·
  การเชื่อมต่อ) สูง 272px ไม่มีป้ายไหนถูกตัด
- **MCP เป็นหน้าเดียวและแสดงเฉพาะ MCP** เซิร์ฟเวอร์ที่ติดตั้งเป็นไทล์ (สถานะเป็นสีและคำ) คลังเป็นแถว
  ที่บอกว่าจะขออะไรจากคุณ (ต้องเข้าสู่ระบบ / ต้องใส่คีย์ / รันในเครื่องนี้) กลุ่มของชั้นวางเป็น pill
  ค้นหาเดียวครอบทั้งสองครึ่ง หน้า placement สองหน้าและ picker หายไป — **ใครใช้เซิร์ฟเวอร์อยู่ในแท็บ
  ใครใช้ ของชีต** มอบให้โต๊ะหรือเอเจนจากฟอร์มเดียวกับที่ตั้งค่ามัน
- ชีตเป็น**ไดอะล็อกกลางจอ** ช่องมีชื่อ คีย์ปิดบัง ปุ่มบันทึกสว่างต่อเมื่อมีอะไรต่าง ปิดชีตที่แก้แล้วถามก่อน
  บันทึกเซิร์ฟเวอร์หนึ่งตัวไม่ตัดตัวอื่นอีก (manager ถูก reconcile ไม่ใช่สร้างใหม่)
- สกิล เครื่องมือในตัว การใช้คอมพิวเตอร์ การเชื่อมต่อ ชุดคำสั่ง — รูปเดียวกันทั้งหมด ชีตของสกิลวาดเป็น
  แถว (ที่มา พื้นที่ หนึ่งบรรทัดเป็นย่อหน้า ค่าอยู่ขวา) ผู้ช่วยกับโค้ดยืนหน้าสุดบนพนักงานเฉพาะทาง
  การ์ดหัวคือชั้นวางของมัน
- โหลดครั้งแรกของห้อง retry และเขียนความล้มเหลวลงหน้า MCP — ไทล์ไม่หายไปเงียบ ๆ อีก
