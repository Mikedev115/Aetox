# 🧹 Aetox v1.5.25

ไม่ใช่หายเงียบๆ และรอบนี้ไม่มีฟีเจอร์ใหม่ ไม่มีอะไรที่คุณใช้อยู่เปลี่ยนวิธีทำงาน

## 🚫 Google Antigravity ถูกถอดออกทั้งระบบ

v1.5.23 เปิดตัว provider นี้พร้อมป้าย `RiskRestricted` สีเหลืองอำพันในหน้าตั้งค่า บอกว่าเซสชันนี้ยืม
client ID ของ editor ต้นทาง — รุ่นนี้เลือกทางตรงข้าม: **ไม่ให้ Aetox ไปแตะโควตา preview ของ Google
ผ่าน client ของผลิตภัณฑ์อื่นเลย**

### ทำไมต้องถอด ไม่ใช่แค่เตือน

**ข้อกำหนดของ Google เขียนเคสนี้ไว้ตรงๆ** — [Antigravity Additional Terms](https://antigravity.google/terms)
ระบุการเข้าถึงบริการด้วยซอฟต์แวร์ของบุคคลที่สาม พร้อมยกตัวอย่างปลั๊กอิน OAuth ไว้ในวงเล็บ
และให้ผลลัพธ์เป็น **ระงับหรือยกเลิกบัญชี** ไม่ใช่ตัดโควตา

Google ลงมือแล้ว — [discussion #20632](https://github.com/google-gemini/gemini-cli/discussions/20632)
บันทึกการแบนที่เกิดขึ้นจริง ขั้นตอนยื่นเรื่องขอคืนสิทธิ์ และ **แบนถาวรถ้าทำซ้ำครั้งที่สอง**

สิ่งที่ผู้ใช้จะเสียถ้าโดนคือ **บัญชี Google ทั้งบัญชี** ไม่ใช่โควตาของ Aetox —
คำเตือนที่ผู้ใช้กดข้ามได้ ไม่ใช่ราคาที่ควรจ่ายกับความเสี่ยงระดับนั้น

### Credential เก่ากลายเป็นใช้ไม่ได้ ไม่ใช่แค่ซ่อน

`"antigravity"` เข้า `removedProviders` ใน `internal/oauth/store.go` แล้ว —
`oauth.json` ที่เคยเขียนไว้ตอน provider ยังอยู่จะอ่านเป็น signed out: ไม่มี `Get` ไม่มี token source
ไม่ refresh และไม่ถูกส่งออกไปอีก `TestRemovedProviderCredentialsAreDropped` มีเคส `antigravity`
เป็นตัวอักษรค้ำไว้ตรงๆ เพื่อให้คำรับประกันนี้ถูกทดสอบจริง ไม่ใช่แค่เขียนไว้

### อะไรที่ไม่ได้แตะ

**ช่องทางอื่นอยู่ครบเหมือนเดิม** กลุ่มที่ล็อกอินได้กลับมาเป็นสามเจ้าเท่าเดิม — ChatGPT (Codex) ·
GitHub Copilot · OpenRouter — และเจ้าที่ใส่คีย์เอง (Anthropic, Gemini, OpenAI, DeepSeek, Kilo, xAI,
ThaiLLM, Ollama, LM Studio และที่เหลือ) ไม่มีอะไรเปลี่ยนเลยแม้แต่เจ้าเดียว

`bench.ps1` และ `BENCHMARK.md` ที่วัดตัว Antigravity **IDE** ในฐานะโปรแกรมคู่แข่งบนเครื่องเดียวกัน
รวมถึงคอมเมนต์ใน `style.css` และหน้าเว็บที่อ้างว่าองค์ประกอบบางอย่างมาจากไหน — **เก็บไว้**
เพราะนั่นคือชื่อโปรแกรม ไม่ใช่ช่องทางไปเอาโควตา การลบที่มาของดีไซน์คือการเสียข้อมูลโดยไม่ได้อะไรกลับมา
บันทึกการปล่อยรุ่นเก่า (`v1.5.23`, `v1.5.24`) ก็ไม่ถูกแก้ย้อนหลังเช่นกัน — บันทึกที่บอกว่ารุ่นไหน
เคย ship อะไรไป ยังเป็นความจริงหลังของนั้นถูกถอดออก

เหตุผลเต็มอยู่ที่ [`docs/DECISIONS.md` §242](../DECISIONS.md)
