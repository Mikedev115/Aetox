# 🧩 Aetox v1.5.21

รุ่นแก้บั๊กรุ่นเล็ก **หนึ่งเรื่อง**: เมนูเลือกโมเดลใต้ช่องพิมพ์ มีบางกรณีที่แถว
โมเดลกลายเป็นตัวหนังสือเฉย ๆ กดไม่ได้ ทั้งที่เมนูนั้นมีไว้เปลี่ยนโมเดลเป็นหลัก

---

## แถวโมเดลที่กดไม่ได้ ตอนที่ผู้ให้บริการยังไม่ยอมบอกรายชื่อ

**เรื่องเดิม** เปิดเมนูใต้ช่องพิมพ์ แล้วเห็น ระดับการอนุมัติ กับ ผู้ให้บริการ
มีลูกศรให้กดทั้งคู่ ส่วน โมเดล เป็นชื่อโมเดลเฉย ๆ กดไม่ลง เกิดกับผู้ให้บริการที่
Aetox ขอรายชื่อโมเดลไม่สำเร็จ เช่น Ollama หรือ LM Studio ที่เซิร์ฟเวอร์ยังไม่ได้
เปิด และผู้ให้บริการที่ยังไม่เปิดให้คีย์ของคุณอ่านรายชื่อ

ที่มันเป็นแบบนั้นเพราะฝั่งหลังบ้านตั้งใจไม่เดาชื่อโมเดลให้ runtime ที่รันในเครื่อง
(เครื่องคุณมีเฉพาะโมเดลที่คุณ pull มาเอง ชื่อที่เดาไว้ล่วงหน้าจะพังกับเซิร์ฟเวอร์ที่
ทำงานปกติ) พอไม่มีรายชื่อ มันจึงส่ง "ลิสต์ว่าง" มาให้หน้าจอ พร้อมข้อตกลงที่เขียนไว้
ในโค้ดว่า ลิสต์ว่างแปลว่าให้เปิดช่องพิมพ์ชื่อโมเดลเอง หน้าตั้งค่าทำตามข้อตกลงนี้มา
ตลอด เมนูใต้ช่องพิมพ์ไม่ได้ทำ มันวาดเป็นข้อความตาย ๆ แล้วฝากคอมเมนต์ไว้ในโค้ดว่า
"ไปตั้งในหน้าตั้งค่าเอา" ซึ่งคนใช้งานไม่มีทางเห็น

**รุ่นนี้** แถวโมเดลมีสามสถานะแทนสองอย่างเดิม

- **มีรายชื่อ** ก็เป็นลูกศรให้เลือกเหมือนเดิมทุกอย่าง ราคาต่อล้านโทเคนยังอยู่
- **กำลังโหลด** ก็บอกว่ากำลังโหลด เมื่อก่อนไม่มีสถานะนี้ ทุกครั้งที่เปิดเมนู
  มันจึงแวบเป็นหน้าตาแบบ "ไม่มีรายชื่อ" หนึ่งรอบ ก่อนรายชื่อจะมาถึง
- **โหลดแล้วว่าง** ก็เป็นช่องพิมพ์ที่เติมชื่อโมเดลที่ใช้อยู่ไว้ให้แล้ว พร้อมปุ่ม ใช้
  พิมพ์ชื่อโมเดลที่คุณ pull ไว้แล้วกด Enter ได้เลย

ใต้แถวมีบรรทัดบอกว่ายังไม่ได้รายชื่อจากใคร พร้อมปุ่ม ลองใหม่ สำหรับคนที่เพิ่งไป
เปิดเซิร์ฟเวอร์ จะได้ถามซ้ำได้โดยไม่ต้องปิดเมนูแล้วเปิดใหม่

**สิ่งที่จงใจไม่ทำ** ไม่ใส่ชื่อโมเดลสำรองให้ Ollama เหตุผลเดิมยังถูกอยู่ และรุ่นนี้
ยังไม่ได้บอก **สาเหตุ** ว่าทำไมรายชื่อถึงว่าง เซิร์ฟเวอร์ไม่ได้เปิด กับคีย์ที่ถูกปฏิเสธ
เดินทางมาถึงหน้าจอเป็นลิสต์ว่างเหมือนกัน การแยกสองอย่างนี้ต้องแก้ถึงฝั่งหลังบ้าน
ซึ่งเป็นงานคนละชิ้นกับการซ่อมแถวที่กดไม่ได้

**เทสต์ที่เพิ่มในรุ่นนี้** `desktop/frontend/src/test/modelCustomId.test.ts` สี่ข้อ:
ช่องพิมพ์เติมชื่อโมเดลที่ใช้อยู่ · ชื่อที่พิมพ์ถูกส่งไปสลับจริง · บรรทัดบอกชื่อ
ผู้ให้บริการและกดถามซ้ำแล้วลูกศรกลับมา · รายชื่อที่มาช้าไม่วาดหน้าตาแบบว่างระหว่างรอ
