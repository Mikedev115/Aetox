# 🧰 Aetox v1.5.27

รุ่นนี้แก้กล่องเครื่องมือที่กระโดดขึ้นลงตอนรันงานยาว ๆ เอาสองสิ่งที่ไม่เคยถูกวาดออกจาก
การ์ดงานขนาน และปิดช่องที่ผู้ให้บริการปฏิเสธคำขอทั้งใบ

---

## 🧵 งานขนานที่รันหลายรอบติดกัน — แต่ละรอบมีกล่องของตัวเอง

**อาการที่เห็น:** เทิร์นยาว ๆ ที่โมเดลเรียกเครื่องมือเป็นชุด ๆ ติดกันหลายรอบโดยไม่พูดอะไรคั่น
กล่องเครื่องมือจะกางขึ้น พับลง แล้วกางกลับไปสูงเท่าเดิม พับซ้ำ ขึ้น ๆ ลง ๆ

**ต้นเหตุ — สามเงื่อนไขที่ชนกันใน `Chat.svelte`**

| เงื่อนไข | ผลที่ได้ |
|:--|:--|
| `shownOwn = working ? own : runOwn` | รอบใหม่หนึ่งรอบดึง **ทุกแถวของ stretch** ออกมาแสดง ไม่ใช่แค่แถวของรอบนั้น |
| `foldable = !working && doneOwn.length > 0` | พับได้ทันทีที่ "ไม่มีอะไรวิ่งอยู่" ซึ่งเกิด**ทุกรอบ** ไม่ใช่ตอน stretch จบ |
| `if (running) armed.delete(key) else settlePhase(key)` | หลังพับครั้งแรก `landing[key]` ถูกล้าง รอบถัดไปจึงหายไปในเฟรมเดียวโดยไม่มีการเคลื่อนไหว |

ตัวคูณที่ทำให้เจอบ่อย: **การคิดไม่เปิด stretch ใหม่** (`turnPhases.ts` บวกเข้า `thinkSecs`
เฉย ๆ) ฉะนั้นการรันที่โมเดลเงียบคิดอยู่หลายรอบจึงอยู่ใน stretch เดียวทั้งหมด และชนครบทุกข้อ

**ที่เปลี่ยน** — "รอบ" กลายเป็นหน่วยที่กล่องถืออยู่ ไม่ใช่ทั้ง stretch

- ระหว่างที่ยังมีเครื่องมือวิ่ง กล่องแสดงเฉพาะแถวของรอบนั้น (`own.slice(folded[key])`)
  ไม่ใช่ทุกแถวที่ stretch เคยเรียก
- ทุกรอบได้การส่งมอบและการพับของตัวเองเหมือนรอบแรก — เดิมรอบที่สองเป็นต้นไปไม่มีจังหวะพับเลย
- `folded` เลื่อนเมื่อรอบถูกเก็บจริง และการคลิกของผู้ใช้ (`readerOwns`) ยังคุมการพับไว้เองตลอด
  การแก้ไม่แย่งการพับคืนจากคนที่กำลังอ่านอยู่

**สิ่งที่ผู้ใช้จะเห็นต่างจากเดิม** — กล่องยังกางและพับรอบละครั้งเหมือนเดิม (นั่นคือสิ่งที่คุณเลือก
ไว้: ให้เห็นสถานะปัจจุบัน) แต่รอบที่พับไปแล้วจะไม่ถูกกางซ้ำ และรอบใหม่จะไม่หายวับในเฟรมที่
ผลลัพธ์สุดท้ายกลับมา

มีเทสต์คุมพฤติกรรมนี้ถาวรใน `src/test/Chat.tools.test.ts` — "gives every round in one stretch
its own box, and its own fold"

## 🧰 การ์ดงานขนานเลิกห่อซ้อนสองชั้น

การ์ดที่รวมงานขนานกันถือคลาส `search-card` ซึ่งมี **เส้นขอบ รัศมี และพื้นสีเดียวกับกล่อง
เครื่องมือที่มันอยู่ข้างในเป๊ะ** ทั้งที่ทั้งสองก้อนอยู่ในกล่องเดียวกันอยู่แล้ว เส้นชั้นในจึงไม่ได้
บอกอะไรเพิ่ม ขณะที่หัวของการ์ด ("รันขนานกัน · N งาน") บอกเรื่องนั้นอยู่แล้ว

ตอนนี้มันเป็นท่อนหนึ่งของกล่อง: แถวใช้ระยะ 8px/10px เท่ากับแถวอื่นในกล่อง เส้นคั่นระหว่างแถว
เป็นของกล่อง และไม่มีกรอบ/รัศมี/พื้นของตัวเอง สิ่งที่ยังอยู่ครบคือหัวชุด ตัวเลขคู่กับชื่อ
บรรทัดสรุปท้าย และสีประจำตระกูลของงาน

**สองอย่างที่เจอระหว่างทาง และอยู่ในภาพหน้าจอเดียวกันทั้งคู่**

- `chat.doneBadge` — คีย์ที่ไม่มีอยู่ใน `th.ts` / `en.ts` / `zh.ts` เลย ผู้ใช้จึงเห็นชื่อคีย์ดิบ ๆ
  กลางการ์ดในทุกภาษา เปลี่ยนเป็น `tool.parallelBadge` พร้อมใส่คำจริงทั้งสามภาษา
- ไอคอนหัวการ์ดขอชื่อ `cpu` ซึ่ง**ไม่มีในชุดไอคอน** (`icons.ts`) จึงไม่เคยถูกวาดเลย — ช่อง 13px
  ว่างอยู่ตรงนั้นมาตลอดโดยไม่มีอะไรบอก เปลี่ยนเป็น `layoutList`

## ⚙️ ผู้ให้บริการและการตั้งค่า

**ปลายทางที่ปฏิเสธคำขอทั้งใบ ไม่ทำให้เทิร์นตายอีกต่อไป** (`openai_compatible.go`)

ปลายทาง OpenAI-compatible บางเจ้าไม่รับ `tools` หรือไม่รับฟิลด์ reasoning เลย และตอบ 400
กลับมา — เดิมเทิร์นจบตรงนั้น ตอนนี้ระบบอ่านคำปฏิเสธนั้นแล้ว **ลองใหม่หนึ่งครั้งโดยไม่ส่ง
ส่วนที่ถูกปฏิเสธ** พร้อมจำไว้ต่อผู้ให้บริการ + โมเดลนั้น เพื่อไม่ต้องเสียเทิร์นละหนึ่งครั้งตลอดไป
ทำแบบเดียวกันทั้งเส้นทางธรรมดาและเส้นทางสตรีม (คำปฏิเสธมาถึงก่อนเฟรมแรก จึงยังไม่มีการพิมพ์
อะไรออกไปให้ต้องเรียกคืน)

`SupportsToolCalling()` ก็อ่านรายการที่จำไว้แล้วเช่นกัน — โมเดลที่รู้แล้วว่าไม่รับ tools
จะไม่ถูกยื่น tools ให้ตั้งแต่แรก

**`openai-compatible` ไม่ประกาศว่ามีปุ่มระดับความคิดอีกต่อไป**

แถวนี้เป็นปลายทางทั่วไปที่เราไม่รู้อะไรเลย จึงไม่ควรมีตัวควบคุมที่ทำอะไรไม่ได้
(แถว "ระดับความคิด" ไม่เคยขึ้นกับผู้ให้บริการนี้อยู่แล้ว และยังไม่ขึ้นเหมือนเดิม)

**การตั้งค่า:** พิมพ์ API key ไว้แล้วกดชื่อผู้ให้บริการที่เลือกอยู่แล้วซ้ำ — เดิมคีย์ที่พิมพ์
ถูกล้างทิ้ง ตอนนี้ตรวจว่าสลับจริงก่อนจึงล้าง
