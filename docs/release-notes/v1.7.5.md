# 🧭 Aetox v1.7.5

รุ่นนี้แก้จุดจับลากระหว่างแชทกับเบราว์เซอร์ในตัวที่ native WebView2 ทับจนผู้ใช้ไม่สามารถ
ขยายหรือลดแผงได้ในตัวติดตั้งจริง พร้อมรวมงานปรับความแม่นของแชท มาร์กดาวน์ และการเลือกใช้
ความรู้ฐานข้อมูลที่อยู่บน `main` หลัง v1.7.4

---

## เส้นแบ่งเบราว์เซอร์กลับมาลากได้

- เว้นพื้นที่ด้านซ้ายของ native browser window 12 CSS px เพื่อไม่ให้ child HWND ซึ่งวาดและ
  รับเมาส์เหนือ DOM ทับ resize seam แม้มีการปัดเศษพิกัดจาก DPI
- ขยายพื้นที่รับเมาส์ของเส้นแบ่งเข้าฝั่งแชทอีก 5px ซึ่ง native browser ไม่มีทางครอบได้
- แสดงเส้นแบ่งในสถานะปกติ ไม่ต้องเดาตำแหน่งจาก hover และปิด touch scrolling ขณะกำลังลาก
- เพิ่ม regression test ที่ยืนยันว่า native HWND เริ่มหลังพื้นที่คุ้มกัน และอัปเดตชุดทดสอบ
  drag/device viewport ให้ตรวจพิกัดแบบ asymmetric frame

## งานที่รวมมากับรุ่น

- แชทวางข้อความที่แทรกระหว่างเทิร์นกลับในตำแหน่งที่ถูกต้อง
- ตัวแสดง Markdown กู้ SVG ที่อยู่ใน code fence ซ้อนผิดรูปแบบได้
- เพิ่มและปรับเส้นทาง skill ฐานข้อมูลแบบ local-first พร้อมผล benchmark ที่ทำซ้ำได้
- เพิ่มบันทึกประเมินการค้นคว้า/ให้เหตุผล และข้อเสนอการส่งมอบ personal secretary สำหรับ v1.8.0
