## README — ขยายคำอธิบายระบบควบคุมเบราว์เซอร์

**เรื่องเดิม** บรรทัดที่บอกว่าเรามีระบบควบคุมเบราว์เซอร์เป็นของเราเองมีอยู่แค่สองบรรทัด
บอกแค่ว่า "กดถูกปุ่มโดยไม่ต้องเดาพิกัด" ซึ่งไม่ได้อธิบายว่ากลไกที่แท้จริงคืออะไร
และไม่ได้บอกว่าทำไมถึงต่างจากเจ้าอื่น

**รุ่นนี้** ขยายเป็นหกบรรทัดที่อธิบายสิ่งที่เกิดขึ้นจริง:

- ระบบ `browser read` ชี้ตำแหน่งและป้ายชื่อ element ทุกจุดบนหน้าให้โมเดล
- โมเดลประมวลผลเป็นข้อความล้วน แล้วสั่ง `click ref=N` ไม่มีการเดาพิกัด x,y
- โมเดลที่ไม่มี vision เลยขับเบราว์เซอร์ได้เท่ากับโมเดลที่มองเห็น
- ลงท้ายด้วยปรัชญาหลักของโปรเจกต์: **"หัวใจไม่ใช่ความสามารถของโมเดล แต่คือทั้งระบบ"**

อัปเดตทั้ง `README.md` (ภาษาอังกฤษ) และ `README.th.md` (ภาษาไทย)

**สิ่งที่ไม่ได้เปลี่ยน** ไม่มีการแก้โค้ดใด ๆ ระบบทำงานเช่นเดิมทุกอย่าง
รุ่นนี้บันทึกสิ่งที่มีอยู่แล้วให้ผู้อ่านเห็นภาพชัดขึ้น
