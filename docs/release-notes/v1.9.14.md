# 🧩 Aetox v1.9.14

รุ่นหน้าตา: หน้าว่างของแผงขวาแต่ละประตูมีหน้าตาของตัวเอง โค้ดมีเงาเมืองโค้ด ผู้ช่วยมีโต๊ะทำงาน
ทีมมีบริษัท และห้องทำงานของประตูทีมวาดใหม่บนพื้นเดียวกัน พร้อมทางกลับเข้าห้องบริษัท

## ห้องทำงานของประตูทีม วาดใหม่บนเงาบริษัท

**เดิม** ห้องทำงานเป็นหัวเรื่องชิดซ้ายกับกล่องว่างกล่องเดียว หน้าตาคนละแบบกับหน้าเริ่มของแผงขวาและหน้าแชท
และตั้งแต่แท็บบริษัทถูกถอดออก (29 ก.ย.) ประตูทีมไม่มีปุ่มไหนพากลับไปที่ห้องบริษัทเลย

**รุ่นนี้** ห้องทำงานยืนบนพื้นตารางแบบเดียวกับหน้าเริ่มของแผงขวา ด้านหลังเป็นเงาบริษัทจาง ๆ ลานกลาง
ปีกแผนก โต๊ะ คน และจอบางจอกระพริบเหมือนงานกำลังวิ่ง ทุกชิ้นบนหน้าเป็นกล่องยกแบบช่องพิมพ์แชท

- **การ์ดบริษัท** บนสุด บอกชื่อบริษัทกับจำนวนแผนก ทีม เอเจนจริงของเครื่องนี้ กด **เข้าบริษัท** แล้วแอปเปิดพอร์ต
  ศูนย์บัญชาการและพาไปที่ห้องบริษัทในแท็บข้างแชท
- **การ์ดศูนย์บัญชาการ** ชุดเดียวกับในตั้งค่า เปิดในแอป เปิดในเบราว์เซอร์ของเครื่อง คัดลอกที่อยู่ ปิดพอร์ต
- ห้องทำงานที่บันทึกไว้ยังเป็นการ์ดเดิม ขั้น ทีม บรีฟ และปุ่มเริ่ม

ไม่ได้ทำ: แท็บบริษัทไม่กลับมาเป็นแท็บแยก (ซ้ำกับศูนย์บัญชาการ) ทางเข้าคือการ์ดบนห้องทำงาน

## หน้าว่างของแผงขวา แยกตามประตู

**เดิม** ทุกประตูได้หน้าเดียวกัน หัว "พื้นที่สำหรับลงมือ" กับโลโก้ใหญ่เป็นเงา

**รุ่นนี้**

- **โค้ด** หัว "โต๊ะโค้ด" ด้านหลังเป็นเมืองโค้ด ตึกละไฟล์ ไฟล์ที่เปลี่ยนติดไฟ เทอร์มินัลเป็นการ์ดใหญ่
  บอกชื่อเชลล์กับเคอร์เซอร์กระพริบ ตามด้วย Git, Pull requests, แผนที่โค้ด แล้วค่อยเครื่องมืออื่น
- **ผู้ช่วย** หัว "โต๊ะผู้ช่วย" ด้านหลังเป็นโต๊ะทำงาน แล็ปท็อปจอติด สมุด แก้ว ต้นไม้ และฟองแชทที่กำลังพิมพ์
  เบราว์เซอร์ยังนำเหมือนเดิม และมีแถว **หยิบต่อได้** ชิ้นงานล่าสุดสองชิ้นของสัปดาห์กับหน้าเว็บที่เอเจนเปิดล่าสุด
  กดแล้ววางกลับบนโต๊ะทันที ไม่มีอะไรให้หยิบก็ไม่วาดแถวนี้
- **ทีม** ใช้เงาบริษัทเดียวกับห้องทำงาน

เงาทั้งสามเป็นภาพนิ่ง วาดครั้งเดียว ไม่มีอะไรวิ่งเบื้องหลัง ชิ้นที่กระพริบเป็นแค่ CSS และหยุดเมื่อเครื่องตั้งลดการเคลื่อนไหว

ไม่ได้ทำ: หน้าแชทแรกของแต่ละประตูยังใช้โลโก้เป็นเงาเหมือนเดิม

เทสต์ที่แก้ในรุ่นนี้: `workbenchStart.test.ts` (เงาตามประตู · ลำดับของประตูโค้ด · หัวภาษาไทยใหม่)
และแถวไกด์ใหม่ `lines.company`
