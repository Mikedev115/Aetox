# 🧩 Aetox v1.9.5

รุ่นนี้ทำให้โต๊ะโค้ดกลับไปหางานที่คุณเปิดไว้ ไม่ใช่แชทใหม่สุดหรือหน้าที่เพิ่งโหลดใหม่
รวมพนักงานกับลูกมือไว้ในหน้าบุคลากร และให้โมเดลเป็นของแต่ละแชท
หน้า Git ดูสาขาอื่นได้โดยไม่สลับงาน ส่วนคำสั่งสกิลเริ่มทำงานตามคำขอจริงแทนสรุปเอกสารแล้วจบ

## บุคลากรอยู่หน้าเดียว เห็นยศและเลือกคนได้ชัดขึ้น

**เดิม** พนักงานและลูกมืออยู่คนละหน้า หัวหน้าบริษัท แผนก และทีมแยกกันได้ไม่ชัด
**รุ่นนี้** หน้าบุคลากรรวมรายชื่อ ค้นหา กรองยศหรือแหล่งที่มา เลือกแก้ไข เปิดแชท และสลับการทำงานได้

- ใช้ยศและสัญลักษณ์เดียวกันทั่วหน้าทีม องค์กร ภารกิจ และออฟฟิศ
- เก็บขอบเขตของหัวหน้าไว้เมื่อแก้โปรไฟล์ ไม่ทำให้ความเชี่ยวชาญหาย
- สวิตช์ลูกมือแยกจากพนักงานหรือทีม การปิดลูกมือทั่วไปไม่ปิดพนักงานของทีมตามไปด้วย
- ลูกมือยังเป็นชุดตายตัว และไม่ได้เปิดให้คุยตรงแบบพนักงาน

## Agent กับ Editor กลับแชทเดิม และไม่สร้าง editor ใหม่ทุกครั้ง

**เดิม** สลับโหมดแล้วอาจได้แชทล่าสุดแทนแชทที่เลือก แชทเปล่าไม่มีประวัติให้กลับมา และ editor ถูกสร้างใหม่เมื่อกลับ
**รุ่นนี้** จำแชทที่เลือกแยกตามโปรเจกต์และโหมด รวมทั้งแชทเปล่าที่ยังไม่มีข้อความ

- กลับมุมมองที่รู้จักได้ทันที แต่ยังไม่ส่งข้อความผ่านเอนจินของแชทเก่าขณะกำลังแนบแชทใหม่
- คลิกรัวรวมเป็นปลายทางล่าสุด ถ้าเปิดไม่ได้กลับมุมมองเดิมพร้อมบอกเหตุผล
- รักษาตำแหน่งเคอร์เซอร์ การเลื่อน และ editor ข้อความปัจจุบันได้ทั้งสองช่องของจอแบ่ง
- editor ที่ซ่อนไม่แย่งโฟกัสหรือกินคำสั่งเลื่อนไปบรรทัด สื่อและเบราว์เซอร์ไม่เล่นค้างลับหลัง
- draft เก็บแค่พิกัด ไม่ค้างเอนจิน ไม่เขียนประวัติเปล่าลงฐานข้อมูล และไม่จำข้ามการรีสตาร์ตเอนจิน
- ประวัติที่บันทึกแล้วต้องมาก่อน draft; ทีมหรือพนักงานที่ถูกลบยังถูกปฏิเสธตามประตูเดิม

## โมเดลเป็นของแต่ละแชท ไม่ถูกคำตอบช้าจากอีกแชทเขียนทับ

**เดิม** เปลี่ยนแชทระหว่างเลือกโมเดลหรือรอข้อมูลอาจทำให้สถานะของแชทเดิมมาทับแชทที่เปิดใหม่
**รุ่นนี้** โมเดลกับระดับคิดจำรายเซสชัน ผลสถานะมี ID และ revision ให้ตรวจว่าตรงแชทปัจจุบันก่อนใช้

- จัดคิวการเลือกขณะย้ายแชท และคืนสถานะเมื่อเปิดแชทไม่สำเร็จ
- รายชื่อผู้ให้บริการ hosted รวมสิ่งที่ปลายทางค้นพบกับ catalog โดยไม่ซ้ำ และใช้ catalog เป็นทางสำรอง
- local/custom ใช้รายชื่อของตัวเอง ไม่เติมโมเดลคลาวด์ให้เอง
- Codex รับรายชื่อแชทจาก catalog OpenAI โดยไม่เอาราคา API มาคิดแทนแพลนหรือเปลี่ยนโมเดลเริ่มต้น

## Git ดูสาขาอื่นได้โดยไม่เปลี่ยนสาขาที่ทำงาน

**เดิม** ประวัติตามสาขาปัจจุบัน เมนูสาขาอาจถูกกรอบแบ่งจอตัด และวันที่คั่นกราฟกินพื้นที่หัวเรื่อง
**รุ่นนี้** เลือกดูประวัติสาขาท้องถิ่นอื่นได้โดยไม่ checkout เปรียบเทียบกับสาขาที่ทำงาน และรวมหลังยืนยัน

- ก่อนรวมแสดงจำนวนคอมมิตแต่ละฝั่งกับสรุปไฟล์ที่เปลี่ยน ยืนยัน hash ทั้งต้นทางและปลายทาง
- ถ้าสาขาขยับหลัง preview ต้องเปรียบเทียบใหม่ ถ้ามีงานไม่คอมมิตปฏิเสธโดยไม่ stash หรือทิ้งไฟล์
- รวมแบบ merge/fast-forward ไม่เขียนประวัติใหม่ ไม่ push ให้อัตโนมัติ และ conflict ยกเลิกเฉพาะ merge ที่ปุ่มนี้เริ่ม
- ประวัติหน้าถัดไปตรึงหัวสาขาและตำแหน่ง ไม่ทำคอมมิตฝั่ง second-parent หายหรือเลื่อนเพราะมีคอมมิตใหม่
- วัน เวลา และหัวเรื่องเต็มอยู่ในรายละเอียดที่เปิด เมนูลอยพ้นกรอบแบ่งจอและอยู่ในขอบหน้าต่างแม้ปรับขนาดตัวอักษร
- โหลดประวัติทีละ 50 คอมมิตเมื่อกดเพิ่ม ข้อมูลไฟล์และ diff อ่านเมื่อเปิดรายละเอียดเท่านั้น รายชื่อสาขาใช้คำขอร่วมกันและจำกัดแถวที่วาด

## เรียกสกิลเพื่อทำงาน ไม่ใช่อ่านแล้วสรุปว่าเสร็จ

**เดิม** `/ชื่อสกิล` ที่เป็น SKILL.md เดินทางรันตรงเหมือนเครื่องมือ จึงอาจสรุปเอกสารแทนทำงานที่ขอ
**รุ่นนี้** เปิดเอกสารสดผ่าน `skill_view` ก่อนให้โมเดลเดิน workflow ตามคำขอเดิม พร้อมไฟล์แนบและหลักฐานการเปิดสกิล

- ถ้าข้อมูลไม่พอถามได้ ถ้าเปิดไม่ได้บอกว่างานยังไม่ได้ทำ
- สิทธิ์ของสกิล การอ่าน และงานเขียนยังตรวจแยกตามเดิม เอกสารไม่กลายเป็นสิทธิ์เหนือผู้ใช้
- ใช้ได้กับโมเดลข้อความล้วน หลักฐานยังอยู่หลังย่อบริบท และคำถามถัดไปไม่เปิดสกิลซ้ำเอง
- `/read` และเครื่องมือ built-in ยัง dispatch ตรง ไม่ถูกเปลี่ยนเป็น workflow ของเอกสาร

## หลักฐานงานโค้ดไม่ครบต้องบอก ไม่ใช่รายงานว่าไม่มี callers

**เดิม** language server ที่ยัง index ไม่ทันอาจตอบบางส่วนโดยไม่บอกว่าคำขออื่น timeout และจุดที่ถามอาจถูกแสดงแทนจุดประกาศ
**รุ่นนี้** `symbol` กับ `impact` เก็บคำเตือนแต่ละคำขอ ส่วนที่ตรวจไม่สำเร็จไม่ถูกนับเป็นศูนย์หรืออ้างว่าเช็คแล้ว

metadata ที่ timeout ลองซ้ำได้ครั้งเดียวเมื่อคำตอบอื่นพิสูจน์ว่า server พร้อม ไม่ลอง refusal, null ที่ถูกต้อง หรือ server เงียบ
ผลทดลอง runtime harness (เอกสารภายใน ไม่เผยแพร่แล้ว) ยังไม่ครบชุด และมีทั้งผลดีขึ้น คะแนนตก และงานที่ไม่ได้ทำ ไม่ใช่คำรับรองว่าทุกรุ่นหรือทุกโมเดลดีขึ้น

## อื่น ๆ ในรุ่นนี้

- เขียนหรือแก้ไฟล์ไม่เปิดแท็บเองหรือแย่งโฟกัส แสดง live text เฉพาะไฟล์ที่เปิดไว้ การเปิดผ่าน `desk open` ยังเป็นคำสั่งชัดเจน

- แท็บไฟล์ถาวร ปิดทั้งหมดได้ Explorer จำโฟลเดอร์และตำแหน่งเลื่อน พร้อมไอคอน Material หรือแบบเรียบ
- ถอดสกิลรีวิวโค้ดแยก งานตรวจ security/performance ยังทำได้ตามขอบเขตที่ขอ ไม่บังคับ workflow รีวิวเพิ่ม
