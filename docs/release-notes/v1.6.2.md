# 🧩 Aetox v1.6.2

รุ่นของบัญชี ChatGPT ที่ล็อกอินไว้แล้วแต่ Aetox ยังใช้ไม่คุ้ม — วาดรูปผ่านมันได้แล้ว
และระดับความคิดของมันมีครบเท่าที่ backend ให้จริง (luna มี `max`, sol/terra มี `ultra`)
พร้อมสามบั๊กที่เจอระหว่างเทสต์ของจริงในวันเดียวกัน: โต๊ะผู้ช่วยวาดรูปไม่ได้เลยมาหนึ่งสัปดาห์
หน้าซับเอเจนเปิดไม่ได้ และแจ้งเตือนของ Windows ตอนทิ้งงานไว้แล้วไปทำอย่างอื่น
ฟีเจอร์ของ 1.6.0 (จอ/เครื่องยนต์สอง process, เครื่องระยะไกล, มาสคอต, ทีมเอเจน)
อยู่ใน[บันทึกรุ่นนั้น](v1.6.0.md) ไม่เล่าซ้ำ

## วาดรูปด้วยบัญชี ChatGPT ที่ล็อกอินไว้

**เรื่องเดิม** ตั้งค่า › สร้างภาพ มีเจ็ดเจ้า ทุกเจ้าใช้ API key ทั้งที่คนที่ล็อกอิน ChatGPT
(Codex) ไว้ส่วนใหญ่ไม่มี OpenAI API key เลย เจ้าของถาม *"ระบบเราเชื่อม Codex ได้ แต่ทำไม
เจนรูปผ่านโควต้า Codex ไม่ได้"*

**รุ่นนี้** มีแถว **ChatGPT / Codex (ใช้บัญชีที่ล็อกอินไว้)** วัดกับ backend จริงก่อนเขียน:
เป็น wire เดียวกับ OpenAI ทุกประการ ต่างแค่ credential เป็น token ของการล็อกอิน · รูปตัด
**ถังโควต้า 5 ชม./สัปดาห์เดียวกับแชท** ไม่ใช่ credit แยก และแถบโควต้าในแอปขยับตามรูป
ที่วาด · backend เลือกโมเดลกับขนาดเอง จึงไม่มี picker โมเดลให้ตั้งผิด · token หมดอายุ
กลางทาง refresh ให้หนึ่งครั้งเหมือนแชท · ปุ่มใต้ error เป็น "ไปล็อกอิน ChatGPT" ไม่ใช่
"ไปใส่ API key"

**และเป็นค่าเริ่มต้นเองเมื่อล็อกอินอยู่** — ไม่เคยเลือกเจ้าที่วาดเลยและล็อกอิน ChatGPT
อยู่ → ใช้แถวนี้ ไม่ได้ล็อกอิน → Pollinations เหมือนเดิม ล็อกเอาต์ทีหลังก็ถอยกลับเอง
คนที่เคยเลือกเองไว้ไม่โดนแตะ และหน้าสร้างภาพเขียนไว้ตรง ๆ ว่า "เลือกให้อัตโนมัติ
เพราะล็อกอิน ChatGPT อยู่" — บัญชีคุณเลือกให้ ไม่ใช่คุณเลือก จึงต้องบอก

**ไม่ได้ทำ** — ถามตอนล็อกอินว่าจะให้วาดรูปด้วยไหม (ตอนนั้นคนกำลังคิดเรื่องโมเดลแชท)
และไม่ได้ใช้ tool `image_generation` บน `/responses` ที่ backend ก็รับ เพราะต้องเขียน
parser ใหม่ทั้งชุดเพื่อรูปเดียวกัน

## ระดับความคิดของ Codex ตามที่ backend บอก ไม่ใช่ตามตารางเรา

**เรื่องเดิม** picker ของ `gpt-5.6-luna` จบที่ `xhigh` และถ้าเลือก `max` ก็ถูกพับเป็น `xhigh`
เงียบ ๆ เจ้าของถาม *"luna ไม่มีให้เลือกระดับ max หรือครับ"* ยิงเช็ค: backend รับ `max`
จริง และเมื่อส่งค่ามั่วมันบอกรายการทั้งหมดกลับมาเอง

**รุ่นนี้** อ่านจากสิ่งที่ backend ส่งมาอยู่แล้ว — `GET /models` ที่ใช้เติมรายชื่อโมเดล
บอกระดับที่รองรับและค่าเริ่มต้น **ต่อโมเดล**: luna ถึง `max`, sol/terra ถึง `ultra`,
gpt-5.5 ถึง `xhigh` picker ตามนั้นเป๊ะ ค่าเริ่มต้นก็ของเขา (sol เริ่มที่ `low`) ระดับที่
โมเดลนั้นไม่มีพับไปขั้นใกล้สุดที่มี สลับโมเดลแล้วเทิร์นถัดไปไม่ 400 เปิดหน้าโมเดลครั้งเดียว
picker ได้ขั้นใหม่ทันทีโดยไม่ต้องรีสตาร์ต และรอบหน้ามีตั้งแต่เปิดแอป
(*"ควรมีตามที่เขาส่งมานะ ไม่ใช่ตั้งเอง"*)

**ยังไม่ครอบคลุม** — แถว OpenAI ด้วย API key ยังใช้ตารางเดิม (`/v1/models` ของ
api.openai.com ไม่บอกระดับ) และเครื่องยนต์ระยะไกลยังไม่ได้รับไฟล์นี้

## โต๊ะผู้ช่วยวาดรูปไม่ได้เลยมาหนึ่งสัปดาห์

**เรื่องเดิม** ขอให้วาดรูป ผู้ช่วยเขียน SVG เองแทน — เพราะ `image_make` ไม่อยู่ใน
เครื่องมือของโต๊ะเลย ตั้งแต่ 7 ก.ย.: วันนั้น `image_make` ถูกจัดหมวด `media` ตามกฎ
ของ repo แต่โต๊ะผู้ช่วยถอดหมวด `media` ไปตั้งแต่ 31 ส.ค. เหลือระบุชื่อแค่ `image_ocr`
กับ `pdf_read` ก่อนจัดหมวดมันไม่มีหมวดเลยติดโต๊ะมาโดยบังเอิญ พอจัดให้ถูกก็หลุดเงียบ ๆ

**รุ่นนี้** ระบุชื่อ `image_make` บนโต๊ะผู้ช่วย และปักในเทสต์คู่กับ `video_ocr` ที่ต้อง
ยังไม่ติด (กฎหมวดยังทำงาน)

## หน้าซับเอเจนเปิดได้แล้ว

**เรื่องเดิม** กดตั้งค่า › ซับเอเจน แล้วหน้าล้มทั้งหน้าเมื่อแชทไม่ได้อยู่บนทีม: engine ตอบ
รายชื่อเอเจนของทีมว่างเป็น `null` และหน้าไล่มันด้วย `.find()`

**รุ่นนี้** รายการทั้งสามบล็อกเป็น `[]` เสมอ (กฎ §34) และหน้ากัน `null` ไว้อีกชั้นเผื่อ
engine รุ่นเก่ากว่าจอ

## แจ้งเตือนของ Windows เมื่อทิ้งงานไว้ (§260)

**เรื่องเดิม** ปล่อยให้เอเจนทำงานแล้วไปทำอย่างอื่น มันถามหรือทำเสร็จก็ไม่มีอะไรบอก
นอกจากกระพริบ taskbar กับเสียง ซึ่งคนต้องรู้ก่อนว่ามีสัญญาณนั้นอยู่

**รุ่นนี้** สวิตช์ที่สาม "แจ้งเตือนของ Windows" — บอลลูนของ Windows เอง ไอคอนถาดอยู่
แค่ตอนมีของที่ยังไม่ได้ดู กดแล้วพาหน้าต่างกลับมา เดสก์ท็อปเป็นคนตัดสินว่า "ไม่ได้ดู" จาก
หน้าต่างที่อยู่หน้าสุด ไม่ใช่ webview เดาเอง และเครื่องที่ปิดแจ้งเตือนของ Windows ไว้ทั้งเครื่อง
มีข้อความบอกว่าต้องไปเปิดที่ไหน · กด `+` หรือ Ctrl+N ในโปรเจกต์แล้วเซสชันใหม่ยังอยู่ใน
โปรเจกต์นั้น ไม่โดดไปหน้าแรก
