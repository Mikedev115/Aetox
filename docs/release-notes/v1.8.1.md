## เสียงอ่านออกจาก aetox.exe ไม่ใช่จาก WebView2

**เดิม** ชิ้นเสียงถูกส่งให้หน้าต่างเป็น URL แล้ว `<audio>` เล่น เสียงจึงออกจากโปรเซสของ Chromium ใน
msedgewebview2.exe และมิกเซอร์ของ Windows แสดงไอคอน WebView2 โดยไม่มีอะไรบอกว่าเป็น Aetox
(เจ้าของ: "ทำไมเสียงของเราไม่แสดงบนนี้ แล้วทำไมไปเป็นไอค่อนของเว็บวิวแทน") ไม่มี API ของ WebView2
เปลี่ยนชื่อ audio session ได้
**รุ่นนี้** ชิ้นเสียงถูกถอดรหัสและเล่นจากโปรเซสของ Aetox เอง ด้วยสองส่วนของ Windows ที่มีมาตั้งแต่ Windows 7:
Media Foundation ถอดทุกฟอร์แมตที่เอนจินเสียงเขียน (MP3 จาก Edge และผู้ให้บริการคลาวด์ WAV จาก
Windows, Piper, OpenAI, Gemini) จึงไม่มี MP3 decoder ในตัวโปรแกรม และ WASAPI เล่นบนลำโพงที่คุณเลือก
โดยให้ Windows resample เอง มิกเซอร์จึงบอกว่าเป็น Aetox พร้อมไอคอนของมัน ตัวอ่านยังทำงานล่วงหน้าแค่
ไม่กี่ชิ้นเหมือนเดิม การหยุดยังหยุดจริง และหน้าต่างได้ยินแค่สถานะ (เริ่มชิ้นไหน จบ หรือพังเพราะอะไร)
ไม่มีเสียงผ่านหน้าต่างอีกเลย

- **ลำโพงในตั้งค่า › เสียง เป็นรายการของ Windows** ไม่ใช่ของเบราว์เซอร์ จึงไม่ต้องขอสิทธิ์ไมค์ก่อนถึงจะ
  เห็นชื่อ ตัวเลือก "ตัวที่ Windows ตั้งไว้" บอกชื่อเครื่องที่หมายถึงตอนนี้ ลำโพงที่เคยเลือกไว้ด้วย id เก่า
  จะเล่นบนตัวตั้งต้น ซึ่งคือสิ่งที่มันทำก่อนใครเลือก
- **ลองฟัง เป็นการอ่านธรรมดา** ผ่านทางเดียวกับปุ่มฟังใต้คำตอบ สิ่งที่มันพิสูจน์คือสิ่งที่คุณจะได้จริง
- เทสต์ที่เพิ่มในรุ่นนี้: `speak_test.go` (เล่นทุกชิ้นตามลำดับแล้วปิดตัวเอง, หยุดแล้วเงียบและลบไฟล์,
  อุปกรณ์เปิดไม่ได้บอกเหตุผล, เอนจินตายกลางทางฟังที่เหลือแล้วค่อยรายงาน) และเทสต์กับอุปกรณ์จริง
  (`AETOX_LIVE_AUDIO=1`: session ในมิกเซอร์เป็นของ pid นี้ชื่อ Aetox ถอด WAV และ MP3 จริง)

## เสียงอ่านตามที่จอแสดง ไม่ใช่ตามซอร์ส

**เดิม** ปุ่มฟังลอกเครื่องหมาย markdown ออกด้วย regex แล้วอ่านทุกอย่างที่ regex ไม่รู้จัก คำตอบที่มี
mockup วาดเป็น `<svg>` ถูกอ่านทีละแอตทริบิวต์ (เจ้าของ: "มันอ่านเป็นอะไรไม่รู้") และพาธถูกอ่านทีละสแลช
**รุ่นนี้** ข้อความมาจากคำตอบที่เรนเดอร์แล้ว — คอลเดียวกับที่แชทใช้วาด — อะไรที่ตัวเรนเดอร์ใส่กรอบเป็น
ภาพ โค้ดบล็อก สมการ แกลเลอรี หรือ panel จะเงียบด้วยคลาสเดียวกับที่มันใส่กรอบ พาธพูดชื่อไฟล์
ที่อยู่เว็บพูดโฮสต์ commit id กับ UUID ตัดทิ้ง ตารางอ่านแถวละบรรทัด รายการเลขอ่านเลขด้วย และหัวข้อ
รายการ แถวตารางจบบรรทัดของตัวเอง จังหวะหยุดจึงตกตรงที่เลย์เอาต์วาง ไม่ใช่ที่ตัวอักษรที่ 240
บับเบิลของอวตารก็ไม่โชว์ `<svg viewBox=…>` หรือ "js" อีกเมื่อคำตอบเปิดด้วยภาพวาดหรือ fence

## ห้องสมุด MCP: 40 → 88 แถว ทุกแถวมีมาร์ก และคีย์เป็นช่องกรอก

**เดิม** ห้องรอ (`mcpCandidates`) ถือ 26 เซิร์ฟเวอร์ที่ผ่านการตรวจตั้งแต่ต้นเดือน รอแค่คนเขียนเหตุผล
แถวที่ต้องมีคีย์บอกให้ "วางคีย์ต่อท้าย header ด้านบน" แล้วให้คุณหาเองว่าไปเอาคีย์ที่ไหน และไทล์ที่ไม่มีโลโก้
เป็นตัวอักษรเฉย ๆ
**รุ่นนี้** (เจ้าของ: "หามาอีก 10 อัน" → "เอา MCP มาเยอะๆ เลย" → "ผมจะดันสายพวกนี้ด้วย" → "ห้ามขาด")

- **48 แถวใหม่** ทุกแถว stdio ถูกรันจริงบนเครื่องนี้ด้วย `initialize` + `tools/list` ทุก URL ถูกยิง
  `initialize` จริง จำนวนเครื่องมือกับโทเคนบนการ์ดคือค่าที่วัด (mongodb 31 เครื่องมือ 19.6k โทเคน ·
  ahrefs 42 เครื่องมือ 80k โทเคน — แพงสุดบนชั้น ซึ่งชั้นวางแบบ v1.8.0 รับได้เพราะโหลดเป็นกลุ่ม)
  ทุก 401 ถูกเดินตาม RFC 9728 → 8414 ในวันเดียวกัน 22 แถว sign-in ตอบ registration endpoint จึงเป็น
  คลิกเดียว สายโฆษณา/คอนเทนต์: LINE OA, Google Ads, Google Analytics, Semrush, Ahrefs, Buffer,
  WordPress, Klaviyo, TikTok Ads · ฐานข้อมูล: dbhub (Postgres/MySQL/SQL Server/SQLite), MongoDB,
  Redis · เครื่องมือ: Chrome DevTools, Figma desktop, Svelte, grep.app, arXiv, Kubernetes, Azure, AWS,
  lnwjud (241 เครื่องมือ) และ 26 แถวจากห้องรอ (airtable, apify, neon, resend, posthog, cloudinary, socket, google-maps …)
- **ทุกแถวมีมาร์ก** เก้าตัวที่ผู้ขายไม่มี SVG ถูก trace จากไอคอน raster ของผู้ขายเองเป็นมาสก์สีเดียว
  รูปของเขา ไม่ประดิษฐ์ ai-quota เป็นตัวเดียวที่ทำไม่ได้ (ไม่มีไอคอนที่ไหนเลย) และเทสต์บอกไว้ว่าทำไม
- **เซิร์ฟเวอร์ที่ต้องมีคีย์ได้ช่องกรอกช่องละตัวแปร** เหมือนการ์ดผู้ให้บริการขอคีย์ พร้อมปุ่ม ไปเอาคีย์
  ไปหน้าที่ออกคีย์ (11 แถว) และขั้นตอนของคลังใต้ช่องขณะคีย์ยังว่าง แถวที่บันทึกแล้วแต่คีย์ยังว่างขึ้น
  **ยังไม่มีคีย์** สีเหลือง แทน "ต่อได้" บนโปรแกรมที่จะปฏิเสธคอลแรก
- **sign-in ที่ล้มบอกบนแถวที่ล้ม** พร้อมปุ่มลองอีกครั้ง — figma ตอบ 403 ทุก body ที่ registration endpoint
  เดิม error ไปอยู่บนสุดของห้องสมุดยาว การกดที่ตายในสามวินาทีจึงอ่านเป็นการรอที่ไม่จบ (เจ้าของ:
  "มันค้างแบบนี้แต่มันไม่ได้จริง") แถว figma-desktop ข้างกันคือทางที่ไม่ต้อง sign-in · พอร์ต loopback
  ที่ไม่มีใครฟังบอกเป็นคำว่าโปรแกรมที่เสิร์ฟมันยังไม่เปิด
- **แถวห้องสมุดกดแล้วเปิดแผงรายละเอียด** และถามผู้ช่วยได้ว่าเซิร์ฟเวอร์นี้คืออะไร ทั้งก่อนเพิ่มและหลังเพิ่ม
  · 401 บอกว่าเซิร์ฟเวอร์ขอสิทธิ์อะไร ไม่ใช่แค่ Unauthorized · แถวที่ยืม token จากการเชื่อมต่อบอกว่า
  คีย์มาจากไหนและพาไปที่นั่น · แถว meta-ads ชี้เซิร์ฟเวอร์ของ Meta เอง
- ไกด์รู้จักช่องคีย์ ปุ่มไปเอาคีย์ ขั้นตอน และคำว่ายังไม่มีคีย์ ในสามภาษา
- **ยังไม่ทำ** ทุกแถวใหม่ยัง `proven: false` — ยังไม่มีแถวไหนถูกใช้กับบัญชีจริงของใคร การ์ดจะบอกเหตุผล
  จากที่ใช้จริงเมื่อมีคนใช้แล้วเท่านั้น

## เอเจนตอบสามคำถามเดียวกับตัวหลัก

**เดิม** ตัวหลักมี identity.md กับ thinking.md (ฉันเป็นใคร คิดยังไง ทำหน้าที่อะไร) แต่เอเจนมีแค่บรีฟยาว
ก้อนเดียว ads มีหน้าที่ 83 บรรทัดโดยไม่มีใครบอกว่ามันเป็นใคร
**รุ่นนี้** ทุกเอเจนมี `identity.md` · `thinking.md` ข้าง `AGENT.md` ในโฟลเดอร์ของมันเอง พับไว้หน้าบรีฟ
ทั้งตอนถูกจ้างและตอนคุยตรง หน้าแก้ไขเอเจนมีสองช่อง ตัวตน กับ วิธีคิด เหนือ หน้าที่ (ชื่อใหม่ของ บทบาท)
และ**เอเจนที่มากับแอปทั้ง 9 ตัว** (ads, automation, content, deepresearch, doc, editor, github, sheet,
video) ตอบสามคำถามเองในตัวโปรแกรม ถอดจากบรีฟเดิมทุกบรรทัด บรีฟจึงเหลือแค่หน้าที่ (1,336 → 773
บรรทัดรวม) ไฟล์ในโฟลเดอร์ผู้ใช้ทับของที่ติดมา ล้างว่าง = กลับไปใช้ของเดิม ไม่มีไฟล์ = prompt เท่าเดิม
ทุกไบต์ แคชของเอเจนที่ติดมาจึงไม่หลุด

- การเชื่อมต่อ (GitHub, Meta Ads) ตั้งได้บนหน้าของลูกมือเอง ข้าง MCP · กล่อง ต้องใช้ วาดโลโก้ของสิ่งที่
  ต้องใช้และบอกว่ามันคืออะไร · เซิร์ฟเวอร์ที่เพิ่มใหม่ขึ้นบนลูกมือที่ประกาศ `needs: mcp:<ชื่อ>` เอง
- แถว พนักงานเฉพาะทาง ขึ้นในคอลัมน์ของประตูโค้ดด้วย · ปุ่ม ตั้งค่าเอเจน ท้ายเมนู ใครตอบ

## โฆษณาและคอนเทนต์: อ่านบัญชี Meta และโพสต์ลงเพจได้จาก Aetox

**เดิม** สายพานมีครบถึงขั้นสุดท้าย (ทำภาพ ทำวิดีโอ ตัดต่อ ถอดเสียง) แต่ไม่มีมืออัปโหลดเลย
**รุ่นนี้** ลูกมือ **ads** อ่านบัญชีโฆษณา Meta ได้ (บัญชี แคมเปญ ชุดโฆษณา insights) บน token จากแอป
Meta ของคุณเอง — Meta เป็นแพลตฟอร์มเดียวที่ร้านเล็กเชื่อมได้เองในสิบนาทีโดยไม่ต้องรอรีวิว และ Aetox
ไม่ถือกุญแจให้ใคร · เอเจน **content** โพสต์ลงเพจ Facebook ได้บน token เดียวกัน (โพสต์ รูป วิดีโอ Reel
ตั้งเวลา) แอปในโหมด Development โพสต์ลงเพจของตัวเองได้โดยไม่ต้อง App Review การโพสต์สาธารณะ
**ถามก่อนทุกโหมด** รวมโหมดที่ไม่ถามอย่างอื่น
- **แถวการเชื่อมต่อบอกว่า token หมดอายุเมื่อไร** แดงเมื่อตายแล้ว เตือนเมื่อเหลือไม่ถึง 3 วัน (token
  จาก Graph API Explorer อายุ 1–2 ชม. ก้อนแรกของเจ้าของตายตอน 03:00 ขณะที่ไทล์ยังเขียนว่าเชื่อมแล้ว)
  พร้อมวิธียืด token 2 ชม. ของ Meta เป็น 60 วัน GitHub ก็อ่านวันหมดอายุจาก header ของมัน
- **ยังไม่ทำ** IG, YouTube, TikTok ยังไม่มีมืออัปโหลด · ads ยังอ่านอย่างเดียว การเขียนที่มีเงินเกี่ยวยัง
  ถูกปิดในโค้ดก่อนที่จะมีเครื่องมือของมัน

## อวตารรู้ว่าตัวเองบังอะไร และมีชีวิตตอนว่าง

- **เดินหลบเอง** เมื่อยืนทับตัวอักษรหรือโค้ด (เจ้าของ: "ทำให้มันเดินออกเองได้ไหม") หน้าเว็บบอกได้ว่า
  ใต้เท้ามีอะไร มองทุก 0.5 วิ สองครั้งก่อนขยับ หาที่ว่างใกล้สุดโดยไม่ต้องลองเดิน ออกข้างก่อนเสมอ
  (ซ้าย/ขวาทุกวงมาก่อนบน/ล่างที่ใกล้กว่า) กลางเทิร์นก็หลบ บ้านยังเป็นจุดที่คุณวาง กลับเมื่อบ้านว่าง
  หน้าตกใจก่อนเดินถูกตัดออก ("มันดุแปลก") หน้าสำหรับจังหวะนี้จะเสนอให้เลือกก่อน
- **ถือของได้ 17 อย่าง มีอารมณ์ 13 แบบ** ของบนตัก ของในมือที่หมุนตามแขน ท่าทำงานถือของประจำงาน
  (ค้นไฟล์ = ไฟฉาย ดีบัก = ประแจ เสร็จ = ถ้วย) และตอนว่างจิบกาแฟ อ่านหนังสือ มองรอบ ๆ ฮัมเพลง
  เดินเล่นใกล้บ้านทั้งในหน้าต่างและบนเดสก์ท็อป

ข้อเท็จจริง) สร้างและเทสต์แล้วในรุ่นนี้ แต่**เมนูไม่วาดประตู** (เจ้าของ: "ปิดไว้ก่อน… ทีมยังไม่เสร็จ
มันควรแยกส่วนกันอยู่แล้ว") flow ของห้องทำงานทีมกำลังถูกคิดใหม่ เปิดกลับได้ด้วยแฟล็กเดียว

## อื่น ๆ ในรุ่นนี้

- **workflow ส่ง .msix ขึ้น Partner Center เอง** เมื่อรีโปมี secret `PARTNER_CENTER_*` ครบสี่ตัว — ขั้นที่
  RELEASING.md เขียนว่า "ลืมง่ายที่สุด" ไม่มี secret = ข้ามเงียบ artifact ยังอยู่ให้ลากมือ
- **กดไฟล์บนแผนที่โค้ดแล้วเปิด** ระยะลากเคยวัดจากศูนย์กลางวง กดวงใหญ่ตรงไหนก็นับเป็นลาก 20 หน่วย
  ตั้งแต่นิ้วยังไม่ขยับ ("ตรงนี้กดไม่ได้") ตอนนี้วัดจากนิ้ว และวงขี่ใต้นิ้วด้วย offset ที่ถูกจับ
- **429 บอกประโยคของผู้ให้บริการด้วย** — OpenRouter ฟรี 50 ครั้ง/วัน เคยถูกตัดเหลือ "Try again shortly"
- ปุ่มสามปุ่มต่อแถวในหน้า เรียนรู้ เล็กลงหนึ่งขั้น ตัวหลักยังมีสีเติมบอกว่าอันไหนคือใช่
- คำถาม "มันคืออะไร" ส่งเป็นภาษาที่ผู้ใช้เลือก · แผ่น token ของ Meta Ads พูดคำของ Meta ไม่ใช่ของ GitHub
  · แถว n8n, Windmill และ Meta Ads บอกว่าเชื่อมแล้วได้อะไร
- เอกสารสถาปัตยกรรมย้ายออกจาก GitHub ทั้งชุด (docs/internal/) เหลือ docs/reports/ ที่เป็นผลวัดสาธารณะ
