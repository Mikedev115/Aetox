# แผนที่ไกด์ (Aetox Guide Map)

เอกสารต้นทางของแผนที่ไกด์ (ยศที่สี่): รวบรวมทุกจุด `data-guide` บน UI ของ Aetox
ข้อความในไฟล์นี้เป็นต้นทางเดียวสำหรับ `lib/guide/map.ts` และคำแปล 3 ภาษาใน `lib/locales/{th,en,zh}.ts`

- **ชื่อ**: คำเรียกสิ่งที่ปุ่ม/องค์ประกอบนั้นเป็น
- **คืออะไร**: 1–2 ประโยค ภาษาผู้ใช้ ไม่ใช่ภาษาระบบ
- **ทำไมออกแบบแบบนี้**: 1–2 ประโยค ต้องมาจาก `docs/DECISIONS.md` อ้างอิง §
- **safe**: `true` เฉพาะสิ่งที่ย้อนได้ในคลิกเดียวและไม่เปลี่ยนข้อมูล (เปิด/ปิดกลุ่ม, เปิดเมนู, เปลี่ยนหน้า, เปลี่ยนแท็บ)

## ความเชื่อมโยงกับทัวร์เก้าฉาก (Tour Scenes Mapping)

เส้นทางแนะนำรอบแรก (Route `first`) จะพาเดินผ่านจุดสำคัญตามฉากของทัวร์แนะนำ:

1. **ฉาก 0 (เปิดตัว/ภาพรวม)**: `sidebar.projects` → `topbar.door`
2. **ฉาก 1 (ผู้ช่วยสองคน)**: `topbar.door.assistant` → `topbar.door.coding`
3. **ฉาก 2 (ตั้งชื่อกันได้)**: `settings.rail.heads` → `settings.head.tab.identity` → `settings.you.name_input`
4. **ฉาก 3 (ความจำสามชั้น)**: `settings.head.tab.memory` → `memory.card`
5. **ฉาก 4 (สแตนซ์/การลงมือ)**: `composer.stance`
6. **ฉาก 5 (ความสามารถ)**: `capability.rail.mcp` → `capability.rail.skills`
7. **ฉาก 6 (ต่อสมอง)**: `settings.rail.brain` → `settings.brain.provider.ollama`
8. **ฉาก 7 (ตัวช่วยบนจอ)**: `account.companion` → `settings.rail.avatar`
9. **ฉาก 8 (พร้อมใช้งาน)**: `chat.send` → `composer.input`
