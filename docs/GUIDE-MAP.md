# แผนที่ไกด์ (Aetox Guide Map)

เอกสารต้นทางของแผนที่ไกด์ (ยศที่สี่): รวบรวมทุกจุด `data-guide` บน UI ของ Aetox
ข้อความในไฟล์นี้เป็นต้นทางเดียวสำหรับ `lib/guide/map.ts` และคำแปล 3 ภาษาใน `lib/locales/{th,en,zh}.ts`

- **ชื่อ**: คำเรียกสิ่งที่ปุ่ม/องค์ประกอบนั้นเป็น
- **คืออะไร**: 1–2 ประโยค ภาษาผู้ใช้ ไม่ใช่ภาษาระบบ
- **ทำไมออกแบบแบบนี้**: 1–2 ประโยค ต้องมาจาก `docs/DECISIONS.md` อ้างอิง §
- **safe**: `true` เฉพาะสิ่งที่ย้อนได้ในคลิกเดียวและไม่เปลี่ยนข้อมูล (เปิด/ปิดกลุ่ม, เปิดเมนู, เปลี่ยนหน้า, เปลี่ยนแท็บ)
