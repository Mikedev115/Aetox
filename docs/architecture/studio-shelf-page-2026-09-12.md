# หน้าคลังสตูดิโอ รอบสอง — จาก "ฟอร์มตั้งค่า" เป็น "ชั้นวางที่มองเห็นของ"

**12 ก.ย. 2026** · สถานะ: **ทุกขั้นลงแล้ว** (1–5) วันเดียวกัน — การ์ด, แท็บมาตรฐาน, การ์ดสรุป, sheet แหล่ง, ปุ่มจากงานวิดีโอ, ชั้น Kenney, ตัวเลือกดูของ, poster, เปลี่ยนชนิด/ซ่อน · ต่อจาก [video-asset-library-2026-09-12.md](video-asset-library-2026-09-12.md) ที่ลงชั้น A ไปแล้วในวันเดียวกัน

**เจ้าของ, 12 ก.ย. หลังเห็นหน้าจริง:** *"คลังสตูดิโอมึงทำไว้ลวกมาก ... ไปวางแผนทำให้ดีกว่านี้"*

## 1. ที่ลวก — ดูจากหน้าจริงบน dev app

เทียบกับหน้า **ความสามารถ** (MCP) ซึ่งเป็นมาตรฐานของแอปนี้: การ์ดหนึ่งใบต่อหนึ่งสิ่งที่มีตัวตน — โลโก้ ชื่อ แท็ก
ประโยคเดียวว่าทำอะไร ชิปสถานะ ปุ่มทดสอบ/ตั้งค่า แล้วท้ายหน้าค่อยเป็นตัวหนังสือเล็ก ๆ

หน้าคลังสตูดิโอรอบแรกคือตรงข้าม:

1. **บั๊ก markup** — แถวใช้ `<span class="set-txt">` ทั้งที่แบบแผนของหน้าอื่นคือ `<div class="set-txt"><div class="t">…</div><div class="d">…</div></div>`
   หัวข้อกับคำอธิบายจึงไหลติดกันเป็นบรรทัดเดียว ("เพิ่มโฟลเดอร์วัตถุดิบ เลือกโฟลเดอร์ที่มีเสียง…") ทุกแถวในหน้า *(แก้แล้ววันเดียวกัน)*
2. **เป็นรายการ path ไม่ใช่ชั้นวาง** — คลังหนึ่งแสดงเป็น `D:\…\30GB+ Video Editing Assets` กับตัวเลขต่อท้าย ผู้ใช้เห็นไม่ได้ว่าข้างในมีอะไร
   ฟังเสียงไม่ได้ ดู overlay ไม่ได้ ทั้งที่ของทั้งหมดคือ "สิ่งที่ต้องเห็นและได้ยินก่อนเลือก"
3. **หน้าว่างไม่สอนอะไร** — ประโยคเทา ๆ บรรทัดเดียว "ยังไม่มีคลัง" ในการ์ดเดียวกับปุ่มเพิ่ม ไม่มีตัวอย่างว่าเอเจนจะได้อะไรจากมัน
   และไม่มีของติดมาให้เลยสักชิ้น จึงว่างจริง ๆ ตั้งแต่วันแรก
4. **แหล่งวัตถุดิบเป็นลิงก์สามแถวหน้าตาเหมือนกัน** — "SFX pack #1 / #2" ไม่บอกอะไร ไม่มีขนาด ไม่มีว่าข้างในมีอะไร ไม่มีธงเรื่องสิทธิ์ต่อแหล่ง
   ทั้งที่ประเด็นสิทธิ์คือเหตุผลทั้งหมดที่ทำเป็นลิงก์แทนการโหลด
5. **สแกนเสร็จแล้วเงียบ** — progress หายไปเฉย ๆ ไม่มีสรุปว่า "พบ 1,855 ไฟล์ เสียงประกอบ 143 overlay 698 …" ทั้งที่นี่คือจังหวะเดียวที่ผู้ใช้อยากรู้ว่ามันเข้าใจของเขาไหม
6. **ชนิดที่ทายผิดแก้ไม่ได้** — FILM BURN มี jpg ตัวอย่างของ Premiere extension 158 ไฟล์ถูกนับเป็น "ไอคอน" ผู้ใช้เห็นแล้วทำอะไรไม่ได้ เอเจนก็หยิบผิดต่อไป
7. **ไม่มีทางมาจากงานวิดีโอ** — แถว "คลังสตูดิโอ: ยังว่าง" ในหน้าความพร้อมบอกให้ไปตั้งค่า แต่ไม่พาไป

สรุปสั้น: รอบแรกทำ **ครึ่งเครื่องยนต์** (สแกน ค้น เครื่องมือให้เอเจน) ได้ดีและวัดกับของจริงแล้ว
แต่ **ครึ่งหน้าจอ** ทำเป็น settings row ทั้งที่ของชิ้นนี้เป็นห้องเก็บของ ไม่ใช่สวิตช์

## 2. หลักของรอบสอง

- **ชั้นวางต้องมองเห็นของ** — ทุกชนิดมีวิธี "ชิม" ที่เหมาะกับมัน: เสียงกดฟัง, คลิป/overlay มี poster + hover เล่น, ไอคอน/ภาพเป็นตาราง thumbnail
- **การ์ดมีตัวตน** ตามแบบหน้าความสามารถ: คลังหนึ่งใบ = ชื่อโฟลเดอร์ (ไม่ใช่ path เต็ม), ที่มา, ขนาด, จำนวน, ชิปสถานะ, ปุ่ม
- **ไม่เคยว่าง** — มีชั้น "มากับ Aetox" ติดมาหนึ่งชั้น: **Kenney Interface Sounds** (100 ไฟล์ .ogg, 0.9MB, CC0) เจ้าของเลือกจากหน้าฟัง 12 ก.ย.
  (`internal/assetlib/builtin.go` — go:embed + สารบัญ probe ไว้ล่วงหน้า แตกลง `<DataRoot>/studio/builtin/` ครั้งแรก ไม่เคยเข้า Store)
  หน้าจึงมีของให้ดูตั้งแต่เปิดครั้งแรก และเอเจนมีเสียงใช้ตั้งแต่วันแรก
- **ผู้ใช้แก้สิ่งที่เครื่องทายได้** — เปลี่ยนชนิด, ซ่อนไฟล์ขยะ; การแก้อยู่รอด rescan
- **ยังไม่โหลดอะไรแทนผู้ใช้** — แหล่งยังเป็นลิงก์ แต่บอกให้ครบว่าจะไปเจออะไร

## 3. หน้าใหม่ — บนลงล่าง

### 3.1 หัว + แท็บเจ็ดชนิด

**แก้ 12 ก.ย. (รอบสาม):** tile เจ็ดใบพร้อมตัวเลขใหญ่ถูกอ่านเป็นแดชบอร์ด — เจ้าของ: *"ดูตอนแรกเหมือนแดชบอร์ด ไม่รู้เลยว่ากดได้"*
จึงเป็น **แท็บ** แทน: ไอคอน + ชื่อชนิด + จำนวนเป็นเม็ด แท็บที่เปิดเชื่อมกับแผงตัวเลือกดูของข้างล่าง (พื้นเดียวกัน ไม่มีเส้นล่าง)
และ**เปิดแท็บแรกที่มีของตั้งแต่เข้าหน้า** จึงอ่านออกว่าเป็น "แท็บ + เนื้อหา" ตั้งแต่เฟรมแรก ชนิดที่เป็นศูนย์ **จาง กดไม่ได้ แต่ไม่หาย**
แท็บเป็นตัวเลือกชนิดตัวเดียว (ตัวเลือกชนิดในแผงถอดออก) และรักษาตัวกรองคลังจากปุ่ม "ดูของ" ของการ์ดไว้ — แผงโชว์ "เฉพาะคลัง X · ดูทุกคลัง"

### 3.2 การ์ดคลัง (shelf cards)

หนึ่งใบต่อหนึ่งโฟลเดอร์ แบบการ์ด MCP:

```
[ไอคอน]  30GB+ Video Editing Assets        มากับ Aetox | โฟลเดอร์ของคุณ
         D:\…\Downloads\30GB+ Video Editing Assets        (path ตัวเล็ก คลิกเปิด)
         1,855 ไฟล์ · 27.3 GB · อ่านล่าสุด 12 ก.ย. 03:52
         ● พร้อม   |  ● ไม่พบโฟลเดอร์ (ถอดไดรฟ์?)  |  ▮▮▮▯ กำลังอ่าน 43%  [หยุด]
         [ดูของในคลัง]  [อ่านใหม่]  [⋯ → เปิดโฟลเดอร์ / เอาออก]
```

- ชั้น "มากับ Aetox" ไม่มี "เอาออก" มีแค่ "ดูของ"
- ปุ่มหลักบนขวาของหมวด: **+ เพิ่มโฟลเดอร์** (เดิมเป็นแถวล่างสุด)
- หลังสแกนเสร็จ การ์ดโชว์ **สรุปผล** หนึ่งรอบ: "พบ 1,855 ไฟล์ — เสียงประกอบ 143 · overlay 698 · …" พร้อมชิปต่อชนิด แล้วค่อยยุบเป็นบรรทัดปกติเมื่อผู้ใช้กดปิด (ตอบข้อ 5)

### 3.3 ตัวเลือกดูของ (asset browser) — ใจของหน้า

เปิดจาก tile ชนิด หรือปุ่ม "ดูของในคลัง" ของการ์ด แสดงในหน้าเดียวกันใต้การ์ด (ไม่เป็น modal — จะได้เลื่อนดูไปพร้อมกัน)

- แถบบน: ช่องค้น (ใช้ `assetlib.Search` ตัวเดียวกับเครื่องมือ — ผู้ใช้เห็นสิ่งเดียวกับที่เอเจนเห็น), ตัวกรองชนิด, dropdown หมวด (ชื่อโฟลเดอร์ชั้นแรกของผู้ใช้), สวิตช์ "เฉพาะที่มี alpha"
- ผลเป็น **grid** 60 ใบต่อหน้า (1,855 ใบวางทีเดียวไม่ไหว) มีเลขหน้า
- ใบต่อชนิด:
  - **เสียง** — ปุ่มเล่น/หยุด, ชื่อ, ความยาว, หมวด เล่นผ่าน `<audio>` จาก filehost (desktop/filehost.go มีอยู่แล้วสำหรับให้ webview อ่านไฟล์ในเครื่อง) ทีละไฟล์ กดใบอื่นตัวเก่าหยุด
  - **คลิป / overlay / ฉากหลัง** — poster frame + ความยาว + ป้าย `alpha` / `green screen`; hover เล่นแบบ muted จาก filehost (`preload=none` จนกว่าจะ hover) พื้นหลังลายตารางหมากรุกใต้ overlay ที่มี alpha
  - **ไอคอน / ภาพ** — thumbnail จัตุรัส, ขนาดพิกเซล
- เมนูต่อใบ: **เปลี่ยนชนิด** (dropdown เจ็ดชนิด), **ซ่อนจากเอเจน**, เปิดโฟลเดอร์, คัดลอก path (ตอบข้อ 6)

### 3.4 หาวัตถุดิบเพิ่ม (เดิม "แหล่งวัตถุดิบ")

**แก้ 12 ก.ย. (รอบสี่):** ย้ายจากท้ายหน้า (เจ้าของ: *"ไม่ใช่ไปอยู่ข้างล่างจนหาไม่เจอ"*) เป็น **sheet เลื่อนจากขวา** แบบเดียวกับ "เพิ่มเซิร์ฟเวอร์"
ของหน้า MCP (`StudioSourcesSheet.svelte`) เปิดจากปุ่ม "แหล่งวัตถุดิบ" ข้าง "+ เพิ่มโฟลเดอร์" บนแถบแท็บ ข้างในมีสองทาง: โฟลเดอร์ที่มีอยู่แล้ว กับแหล่งให้ไปโหลด
และแท็บเจ็ดชนิดเปลี่ยนเป็น `.ag-tabs-bar .seg` ซึ่งเป็นแท็บมาตรฐานของแอป (ตัวที่หน้าแก้เอเจนใช้) แทนแท็บทำเองที่ล้นแถว

การ์ดต่อแหล่ง ไม่ใช่แถวลิงก์:

```
[ภาพ/ไอคอน]  30GB+ Video Editing Assets                        ~33 GB · Google Drive
             เสียง 140+ · overlay 700 · ฉากหลัง · ไอคอนเคลื่อนไหว · มีม   (จากที่สแกนจริง)
             ⚠ สิทธิ์ไม่ระบุ — มีของขาย (CinePacks) และ MV เพลงลิขสิทธิ์ ใช้กับงานขายต้องคัดเอง
             [เปิดหน้าดาวน์โหลด]        ✓ นำเข้าแล้ว  (เมื่อชื่อโฟลเดอร์ของคลังใดตรงกับแหล่ง)
```

ธงสิทธิ์สามระดับ: `CC0` / `ต้องตรวจเอง` / `ไม่ระบุ` — เขียนไว้ที่ `studioSources.ts` ต่อแหล่ง
"SFX pack #1/#2" เปลี่ยนเป็นชื่อจริงตามหน้า Drive: **peen's SFX** กับ **SFX Sound Effects**
ส่วนแพ็ก 30GB+ ที่เจ้าของโหลด **ไม่ได้อยู่ในคู่มือ ii23** (เป็น "แชร์กับฉัน" จากที่อื่น) จึงยังไม่มีการ์ดจนกว่าจะได้ลิงก์

### 3.5 ทางมาจากงานวิดีโอ

แถว `assets` ใน VideoReady เป็นปุ่ม → `openSettingsAt('studio')` แบบเดียวกับที่ปุ่ม "เพิ่มคีย์" ในหน้าสร้างภาพพาไปหน้าโมเดล (ตอบข้อ 7)
