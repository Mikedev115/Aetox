โปรเจกต์นี้เป็นชุดฟังก์ชันช่วยของเว็บเซอร์วิสตัวหนึ่ง ในโฟลเดอร์ `helpers/` มีฟังก์ชันที่เขียนไว้แค่หัวกับ docstring ยังไม่มีเนื้อ ช่วยเขียนให้ครบทุกตัวตามที่ docstring บอก ใช้ Python 3 ไลบรารีมาตรฐาน หรือ `pyyaml` / `lxml` ถ้าจำเป็น ห้ามเปลี่ยนชื่อไฟล์ ชื่อฟังก์ชัน หรือพารามิเตอร์ เพราะมีโค้ดส่วนอื่นเรียกใช้อยู่
