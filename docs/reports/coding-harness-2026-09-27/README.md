# งานโค้ดจริง โมเดลเดียวกัน: Aetox · OpenCode · Codex CLI

> เอกสารบันทึกผล · วัดเมื่อ 27 ก.ย. 2026 · ข้อสอบ 11 โจทย์ × 2 โมเดล × 3 ตัวครอบ = 66 รัน
>
> คำถามเดียว: **ให้โมเดลตัวเดียวกันทำงานโค้ดชิ้นเดียวกัน ตัวครอบ (harness) ไหนส่งงานที่ผ่านเทสต์ได้มากกว่า**
> ทุกโจทย์ตัดสินด้วยเทสต์ที่ซ่อนไว้ ผู้แข่งไม่เห็นเทสต์ระหว่างทำ ไม่มีคนให้คะแนนด้วยความรู้สึก
>
> นี่คือรอบนำร่อง (pilot) ช่องละ 1 รัน ส่วนต่างเล็ก ๆ (1–3 เทสต์) แกว่งได้เมื่อรันซ้ำ
> ส่วนต่างที่ควรอ่านคือส่วนต่างที่ใหญ่ ข้อสอบ เทสต์ และผลรายรันอยู่ในโฟลเดอร์นี้ทั้งหมด ตรวจซ้ำได้

- **ห่างที่สุดในงานยาวและงานในรีโปใหญ่บนโมเดลเล็ก** — บน Luna: B1 (migrate ฐานข้อมูล 3 เทิร์น) 84 ต่อ 64 และ 68,
  B3a (บั๊กจริงใน Caddy) มีแค่ Aetox ที่แก้ได้ ตัวอื่นมักทำให้ของที่ผ่านในเทิร์นก่อนพังเมื่อเพิ่มของใหม่
- **ยิ่งโมเดลเก่ง ส่วนต่างยิ่งแคบ** — บน Terra ทั้งสามตัวแก้ B3a ได้ และหลายโจทย์ห่างกันแค่ 1–4 เทสต์
- **Aetox ช้าที่สุดและใช้ token มากที่สุด** — เวลา 1.3–1.7 เท่าของ OpenCode และ 1.6–2.4 เท่าของ Codex CLI ·
  token ราว 2 เท่าของ OpenCode และ 2.8–3.2 เท่าของ Codex CLI (ส่วนใหญ่เป็น token ขาเข้าที่แคชได้)
  เวลาส่วนใหญ่ไปกับการอ่านโค้ดและรันตรวจผลก่อนตอบ Codex CLI เร็วและประหยัดที่สุด
- **จุดที่ Aetox แพ้:** S1 (xjq) แพ้ OpenCode ทั้งสองโมเดลและแพ้ Codex บน Terra · S3 (etl_pipeline) แพ้ OpenCode บน Luna
  · F2 แพ้ Codex บน Terra

## 3. วัดอย่างไร

| เรื่อง | ค่าที่ใช้ |
|---|---|
| โมเดล | `gpt-6-luna` และ `gpt-5.6-terra` ความคิดระดับ medium ผ่านบัญชี ChatGPT (Codex) บัญชีเดียวกันทั้งสามตัว |
| Aetox | 1.9.0 ตัวเทอร์มินัลจาก Release ([`aetox-cli-windows-amd64.zip`](https://github.com/Mikedev115/Aetox/releases/tag/v1.9.0) sha256 `9881e62f…c2d4`) ไม่ได้บิวด์เอง · สั่งงานแบบ `aetox chat` ครั้งละหนึ่งข้อความ · อนุมัติเต็ม · โฟลเดอร์ข้อมูลใหม่ทุกรัน · ไม่มีสกิลหรือการตั้งค่าของผู้ใช้ มีแค่ของที่ติดมากับตัวติดตั้ง |

| ข้อความที่ส่ง | ไฟล์เดียวกันทุกไบต์ทั้งสามตัว ([`tasks/*/prompts/`](tasks)) · โจทย์หลายเทิร์นส่งทีละเทิร์นตามลำดับ ไม่มีข้อความอื่นแทรก ไม่มีคนตอบคำถามกลางทาง |
| ที่ทำงาน | ทุกรันเริ่มจาก git repo ใหม่ที่มีแค่ไฟล์ตั้งต้นของโจทย์ ([`tasks/*/start/`](tasks)) |
| เทสต์ | คัดลอกเข้าไปตรวจหลังตัวครอบจบเทิร์นแล้วเท่านั้น ([`tasks/*/hidden-tests/`](tasks)) |

**ความยุติธรรมที่ควรรู้**

- ทั้งสามตัวใช้โมเดล บัญชี ระดับความคิด ข้อความ และไฟล์ตั้งต้นเดียวกัน ต่างกันแค่ตัวครอบ
- Aetox เปิดสกิลที่ติดมากับตัวติดตั้งตามที่ผู้ใช้ได้จริง OpenCode ไม่มีสกิลติดมา Codex ถูกปิดสกิลระบบ ปลั๊กอิน และค้นเว็บ
  ให้เหลือแค่ตัวครอบกับล็อกอิน เหมือนที่ OpenCode ได้
- Codex รอบแรกล้ม 3 รันตั้งแต่ก่อนทำงาน (ล็อกอินชนกับแอป Codex ที่เปิดอยู่บนเครื่อง ได้ error `refresh_token_reused`)
  ทั้ง 3 รันถูกทิ้งแล้วรันใหม่ทั้งหมด ไม่มีรันไหนในตารางที่ล้มเพราะล็อกอิน
- S4 (code_search) ได้สูงสุด 23/25 บน Windows แม้ใช้เฉลยของชุดข้อสอบเอง — ทุกตัวที่ได้ 23/25 คือเต็มเท่าที่ทำได้
- เวลาวัดขณะรันพร้อมกัน 3 รัน ใช้เทียบกันได้ แต่ตัวเลขเดี่ยวจะช้ากว่ารันทีละรัน
