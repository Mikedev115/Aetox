## กติกาให้เอกสารไม่หลุดกัน

1. **รายงานใหม่ต้องลงตารางในหน้านี้** ในการ commit เดียวกับตัวรายงาน ถ้าแทนฉบับเก่า ย้ายฉบับเก่าลงตาราง "ฉบับก่อนหน้า" และใส่บรรทัดแรกในฉบับเก่าว่าแทนด้วยฉบับไหน
2. **README และเว็บลิงก์มาที่หน้านี้ หรือฉบับล่าสุดตามตารางนี้** ตัวเลขที่ขึ้น README หรือเว็บต้องอยู่ใน [PUBLISHED-NUMBERS.md](PUBLISHED-NUMBERS.md) ว่าอยู่กี่ที่
3. **ที่นี่มีแต่ผลวัด** เอกสารทดลอง เอกสารคิด และรายละเอียดภายในเก็บใน `docs/internal` ซึ่งไม่ขึ้นรีโปนี้ · รายงานสาธารณะลิงก์ได้แค่เอกสารสาธารณะ
4. **ตรวจก่อนขึ้นสาธารณะ** `python scripts/check-report-links.py` ตรวจว่าลิงก์ในรายงานกับ README ไม่เสีย และทุกรายงานในโฟลเดอร์นี้อยู่ในหน้านี้
